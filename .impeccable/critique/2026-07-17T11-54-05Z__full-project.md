## Anti-Patterns 判定

**LLM 评审（A）：PASS，不是 slop。** 设计带领域信念：考卷面 serif 栈遵循真实高考
卷印刷惯例、暖纸+近黑墨+茶青克制、宽词「阅读」劝退收窄+「猫」反问意图是真产品
判断力。内容确实是主角。

**确定性扫描（B）：CLI 命中 394 → 5，数量级改善。** 07-13 的 230 条 font-size/
131 条 color 文档缺口全消（design-canon-v2 token 反向注释生效）；旧真漂移
（emerald/amber/radius 出格）不再出现。剩 5 条：margin-top transition（真，
C 路独立同报）、side-tab 红边 3px（DraftPaperWorkbench.css:324，绝对禁令族）、
draftPaperPreviewHtml 10-12px 扁平梯与 em-dash 21 处（考卷印刷语境，误报）、
broken-image（JSDoc 注释误伤，B 已实核）。五页注入：dark-glow 全页误报（浅色
主题误判，与 07-13 同）；visually-hidden 溢出为 a11y 惯用法误报；真发现=详情页
peek-paper 剪裁定位子元素（与 C 路 max-height 硬跳同区互证）、my-space 9px
tiny-text（A4 微缩卡语境，边缘）、两处 cramped-padding。

**工艺评审（C）：历史性改善——「句子写完了大半」。** 07-13 的账（按压仅 3 处/
退出全瞬灭/scrollIntoView 3/4 无视 reduce）已翻面：75 条 transition 93% token
化、transition:all=0、ease-in=0、scale(0) 入场=0、按压反馈 8 类全站一致、
usePresence toast/模态出入场对称教科书级、hover 抬起双 gate。剩余坏账：三个
disclosure 菜单（insertion/export+more/filter-panel）退出瞬灭裸弹、
SevenChoicesAnalysisPanel.tsx:60 scrollIntoView 漏守 reduced-motion（helper
收编时的漏网点，确证回归，一行修）、详情页「一张纸」展开 max-height:none 硬跳、
margin-top/grid-template-columns 两处布局属性动画（低频有界）。

## 三路交叉验证

- **三路同指**：margin-top transition（B CLI + B 注入 + C 独立发现）。
- **两路互证**：详情页 peek 区（B 剪裁 + C 硬跳）；讲评 404（A 亲见 + B 转录）。
- **A 独有**（人眼才看得见）：篇章标题重复渲染、相似篇章空转、面包屑裸串。
- **C 独有**（契约才查得出）：菜单退出不对称、scrollIntoView 漏网点。
- **误报净化**：dark-glow/visually-hidden/JSDoc/考卷小字号/考卷 em-dash 共
  ~9 条判死，不进账。

## Overall Impression

地基已经从「扎实」进到「优秀」：token 纪律、动效语言、领域还原都是同类工具
罕见水平。剩下的问题几乎全是**内容信任层**（标题重复、空转的招牌功能、裸串）
和**最后一寸工艺**（菜单退出、一行 reduce 漏网）——没有一个是结构性的。

## What's Working

1. **讲评态右栏解析卡**：答案依据+定位关系/同义替换+干扰项定性——真教学价值。
2. **A3 对折工作台**：spread+对折线+张数换算+重排进度丸，印刷心智模型完整。
3. **动效系统**（C 路盖章）：五档时长梯带边界注释、Emil 原方曲线、usePresence
   范式、a11y 双保险。「这不是套 CSS，是有人认真建了一套动效语言。」
