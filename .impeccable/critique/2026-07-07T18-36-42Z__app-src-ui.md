## Anti-Patterns Verdict

**表层 PASS，集成层 FAIL。** 章程拒绝的五种长相（SaaS 蓝/科技紫/营销渐变/表格墙/糖果风）无存活实例；`shared-ui/tokens.css` 源头真干净，历史 `--blue-*` 已重映射成中性。但「按 cut 拼装、局部合理、全局不连贯」明显：脚手架标签上生产、四套顶栏、AI 仪表读数裸奔。

- 探测器（源码）：14 条命中；App.css 6 条 side-tab 全在无人引用的死 CSS；活的在 harness 与 reading-analysis 孤儿支。
- 探测器（DOM，5 页注入全成功）：feed 标题溢出 236px、低对比 ×2（#9a9a93 on #ededea 2.4:1 / on #ffffff 2.8:1）、clipped-overflow ×2、`transition: width`（与源码互证）。
- 误报：`.visually-hidden` 溢出为无障碍隐藏模式；flat-type-hierarchy 属产品 UI 克制字阶；#e3ddd3 等与 token 距离极近属 harness 已治理调色板变体。

## 核心发现

### 一、外壳的「地层未压平」（A 侧最大发现）
1. **`Paper Surface (C4)` 印在全部 4 个卷面页顶栏**（Harness.tsx:1259/1304，`.pi-ps-harness-tagline`）——内部 cut 代号朝向用户。
2. **四套顶栏形制**：首页/详情/管理台（字标+描边按钮）、草稿卷（返回+标题输入+分段+导出）、My Space（返回+eyebrow）、卷面（返回+C4 标签，无全局导航）。
3. **「返回」三个名字**：返回取题台 / 返回工作台 / 返回列表。
4. **圆角两套刻度**：登录 12/8、管理台 12 vs 章程 8/6；App.css 散落一次性 5/7/10/16。
5. **焦点环三套**：章程 3px@0.20（登录用对）vs 2px@0.6 ×3 vs inset 2px@0.6 ×2。
6. **阴影词表零散**：无组件用章程 Floating token；存在超重 `0 18px 46px rgba(30,30,28,0.22)`。

### 二、解析面板色彩孤岛（A/B 交叉证实）
`pi-ps-*` harness（app 侧，非 `shared/papersurface/**` 锁定区）运行 PR #52 PA 批准的独立「warm pencil + ink」配色：暖米右栏底、棕琥珀徽标。其内部：
- **自违规**：文件头注释明写「amber #f59e0b 保留给 distractor source，不得用于 rail/chip」，而 `option-badge--trap`（css:486-489）用了 rgba(245,158,11,.13)。
- **无文档漂移**：slate 蓝灰 #6f7b8f ×20（`.pi-ps-analysis-option-zh`，对暖米底 ≈4.2:1 未达 AA）、杂绿 #2a7c4f/#1f6f47、emerald 契约色越界到卷面外（blockquote border-left）。
- **字道**：harness 全区 `font-family: system-ui`（css:117），其余页面 Inter（实测 paper 页 shell 39 元素 system-ui）。
- 卷面内 evidence 高亮（mark emerald、active teal）in-paper 属锁定契约，豁免。

### 三、产品边界泄露
题组详情：话题置信度 `60%/85%` 裸奔 + 15 枚 owner 校对用「待对比」琥珀按钮墙——AI 车间仪表进了消费视图，违背「内容是主角/网站只消费」。

### 四、零散违章
- 语义色硬编码绕 token：`#16a264`（App.css:927/2268）vs success #059669；`#c49b2a`（:940/2280）vs warning #d97706。
- #9A9A93 作可见文字（登录副文案、eyebrow）≈2.6:1，章程自身禁止 faint 作正文。
- 管理台近乎空屏（像坏了）；搜索 loading 空白闪；feed 标题截断（DOM 溢出 236px）；「加入草稿卷」hover-only 且键盘不可达。

## 强项

1. **主操作语言全站统一**：实心墨绿 + 白字贯穿；Green-Pen 预算实测 <10%，签名克制。
2. **草稿卷 A4 实时预览 + 双字道**：分页建议人话可执行，是「信得过发给学生」的信任锚点，也是情绪旅程最强峰。
3. **源头 token 真干净**：真中性灰阶 + 单条墨绿，历史蓝紫全灭——不像 AI-slop 的根本原因。
4. **文案口吻**温暖不油腻，无营销腔无报错腔。

## Priority Issues

1. **[P1] 外壳统一**：四套顶栏→一个 AppShell；「返回」统一命名；C4 脚手架标签换真标题；owner 视角 7 按钮收组（根治 900px 换行）。
2. **[P1] 解析面板归队**：色彩孤岛收敛到章程（作废 PR #52 warm-pencil 决定需在 plan 显式记录）、slate 蓝/杂绿/自违规 badge/字体/transition:width 一并修。
3. **[P2] token 纪律大扫除**：焦点环统一章程环、圆角回 8/6/4、阴影收敛 Resting/Floating、语义色硬编码入 token、#9a9a93 可见文字改 ink-muted。
4. **[P2] 产品边界收尾**：置信度%与「待对比」墙对 member 隐藏（owner 保留），需 PO 确认口径。
5. **[P2] 找题体验小包**：loading 骨架、加入草稿卷常驻+键盘可达、feed 标题列宽。
6. **[P3] 打磨杂项**：死 CSS 四组、空态口吻统一、思考模式开关、980px 组间距、管理台空屏最小处理。

## Persona 红旗

- **Alex**：无快捷键；三套焦点环致键盘走位不可靠；「返回」每页换名打断肌肉记忆；灰色圆形 `→` 提交靶不确认 Enter 可用。
- **Sam**：#9A9A93 正文 2.6:1、slate 释义 4.2:1 未达 AA；hover-only 按钮键盘不可达；焦点可见性时强时弱。
- **Jordan（M2 新同事）**：登录页无一句产品说明；首触卷面即见 `(C4)` 读成「内部未完成」；管理台空屏像坏了；四套外壳建不起页面地图。

## 认知负荷

8 项过 6：跨步 working memory（草稿 pill 常驻）与渐进披露是强项；败于首页首屏 ≈15+ 可点目标、题组详情琥珀墙+置信度墙信息过载。

## 情绪旅程

峰1=首页（品牌人格在场）；谷1=卷面 `(C4)`+详情待对比墙（从专业工具跌到脚手架）；谷2=空管理台；峰2/终点=草稿卷 A4 预览+分页建议（最强一记）。峰终偏正，中段两谷拉低「顺手」。
