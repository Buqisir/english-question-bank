## Anti-Patterns 判定

**LLM 评审（A）：过。** Linear/Notion 级用户会信任这个界面：中性纸底+近黑墨+单一茶青、Inter/衬线分道、扁平+状态阴影、组件词汇全站一致。无渐变无玻璃无紫。会让人停顿的不是视觉 slop，而是**数据组合毛病渗进 UI**（卷名结巴、rail 全截断、无关推荐）。

**确定性扫描（B）：394 命中，绝大多数是文档缺口不是 slop。** font-size 230 条 = 事实工作梯（13/14/11/15/18px）没写进 DESIGN.md；color 131 条大半是纸面暖墨家族未入档（已拍板的方向）；真漂移：emerald #10b981（应 #059669）、amber #f59e0b（应 #d97706）、radius 7/10/12px 出格。broken-image 1 条为 JSDoc 注释误报。页面注入 5 页：search submit 对比度 2.4:1、topbar 标题溢出 39px、pi-ps-harness 剪裁定位子元素 ×2、个人空间 h2→h4 跳级。dark-glow 全页误报（浅色主题误判）。console 零报错、网络零失败。

**工艺评审（C）：词汇表教科书级，句子写了一半。** motion-pass 的曲线/时长/reduced-motion 全对、零 ease-in、零 transition:all；但 token 只铺到 hover 和入场——全站按压反馈仅 3 处（2 处 base transition 缺 transform，按下弹回无缓动）、模态/菜单/toast 退出全部瞬灭、两个模态框裸弹、3/4 处 scrollIntoView 无视 reduced-motion。

## Priority Issues

1. **[P1] 无匹配搜索硬凑 8 条推荐，每条自注"与…无关"** — 品牌"可信"轴最弱点，工具最低信任时刻演成闹剧。修：全无关时诚实空态领句或干脆不出候选。
2. **[P1] 详情/筛选状态不进 URL** — 刷新/改窗口即被踢回列表；详情是 button 而兄弟操作是 a href。修：详情给 ?view= 路由、筛选序列化进 query。
3. **[P2] 交互工艺账（C 全单）** — 按压反馈半残/缺失、模态菜单 toast 无退出动画、原点不感知。C 已给 Before/After 全表，几十行 CSS，全站手感升一档。
4. **[P2] 数据组合毛病渗 UI** — 卷名结巴（"全国新课标Ⅰ 新课标Ⅰ卷"/杂"3"）、rail "Reading…"×4（label 输给定宽 count）、相关性排序年份头重复。新同事第一眼"这数据可信吗"。
5. **[P2] 对比度/结构小账** — search submit 2.4:1、topbar 溢出 39px、h2→h4 跳级、--mint-soft emerald 色相漂移 ~10 处。

## 主页方向（owner 2026-07-13 口述议题）

owner 长期觉得主页"不够 feel"；有人建议"大输入框+全空白"，owner 未接受但没方向。A 的证据：美学 4/4、feed 扫读好，但 hover 藏操作 + 行内两种意图竞争（挑衅问题1：杀掉 hover 栏、详情做唯一门？）。合成判断：拒绝纯空白版正确（recognition over recall；题库是结构化馆藏不是开放语料），但"没有锚"的感受有据。方向候选：搜索做主角+脚下铺工作现场（组卷篮状态/最近看过/题型 chips）。**建议单独立刀，2-3 原型变体让 owner 实点拍板。**
