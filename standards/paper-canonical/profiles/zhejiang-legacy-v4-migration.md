# Zhejiang legacy Profile v4 migration

Zhejiang legacy Profile v4 replaces the v3 suppression bridge with the
source-backed Writing hierarchy from the hash-bound original DOCX
`sha256:1a447b5dc7bdba349347d61080304eab55815e41db055b5c2ff9b43545b79cdc`:

- `第四部分 写作（共两节，满分40分）`
- `第一节 应用文写作（满分15分）`
- `第二节 读后续写（满分25分）`

The profile now owns two ordered 15/25-point sections, each binding exactly
the same Application or Continuation slot that v3 bound inside the temporary
shared section. All non-Writing slots, family versions, numbering, scoring,
answer regions, and completeness rules are unchanged.

The complete Zhejiang fixture now admits Application Writing only from a new
digest-bound accepted capture/transcription pair for the same immutable DOCX.
It no longer inherits the Foundation fixture's English Application prompt.
Profile chrome comes only from the v4 Profile/Plan projection; neither
renderers nor legacy Paper Asset fields may supply or translate it.

Manifest v9 retains v8 and Zhejiang legacy Profile v3 for existing
Publications and makes v4 the only Zhejiang legacy Profile accepted for new
compilation.
