# Manifest v18 migration

Manifest v18 adds the Cloze Rhythm v1 renderer-typography authority without
changing canonical text, question/blank identity, official answers, family
contracts, the shared A-D selector, Reading Typography v4, or Seven Choices
Rhythm v3.

The new authority binds the digest-fixed page-09 Cloze Golden Geometry reference,
dimensionless vertical and horizontal measurements, the complete Cloze
semantic-role adjacency graph, 3.3em-class atomic inline blanks, fixed
four-column option origins, label/text anchors, row atomicity, pagination,
Student/Teacher tails, and transitions to Grammar Fill. Screen v18 and
Print/PDF v19 consume the same canonical projection under this authority.

Manifest v1-v17, all earlier consumer contracts, schemas, authorities,
original source bytes, official-answer bytes, and evidence remain immutable
and resolvable for historical Publications. Generated DOCX stays retired.
