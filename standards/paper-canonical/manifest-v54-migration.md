# Combined format authority successor v54

v54 derives from immutable v53 and replaces only Source Adapters v15 with v16,
Paper Presentation v1 with v2, and the identity-named Normalization Report and
Publication schemas required by a producer authority. The materialization
adapter entry advances to behavior v2 while all input schema versions remain
unchanged. Global accepted authority remains v36.

The adapter successor makes the shared materialization validator's suspected
passage-instruction diagnostic part of admission and uses the same writing
notice/word-count interpretation as DOCX materialization and both renderers.
Presentation v2 closes the shared 18pt listening rhythm, source-preserving
combined/split writing notices, measured overflow, and the bounded 8/10-page
cover/search/scoring rules. Screen v42 and Print/PDF v43 select v54.

No Source, Candidate, confirmation, Publication, pagination plan, PDF, or other
historical artifact is rewritten. A digest-bound explicit old pagination plan
remains replayable under its recorded rules; this migration does not promise
pixel-identical output when historical content is re-rendered by current code.

Reproduce with `node scripts/generate-paper-format-authority-v54.mjs --check`.
Semantic and compatibility coverage is in
`node scripts/verify-paper-format-authority-v54.mjs` plus the existing focused
materialization, writing-render, and fixed-page planner checks.
