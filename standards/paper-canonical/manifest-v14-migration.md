# Manifest v14 migration

Manifest v14 changes only the current renderer/output authority closure. It
binds Renderer Typography v4, whose Reading contract adds the complete
semantic-role adjacency graph and exact Screen/Print-PDF rhythm mappings for
passage chrome, A-D passage content, questions, options, teacher tails,
continuations, passage transitions, and the following section.

The measured golden-reference evidence remains byte-bound. Cropped JPEG
coordinates supply only dimensionless local baseline ratios and are never
treated as CSS pixels, PDF points, or full-page A4 scale.

New canonical publications bind Screen v14 and Print/PDF v15. Manifest v1-v13,
Renderer Typography v1-v3, and their consumer contracts remain immutable
parse-only authority for existing publications.

Admission, canonical content semantics, Profile cardinality, normalization,
question and option order, answers, horizontal A-D placement, rich-content
order, and non-Reading rendering do not change.
