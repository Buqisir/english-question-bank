# Paper Typography v5 migration

v5 preserves v4 A–D identity, centering, 18pt line box, role classes,
adjacency graph, targets, and reference measurement. It registers one new
visible-chrome fact: the Profile-owned Reading instruction is the last chrome
role before passage A. The instruction-to-A edge remains the existing
`chrome_to_a` one-baseline relation; no line-height adaptation is introduced.
