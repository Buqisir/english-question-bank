# Cloze Rhythm v4 migration

Cloze Rhythm v4 succeeds v3 without modifying it. The fixed A/B/C/D anchors
and the `0.411765em` label-to-text gap are unchanged. The question-number
track now right-aligns its visible glyph edge to the fixed first-option anchor,
so `41.` → `A.` has zero added inter-token gap.
