# Paper Typography v7 migration

Paper Typography v7 succeeds v6
(`sha256:a7b1739414fdaa21c8c8c9774ea5a7f6a5fb42f38a84a545ab36b278e20a6152`)
without changing canonical text, source identity, fixed 18pt Print/PDF
baseline, or the accepted 2em/4em paragraph roles.

It versions three Owner-gold horizontal rules for all public surfaces:
Reading question leads use the measured 1.647em hanging anchor; the Reading
four-column C origin and two-column second origin share one 4160/8764 usable
width anchor; and Reading/Cloze question numbers, option labels, and option
text use regular 400 weight. It also versions the 0.2em numeric score-run
baseline shift, derived from local Song-font glyph descent rather than image
pixels.
