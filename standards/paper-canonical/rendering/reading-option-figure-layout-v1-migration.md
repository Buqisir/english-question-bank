# Reading Option Figure layout authority v1

Manifest v47 is a scoped rendering successor to the immutable Reading Figure
Option admission authority in manifest v46. It adds one renderer-owned physical
layout artifact for already-projected Figure Options; it does not change the
v46 Reading family, projection, admitted media bytes, or current/public v36
authority.

Screen and Print/PDF translate the same point-based placement. Existing
literal-text Reading layout remains on its previously published path.
