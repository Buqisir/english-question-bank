# Continuation Writing Rhythm v5 migration

Continuation Writing Rhythm v5 succeeds v4
(`sha256:771646e39e013070ffb74ed9f81fa34fa3a5e0572ae28f2d2e5bb46328f1881f`)
without modifying it.

underlying Continuation geometry, source material, student/teacher separation,
and fixed rhythm remain unchanged. The v4 bytes remain reloadable.
