# Manifest v23 migration

Manifest v23 succeeds, but does not rewrite, Manifest v22. The successor
publishes Grammar Fill rhythm v3 and public-geometry-fixtures v2. Their closed
proof chain binds the source oracle v3 and public adversary v2, neither of
which contains `wrappedLineWidthPt` or another px/pt shadow-geometry field.
The conformance fixture rejects both pt and px width injections.

The canonical projector now carries each Grammar Fill Blank's exact
source-backed prompt identity as an explicit string or `null`. The shared
post-loader consumer no longer infers prompt semantics from adjacent prose.

Fixture selection requires the exact Manifest v23 Consumption Plan and the
surface-compatible Consumer Contract. Screen v23 and Print/PDF v24 reject an
absent, historical, or mismatched Plan. Semantic authority validation also
requires the exact fixture artifact even when its manifest descriptor,
schema, registry entry, and artifact are removed together.

Manifest v1-v22, Grammar Fill rhythm v1-v2, source oracle v1-v2, public
adversary v1, public-geometry-fixtures v1, every prior schema and consumer,
and the byte-pinned historical v13 Publication remain byte-for-byte resolvable.
Generated DOCX stays retired.
