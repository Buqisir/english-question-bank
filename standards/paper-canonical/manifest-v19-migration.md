# Manifest v19 migration

Manifest v19 supersedes only the incomplete Cloze Rhythm v1 authority closure.
It adds the semantically closed Cloze Rhythm v2 payload and exact schema without
changing canonical text, Question/Blank identity, official answers, renderer
geometry, family contracts, or the shared A-D selector.

Every declared v2 field is exact authority: all 26 edge endpoints, relations,
ratios and collapse semantics; Screen and Print/PDF targets and tolerances;
blank alignment and atomicity; the fixed four-track horizontal strategy,
origins, pitch, widths and gutter; renderer-owned values; and both digest-bound
Golden Geometry references. Screen v19 and Print/PDF v20 consume the same
canonical projection under this authority.

Manifest v1-v18, every earlier Consumer Contract, schema, renderer authority,
Publication, source byte, official-answer byte, and evidence artifact remains
immutable and resolvable. Generated DOCX stays retired.
