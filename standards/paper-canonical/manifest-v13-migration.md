# Manifest v13 migration

Manifest v13 changes only the current renderer/output authority closure. It
binds Renderer Typography v3, whose new Reading passage-letter contract is
measured from the accepted golden paper. Cropped JPEG pixels supply only
dimensionless local baseline-step ratios; Screen and exact-A4 PDF map those
ratios to their actual rendered line steps and bind each measured predecessor
to the exact visible `groupId`. The v2 Question and A–D Option layout
coordinates remain numerically unchanged.

New canonical publications bind Screen v13 and Print/PDF v14. Manifest v1-v12
and their consumer contracts remain immutable parse-only authority for
existing publications.

Admission, canonical content semantics, Profile cardinality, normalization,
question order, answers, and the supported Screen/Print-PDF output matrix do
not change.
