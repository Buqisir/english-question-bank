# Application Writing family v2 migration

Application Writing v2 replaces the v1 foundation envelope only for new
canonical compilation and publication. It closes the family variant and its
reviewed source-capture schema: prompt text, the `student_authored_only`
word-count ruling, Given Skeleton presence/parts, and the Plan-bound response
must each resolve to immutable evidence observations.

Existing manifest-v1 through manifest-v3 Publications remain resolvable
through their immutable authority closures. New Publications use manifest v4
and matching Screen v4, Print/PDF v5, and DOCX v4 Consumer Contracts.
Legacy `paper-asset-v1`, Analysis, model answers, ReviewCards, highlights, and
generator audits remain non-authoritative migration leads and cannot construct
or change the Application Writing canonical Group.
