# Application Writing family v3 migration

Application Writing v3 preserves the closed v2 variant while strengthening
source admission. New compilation requires exactly one digest-matching
original source document and one independently digest-closed, manually
reviewed transcription. The capture's ordered blocks, Given Skeleton union,
fixed-part ownership, and response region must agree with that transcription;
the capture cannot authorize itself.

Manifest v4 and Application Writing v2 remain immutable and resolvable for
existing Publications. New Publications use manifest v5 and matching Screen
v5, Print/PDF v6, and DOCX v5 Consumer Contracts. Legacy `paper-asset-v1` and
optional supplements remain non-authoritative.
