# 生词本首次空态换成折角纸（BRAND §5.2、第 54 条）· 2026-11-16

生词本一张卷都没收藏时，空态的图从「生词本」图标的平涂版（88px，三档灰）换成原语插图「收藏的卷」：雾薄荷折角纸、浅雾薄荷正文行和药丸空、墨书签。图高 64px，放在一行字上面。说明和「去找题」键都没改。

依据：BRAND.md §5.2 的插画表写着生词本这一处用 `spot-paper.svg` 64px；DESIGN.md「Empty states」说插图本身按 BRAND §5.2。

## 怎么接的

- `app/public/brand/spot-paper.svg`：从 `design/brand-2026-10-13/illustration/spot-paper.svg` 原样复制，逐字节一样。和獭獭图是同一个办法。
- `EmptyState` 多一类图 `primitive`，现在只有 `'paper'` 一种。用法：`<EmptyState primitive="paper">`。
- `emptyState.css`：
  - 新变量 `--eqb-empty-primitive-size: 64px`；
  - 图下补 8px，和坐石全身像一样。viewBox 贴着画出来的边，不补的话图离字太近。
- 别的四处空态（个人空间、听写词组、题库、草稿卷）不动。
