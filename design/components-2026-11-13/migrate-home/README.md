## 五、要 Owner 看的

1. **「筛选」没有边了**：原来的注释说，这一行只有搜索框是带框的控件，「筛选」只用一根细线，不另立一个框。现在连细线也没了，展开和收起只靠有没有桌色底来分。如果要留细线，得给 `Button` 加描边那一种。清点时有边的按钮 26 个、没边的 288 个，没过门槛（`../inventory.md`）。
2. **「清除搜索」从圆变成圆角方块**：按 `Button` 的规矩，按钮不做胶囊和圆。它在搜索框里面，旁边的「搜索」回车键是圆角 8 的方块，现在两个一样了。
3. **「浏览全部」字和图标靠近 2px、字变重**：照构件。
4. **结果行「看整卷」没换**：
   - 原因一：它在会滑的悬停列表里。照 button.css 的规矩，列表里的透明底按钮悬停时不自己垫底，由列表的滑块垫。可这个键原来悬停时自己会垫一块，字又本来就是墨色，换了以后悬停这个键本身就完全没有变化了。要换，得先定列表里的键悬停时要不要自己垫底。
   - 原因二：本地网站的卷都没上线（结果行显示「整卷未上线」），这个键拍不到。
5. **顺手看到、没改的**：点「清除搜索」以后，焦点掉到页面最外层，不回输入框（键盘用户得从头 Tab）。改前改后一样，这次没碰，要改的话另做。
