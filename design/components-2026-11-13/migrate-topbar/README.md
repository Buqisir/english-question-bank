# 换顶栏：顶栏按钮换成共用按钮构件（构件厂第 4 步第一页）· 2026-11-13

状态：**提案 · 单一来源**。Owner 说「先换顶栏」，下面换法、对照和判断只有脚本和我看过；同事访谈按 11-08 的决定没做。本地提交，没推送。

## 一、换了什么

`app/src/components/AppTopbar.tsx` 里顶栏**自己的**按钮换成 `shared-ui/Button`：

| 按钮 | 现在 | 原来 |
|---|---|---|
| 返回找题 | 次要灰 `subtle`、小号 `sm` | `.topbar-back` |
| 生词本、过生词、个人空间、管理 / 退出管理、退出 | 淡墨 `quiet`；首页找题台 `lg`，其余 `sm` | `.ghost-button` 加 `.topbar .ghost-button`、`.app-shell:has(.concierge-desk) .topbar .ghost-button` |

- 首页找题台用大号：`AppTopbar` 新加 `navSize`，`App.tsx` 在渲染找题台的同一个条件下（不在管理页、题组列表）传 `lg`。原来靠 CSS `:has(.concierge-desk)` 加高。
- `App.css`：`.topbar-back` 只留位置（不缩、往左让 8px，箭头仍和内容左边对齐）；删掉找题台那三条加高、变墨、图标尺寸规则（现在由构件管）。
- **没换的**：页面塞进顶栏的按钮（草稿卷的「⋯」、版本、A4 / A3、导出；整卷预览的讲评、PDF），它们属于那两个页面，等换那两页时一起换。所以 `.topbar .ghost-button` 规则还留着，顶栏的滑动高亮两种按钮都认。可改名的卷名（清点 button-08）照第 2 步的判断不套按钮构件。

顺带修了构件的两处（换顶栏时对出来的）：

1. **字被裁掉半像素**：构件按钮和菜单项写了 `line-height: 1`，字标签为了省略号又是 `overflow: hidden`，中文字形顶上、底下各被裁掉约半像素。逐像素对比时详情页的导航按钮有 85 个像素不同，就是这个。改成继承页面行高（和原 `.ghost-button` 一样）后剩 1 个。构件检查补了一条「字标签框高 ≥ 字号 × 1.2」，先把 `line-height: 1` 放回去跑过，确实报失败。
2. **键盘焦点变墨**：原顶栏键盘焦点在导航上时字提到墨色，构件没有。加进构件（淡墨、次要灰在键盘焦点时字提到墨色），和悬停一致。
