# 顶栏滑块：「管理」和「退出」之间不再飘过去

2026-11-16 Owner 截图：「这里两个选中态之间管理跟退出选中态之间移动的话会飘。」

## 原因

顶栏右边的键共用一块滑动高亮（`FluidHoverList`，`app/src/components/useFluidHover.ts`）：指针在哪两个键之间，就亮离它近的那个，换键时高亮滑过去。「管理」和「退出」中间隔着头像和用户名，中间空 87px（量），不是键。所以：

- 指针停在头像、用户名上，「管理」或「退出」还亮着，像停在了不该停的地方；
- 过了中点，高亮从头像和名字后面滑过 159px 才到「退出」。

## 改法

`useFluidHover` 加了 `glideGapMax`：两个相邻的键之间空得比它宽（说明中间放着别的东西），高亮就不滑过去。指针在这段空里时什么都不亮，高亮在原地淡出；到了下一个键原地淡入。一步跨过去（没停在空里）也是原地换，不滑。顶栏传 16px：平常键之间只空 4px，页面自己的键和全站键之间的分隔线那里约 9px，都照旧滑。别的列表没传这个参数，行为不变。

## 量（本地临时网站，1440 宽，鼠标从「管理」中心分 24 步移到「退出」中心，每步停 25ms）

| | 指针在头像、用户名上 | 换到「退出」 |
|---|---|---|
| 改之前 | 「管理」一直亮着（不透明度 1） | 高亮 x 从 280 滑到 439（滑 159px） |
| 改之后 | 不亮；从「管理」边上起约 3 步淡完 | 在 439 原地从 0 淡到 1，x 不动 |

一步跳过去：改之前高亮 x 280 → 410 → 436 → 439（滑过去）；改之后第一帧就在 439。逐帧数据在 `before.json`、`after.json`。
