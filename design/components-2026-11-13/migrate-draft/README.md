## 一、换了什么

`app/src/features/draft-paper/DraftPaperWorkbench.tsx` 里换了四处：

| 位置 | 现在 | 原来 |
|---|---|---|
| 顶栏「…」（学生、最近草稿卷） | `Button` 次要灰 `subtle`、小号 `sm`、只有图标。存盘出错时的危险色边和红点照旧 | `.draft-more-menu-trigger` 自己的一套 |
| 顶栏「导出」和它的菜单 | `Menu`：触发键是雾薄荷主键 `primary`、中号；三项菜单加一条分隔线 | `.draft-export-menu-trigger` 加 `.draft-export-menu-panel`，开关和点外面关都在页面里自己写 |
| 空卷「去找题」 | `Button` 主键 `primary`、大号 `lg` | `.draft-a4-empty-cta` |
| 每个题组工具条上的「…」菜单（上移、下移、前置分页 / 取消分页、移除） | `Menu`：触发键是墨字 `strong`、中号；「移除」前面是分隔线，「移除」本身是危险项 | `.draft-group-actions-menu(-trigger/-panel)`，面板放在工具条里面 |

- **页面里删掉的**：导出菜单的开关状态和那段「点外面、按 Esc 关菜单」的代码；题组菜单的开关状态和失焦就关的写法。这些现在都由构件管。
- **CSS**（`DraftPaperWorkbench.css`）：
  - 删掉导出键、导出面板、「…」键底子、「去找题」、题组菜单这几块规则。
  - 工具条里那几条宽泛的 `.draft-group-actions button` 规则加了 `:where(:not(.eqb-button))`，只管还没换的按钮。`:where` 不加特异度，所以原来谁盖过谁一条都没变。
  - 加了两条显式层叠，都写了注释：
    - 工具条里的构件键圆角改成 4px（DESIGN.md §5 同心：外圆角 8 减去内边距 4）；
    - 存盘出错时「…」键一直保持危险色，并加 1px 危险色边。
- **构件也补了一处**（`shared-ui/button.css`）：触发键打开着的时候（`aria-expanded=true`），保持桌色底、墨字，让人看得出面板是从哪个键出来的。原来草稿卷的两个「…」键就是这样。这一处只对淡墨、次要灰、墨三种透明底的语气生效。放在顶栏这种滑动高亮列表里时，鼠标悬停仍然只显示列表滑过来的那层底。
- **没换的**：

| 位置 | 为什么没换 |
|---|---|
| 「A4 散页 / A3 对折」 | 分段开关，属于另一类构件 |
| 「PDF 版本」下拉框 | 字段，属于另一类构件 |
| 顶栏「…」打开后的面板 | 里面是输入框和下拉框，不是菜单项 |
| 工具条上的「换篇」 | 带按下状态的开关键；窄的时候只剩图标，读屏名字和看得见的字也不一样，套 `Button` 要改构件的接口 |
| 「建议前置分页」小签、A3 接缝小签、排序建议卡的两个键 | 「提议和决定」是 Owner 11-13 刚定的样子 |
| 撤回提示条、存到个人空间对话框里的键 | 等提示条、对话框各自那一批构件 |
| 左边目录的「相似篇章」几个键 | 整卷预览也在用，换整卷预览时一起换 |
| 缺题条目那三个 12px 小图标键 | 只在题组找不到时出现；12px 图标不在按钮的三档尺寸里 |

## 三、要 Owner 看的

1. **导出菜单和题组菜单变小变紧**：这是第 2 步第五节第 3 条（菜单圆角和内边距用 8 / 4，还是原来的 12 / 8）。如果要保留原来的样子，改的是构件，全站菜单会一起变。
2. **题组菜单的字从 16 变成 13**：我判断原来的 16 是没写字号、继承下来的，不是有意设计的，所以按全站菜单统一成 13。
3. **「前置分页 / 取消分页」不再报「按下」状态**：菜单项没有按下这一说，现在靠字本身的翻转来表示当前状态。如果要让读屏念出「已勾选」，需要给 `Menu` 加一种可勾选的菜单项（`menuitemcheckbox`）。
4. **题组「…」悬停时不再弹出「更多题组操作」的小提示**：`Menu` 的触发键现在不接 `title`；读屏名字还在。要的话可以给 `Menu` 加一个参数。
5. **构件新加的「打开着」状态**（见第一节）：照搬的是草稿卷原来的做法。
