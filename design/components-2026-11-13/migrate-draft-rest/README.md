## 二、换了什么

`DraftPaperWorkbench.tsx` 里「保存 PDF 到个人空间」对话框的 4 个键，全换成 `Button`，都用大号 `lg`（高 36）：

| 键 | 现在 | 原来 |
|---|---|---|
| 「关闭」（标题右边） | 墨字 `strong` | 白底描边（`.draft-dialog-head button`） |
| 「新建」（新文件夹名右边，带文件夹图标；没填名字时禁用） | 墨字 `strong`，图标走 `icon` | 白底描边（`.draft-new-folder-row button`） |
| 「取消」 | 墨字 `strong` | 白底描边（`.draft-dialog-actions button:not(.primary-button)`） |
| 「保存」/「保存中...」（提交键） | 石板墨填充 `solid` | 老的全站 `.primary-button` |

- **「保存」用 `solid`，不用雾薄荷主键 `primary`**：原来的 `.primary-button` 就是石板墨底、白字，`solid` 颜色一样；这一页的雾薄荷主键已经给了顶栏「导出」（DESIGN.md §2 每页一处）。
- **CSS**（`DraftPaperWorkbench.css`）：那组白底描边的手写规则原来管 6 种按钮，这次从里面拿掉对话框的 3 个选择器，原处留了注释。规则本身还在，管剩下的撤销提示条里的键。
  - 剩下的 `.draft-outline-actions`、`.draft-suggestions` 两个选择器在页面里已经找不到对应元素，原来就是空的，我没动。
- 对话框本身、文件名和文件夹的输入框、下拉框都没动。

## 五、要 Owner 看的

1. **对话框里的次要键没有边了**：原来是白底描边的「小盒子」，现在是透明底的墨字，悬停才出底色。`Button` 没有描边那一种：清点时有边的按钮 26 个、没边的 288 个（`../inventory.md` 按钮「边框」那行），有边的不到一成，没过门槛，所以没做。和个人空间删除确认框里的「取消」现在是一个样子。
2. **字从 16 变 13**：原来那组手写规则用 `font: inherit`，继承来的是 16。我判断不是有意设计的，因为同一排的「保存」是 13。
3. **「保存」用石板墨填充、不用雾薄荷**：理由见第二节。
4. **「换篇」的读屏名字**：要换它得先定读屏名字怎么说。
   - 改成包含「换篇」两个字的说法，比如「换篇：换一篇相似篇章」；
   - 或者给 `Button` 开一个口子，让它在有字时也能另给读屏名字。
   - 前一种同时修了看得见的字和读屏名字对不上的问题，我倾向这个。
5. **「采用」「撤回」和两个分页小签**：是你 11-13 定的提议样子。如果要进构件，得给 `Button` 加一种「提议」语气，或者单做一个提议小签的构件。
