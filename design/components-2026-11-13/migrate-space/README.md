## 一、换了什么

全都换成 `Button`（`app/src/shared-ui/Button.tsx`）。行上的「…」上一页已经换成 `Menu`。

| 位置 | 现在 | 原来 |
|---|---|---|
| 文件行「下载」「打开原草稿」 | 次要灰大号（`subtle` `lg`，高 36，窄屏 34），和同一行的「…」一样 | `.my-space-row-actions button` 手写 |
| 「下载」下载中 | 仍用 `disabled`（变淡、不能点），「…」也一样禁用，和原来一样 | 同左 |
| 空态「去找题」、出错态「重新加载」 | 雾薄荷主键大号（`primary` `lg`，高 36） | `.my-space-empty-cta` |
| 删除确认框「取消」 | 墨字大号（`strong` `lg`） | `.my-space-confirm-actions button`，高 34 |
| 删除确认框「删除 PDF」 | 危险字大号（`danger` `lg`） | 同上加 `.my-space-delete-confirm` |

- **CSS**（`MySpacePage.css`）：
  - 删掉行键的手写规则（基本、悬停 / 焦点、禁用）、`.my-space-empty-cta` 一块、确认框按钮三条；焦点环那条只留文件夹按钮。原处留了注释。

  - `my-space-empty-cta`、`my-space-delete-confirm` 两个类名还挂在 `Button` 上，只当选择器钩子。
- **`Menu` 补了 `gapClick`，个人空间的菜单设成 `false`**：见第三节第 1 条。
- **没换的**：

## 三、要 Owner 看的

1. **上一页换菜单时漏了一样行为，这次补上了**：原来个人空间的菜单关掉了「点面板空隙也算点最近那一项」（会滑的悬停列表默认开着这个），换成共用 `Menu` 时没带过去。也就是说，从上一个提交到这个提交之间，在菜单面板边上的空白处点一下，可能会点到「删除文件」（还会弹确认框，不会直接删）。这次给 `Menu` 加了 `gapClick`，个人空间设成 `false`，和原来一样；别处的菜单原来就开着，没动。
2. **同一处还漏改了一个检查脚本**：`scripts/verify-my-space-shelf.mjs` 里菜单那 5 条还在 `MySpacePage.tsx` 里找菜单代码（`role="menuitem"`、`createPortal`、`activeFileMenuCloser` 等），上一页把它们搬进 `Menu.tsx`、删了 `activeFileMenuCloser`，这几条从那时起就会失败。上一页的 README 说「找的是类名，没动」，那句不对，这个文件我当时没查到。这次改好了，见第四节。
3. **确认框的键 34 → 36**：`Button` 没有 34 这一档，取了大号。
4. **空态主键有了悬停变化**：原来悬停时没有任何变化。
5. **行上两个键的字重 400 → 500、内边距 10 → 12**：照构件。
