## 规范

### 形状
1. 灰块圆角一律 `--eqb-radius-control`（8）。芯片、分段开关这类标签照旧用胶囊。
2. 高度两档：**28**（图标钮、紧凑键、文字里的小键）和 **32**（单行列表行、分区标签）。
3. 灰块不贴容器边：
   - 板里的整行，四边收 4px，和板的 12 圆角同心；
   - 滑块（FluidHoverList）用 `--fh-inset-x` / `--fh-inset-y` 往里收（负值是往外扩）。
4. 小于 28 的灰块撑到 28，用负外边距抵掉多出来的高度，**不挪动布局**。逐个量过邻居位置，见下面「小灰块」一节。

### 三个状态（`shared-ui/tokens.css`）

| token | 值（方案 D） | 页底 #F1F5F7 上 | 白底上 | 用在 |
|---|---|---|---|---|
| `--eqb-color-state-hover` | rgba(31, 90, 122, 0.087) | #DFE8EC，ΔL* 5.0 | #ECF1F3，ΔL* 5.3 | 悬停、键盘焦点 |
| `--eqb-color-state-selected` | 同上 | 同上 | 同上 | 选中，**必须另带一个不靠灰的标记** |
| `--eqb-color-state-selected-hover` | rgba(31, 90, 122, 0.139) | #D4DFE6，ΔL* 8.0 | #E0E8ED，ΔL* 8.5 | 悬停在已选中的东西上、行按下 |

- 改前是桌色 #E6EDF0 / 边框色 #DCE6EB（不透明），页底上 ΔL* 只有 3.0 / 5.6。
- D 是半透明叠层，所以同一个 token 在页底和白底上深浅差不多（Claude 参照：行 ΔL* 4.5，图标钮 9）。
- 为什么选中不能只靠灰：就算 D，选中底对页底也远不到 WCAG 1.4.11 要求的 3:1。所以选中靠下面这些标记来认，灰只是辅助。

### 落地时多做的三件事

1. **57 条悬停 / 选中的底换成 token**（19 个 CSS 文件，只改 background 值）。灰块、只读小标、表头、骨架屏、禁用填充键这些「面」仍用桌色，没动。
2. **不叠两层**：叠层半透明，选中的东西自己画了底，滑块再停上去会叠成两层。`App.css` 用 `.fluid-hover-list:has(…)::before { opacity: 0 }` 把滑块藏掉（芯片按下、打开着的触发键、展开的卷头、听写词组选中、听音频当前词）。实测展开的卷头：静止 0.086、悬停 0.137，滑块透明度 0。行里嵌着的键悬停时叠在滑块上，是有意深一档。
3. **灰底上淡墨字提一档**：淡墨 #5A6C75 在页底上本来只有 4.99，垫上 D 的悬停层掉到 4.40、最深层 4.04。所以在悬停 / 选中范围里把 `--eqb-color-text-muted`、`--desk-muted`、`--muted`、`--blue-text` 改指次要灰 #3F525B：页底最深层 6.03、白底最深层 6.59。这几个别名在 `:root` 上就解析了，所以要在作用范围里逐个重设，只重设源头变量不起作用。

### 展开的卷头

灰画在卷头的 `::before` 上：四边收 `--eqb-space-1`（4）、圆角 8、`z-index: -1`，卷头 `position: relative; isolation: isolate`。布局不变（改前改后卷头的盒子一样大）。

### 只有图标的 Button 中号：32 → 28

重跑 13 页清点：1440 宽 9 个、390 宽 8 个正方形图标键都是 28×28；没有一个被裁。剩下唯一 32×32 的是搜索框里的回车键（`SearchField` 自己的，不是 Button 中号，放在 54 高的框里，没改）。
