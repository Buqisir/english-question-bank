## 规范（已落地的部分）

1. 灰块圆角一律 `--eqb-radius-control`（8）。胶囊芯片照旧（胶囊只给标签类）。
2. 滑块（FluidHoverList）默认圆角从 0 改成 8；新增 `--fh-inset-x` / `--fh-inset-y` 把灰块往里收。
3. 板里的整行（RowList、个人空间文件列表、卷行里的题组列表）：灰块四边收 4px，和板的 12 圆角同心。
4. 菜单：菜单项 4 → 8，面板 8 → 12（card），面板内边距 4 不变，仍同心。**和 DESIGN.md §5 现写的「菜单 8、项 4」不一致，等拍板后同步。**
5. 听写分区标签：灰块 32 高、左右各多出 8px 包住字，不再是上下通高的直角块。
6. 听音频列表、复习下载选项的滑块 4 → 8。

## 没改、等定的

- **对比度**：桌色在页底 #F1F5F7 上只有 ΔL* 3.0（1.08:1），比 Claude 最淡的「选中」4.5 还淡；在白纸上 6.7，接近。
  提案：页底上悬停改用 border 色 #DCE6EB（ΔL* 5.6），白纸上保持桌色。代价：淡墨小字 #5A6C75 在 #DCE6EB 上 4.32，不到 AA 4.5，要么悬停时把字提到次墨，要么不改。
- 展开的卷行，卷头整条常亮灰（「已展开」），直角贴边。改成收 4px 圆角会和下面题组断开，等定。
- 小于 28 高的灰块（22–24 高，圆角 4）：结果行展开钮、选词浮条的翻译 / 查词键、词典发音键、讲评面板关闭键、题块操作键。按规范应该把灰块撑到 28、圆角 8，会动布局，下一批做。
- 图标钮：Button 中号只有图标时是 32×32，Claude 是 28×28；顶栏已经是 28。全站换成 28 要逐页看，没做。
