## 一句话

> **像老师用一支圆头笔，在纸上画出的熟悉东西：骨架认得出，隐喻取自老师桌上的真实动作，每枚只有一处轻力。**

三层，从下往上判定；下一层不过，上一层不看。

| 层 | 管什么 | 谁来守 |
| --- | --- | --- |
| **骨架**（语法） | 全套必须一样：笔、个头、角、呼吸、繁简、视角、强调态 | Agent 出稿前自检，机器量 |
| **隐喻**（创新） | 画什么：选哪个真实动作或瞬间 | Owner 选 |
| **一处轻力**（微妙） | 怎么画那一笔：收、展、提、落、让 | Owner 选 |

## 第二层 · 隐喻（创新在「选哪个瞬间」）

创新的标准不是「长得新」，而是**找到更贴切的真实动作或瞬间**。Owner 采用过的大胆方案都是这样：

| 图标 | 隐喻 | 出处 |
| --- | --- | --- |
| BookMarked | 圈出一词：老师圈生词 | CR:1222 |
| DictionaryLookup | 词在镜中 | CR:2331 |
| ReadingAnalysis | 纸角相让：纸与镜互让一角 | CR:1101 |
| Clipboard | 回形针别住左上角 | CR:1630 |
| Scissors | 展开、刃头圆钝 | CR:1295 |
| QuestionGroup | 连号题页 | CR:2306 |

### 通用与领域分开出稿（Owner 原则，CR:294）

> 「公认通用符号以微调为主；有语义依据的领域图标允许改变构图做特色。」

- **通用符号**（勾、叉、加、箭头、回转、下载、搜索、齿轮……）：隐喻不换，创新只在第三层。例外：一形多义要拆时，可以给拆出来的意思换隐喻。
- **领域图标**（卷、词、题组、讲评、听写……）：隐喻与构图都放开；取材优先老师桌上的实物（spec §1.4）。

## 第三层 · 一处轻力（微妙）

每枚只用**一种**力，用在**一处**。力是静止的姿态，不是动画（principles §5「静态的生动不推导出添加动画」）。

| 力 | Owner 采用过的例子 | 给人的感觉 |
| --- | --- | --- |
| **收** | 箭翼轻收、谷口轻收、纸带轻收、短尾轻收、肩线轻收、盾身轻收、纸页轻收 | 利落、不拖沓 |
| **展** | 叉号轻展、勾形轻展、加号舒展、向外轻撑、同拱轻开、齿距轻开、下窗轻展 | 舒展、有呼吸 |
| **提** | 重心轻提、锁梁轻提、分类耳轻抬、铃舌轻提、腰线轻提、浅托轻举、折口轻提 | 有精神 |
| **落 / 托 / 压** | 纸尾微垂、钩尾轻落、加号轻落、弧底轻托、上撑下托、压住、短钉轻扣 | 有重量，像真东西 |
| **让** | 点画相让、纸角相让、留出一角、并肩轻错、轻叠成面 | 部件间靠留白分前后 |

**读法上的诚实说明**：这些名字是当时出稿的 agent 起的，Owner 在其中选择，所以「轻」的比例有一部分来自当时给出的候选。Owner 授权大改时也选了大改（Link「全部改头换面」、Headphones n2、Clipboard 回形针）。
因此：**五种力是画法，不是改动幅度的上限**；改多大由这一枚的语义需要决定。

16px 下力可以变弱，但不得因此糊、黑或认不出（spec §4.3）。评审以 16px 小样为准。

## 不做（Owner 否决过的方向）

| 不做 | 证据 |
| --- | --- |
| 只剩抽象关系、没有可认的对象 | 长难句 A/B/C「太抽象了，太不明了」CR:2351；相似篇章 D/E/F「语义都不鲜明」CR:1010 |

| 像本套另一枚或引起错误联想 | 相似篇章「很像复制」CR:1000；耳廓「问号联想」CR:749 |
| 太过；修联想把本体修丢 | F2「现在又太过了」CR:896；E+「反而不像耳朵」CR:749 |
| 题型做图标 | 「题型不搞图标」CR:2191 |

| 笔法上的「大胆」（抖动、不规则曲线、粗细变化） | G8 |

## 本轮授权与流程（2026-11-02）

- **重开全部**：Owner 要求每一枚出若干变体逐一选定，并「充满创意」。这覆盖 119 枚已选定稿的「不再改形」，但**每张画板第一个选项永远是「保留现版」，默认保留**；变体须明显更好才换。
- **顺序**：按用量（`usage.md`），先做有产品调用的约 60 枚；题型 6 枚不做。
- **每枚画板**：保留现版 + 6 个变体，每个写明「隐喻 + 力」与适用意思；都放进真实控件里看（16px 按钮、24px 圆钮），附 16 / 24px 小样。
- **全家福**：画布上常驻一块，已选定的排成一行，16px 配真实文字。每选一枚放进去，在一整排里看。
- **每 10 枚整组校准一次**：只调参数，不换已选的形（参照 CR:2426）。
- **Owner 选择时自问**：去掉文字还认得出吗？放进全家福是不是最跳的那个？它的「新」在意思上，还是只在笔法上？
- **署名**：借自 Solar（CC BY 4.0）的 15 枚通用图标，改到不再使用 Solar 路径时，同步更新 `../icon-system-2026-09-15/ATTRIBUTION.md`。
