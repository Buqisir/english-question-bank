## 一句话

> **像老师用一支圆头笔，在纸上画出的熟悉东西：骨架认得出，隐喻取自老师桌上的真实动作，每枚只有一处轻力。**

三层，从下往上判定；下一层不过，上一层不看。

| 层 | 管什么 | 谁来守 |
| --- | --- | --- |
| **骨架**（语法） | 全套必须一样：笔、个头、角、呼吸、繁简、视角、强调态 | Agent 出稿前自检，机器量 |
| **隐喻**（创新） | 画什么：选哪个真实动作或瞬间 | Owner 选 |
| **一处轻力**（微妙） | 怎么画那一笔：收、展、提、落、让 | Owner 选 |

### 通用与领域分开出稿（Owner 原则，CR:294）

> 「公认通用符号以微调为主；有语义依据的领域图标允许改变构图做特色。」

- **通用符号**（勾、叉、加、箭头、回转、下载、搜索、齿轮……）：隐喻不换，创新只在第三层。例外：一形多义要拆时，可以给拆出来的意思换隐喻。
- **领域图标**（卷、词、题组、讲评、听写……）：隐喻与构图都放开；取材优先老师桌上的实物（spec §1.4）。

## 第三层 · 一处轻力（微妙）

每枚只用**一种**力，用在**一处**。力是静止的姿态，不是动画（principles §5「静态的生动不推导出添加动画」）。

| 力 | Owner 采用过的例子 | 给人的感觉 |
| --- | --- | --- |
| **收** | 箭翼轻收、谷口轻收、纸带轻收、短尾轻收、肩线轻收、盾身轻收、纸页轻收 | 利落、不拖沓 |
| **展** | 叉号轻展、勾形轻展、加号舒展、向外轻撑、同拱轻开、齿距轻开、下窗轻展 | 舒展、有呼吸 |
| **提** | 重心轻提、锁梁轻提、分类耳轻抬、铃舌轻提、腰线轻提、浅托轻举、折口轻提 | 有精神 |
| **落 / 托 / 压** | 纸尾微垂、钩尾轻落、加号轻落、弧底轻托、上撑下托、压住、短钉轻扣 | 有重量，像真东西 |
| **让** | 点画相让、纸角相让、留出一角、并肩轻错、轻叠成面 | 部件间靠留白分前后。其中「前后遮挡就断开」已升为全套规则 G9 |

**读法上的诚实说明**：这些名字是当时出稿的 agent 起的，Owner 在其中选择，所以「轻」的比例有一部分来自当时给出的候选。Owner 授权大改时也选了大改（Link「全部改头换面」、Headphones n2、Clipboard 回形针）。
因此：**五种力是画法，不是改动幅度的上限**；改多大由这一枚的语义需要决定。

16px 下力可以变弱，但不得因此糊、黑或认不出（spec §4.3）。评审以 16px 小样为准。

## 本轮授权与流程（2026-11-02）

**流程更新（Owner 2026-11-02 晚）**：不再逐枚出大量变体，也不再出整套新方向。以现版为底，按家族分组，每组一页：先自动套用 G2（看起来一样大）与 G9（前后留缝），再只提少量微调建议，Owner 整组确认。下面「每枚画板」「全家福」两条暂停。

**第 1 组「纸与卷」已写入（Owner 2026-11-02）**：G2 收小 10 枚（卷家族与分页 0.972，题组、文档、查文件、表格 0.935，见 `icons-v3.mjs` 的 `G2` 表）；相似篇章改成一长一短两道波纹，修正 G4 净空（0.97 → 1.6）；采用「同一支笔」，卷内细节去掉局部细线，与外框同重（「卷」第二行收到 x=12.6）。草稿卷选「竖纸 B1+」：纸用卷的竖比例，右上角落在笔轴上，纸边在笔前等距断开，纸内一行写到笔尖，按修订后的 G2 放到同档（×1.039）。任务板选 A「夹板两行」：与单词复习同一块板和顶夹，板 + 两行 = 任务，取代回形针别角（第二层隐喻表里的 Clipboard 回形针一行就此作废）。

**第 2 组「文件与收纳」已写入（Owner 2026-11-02）**：G2 调个头：复制 ×0.918（前纸卷边沿弧收短，守 1.5 缝），删除 ×1.044 并下移 0.5，下载不动。打印选 P2「上下对称三段」：上进纸、机身、下出纸，出纸口算部件相接，不算 G9 遮挡（修正了尾角圆弧方向）。另存为选 S1「舒展」：仍用通用软盘（通用表意「存」），只把比例放舒展；EQB 里另存为 = 弹出系统存储对话框，区别于下载（默认目录）和保存到个人空间（应用内）。采用「同一支笔」：保存细节、打印纸、复制都跟随尺寸档，复制去掉固定 2.25。上传与下载成对：用同一个托盘，箭头朝上。

文件夹语法（新增家族部件）：**合着 = 一个东西；前片倒下 = 打开；合着 + 加号 = 新建；个人空间 = 公文包**。文件夹选矮台阶耳；打开的文件夹选 O3：前片斜边接到后片左边，在折轴处相接，不留断头；新建文件夹选 N1：合着的文件夹 + 居中加号；个人空间选 M2 公文包，不再用文件夹加横线。

**第 3 组「词与阅读」已写入（Owner 2026-11-02）**：G2 放大偏小的：生词本 ×1.018、打开的书 ×1.056、阅读理解篇章 ×1.045，笔记本与单词卡落在 334–340 同档。单词卡选 K2「横卡」：一张横卡 + 实心 A，宽高比收到 1.2（由此在 G2 加「横形宽高比 ≤ 1.2」）。过生词重新解构，选 G1「收下」：实心 A 落进下载 / 上传同一个托盘，意思是「这个词我收下了」，取代「圈出一词」。翻译选 Y2a：借通用「文 A」，用 EQB 的笔重画；「文」的撇、捺都从横上挂下，不留断点；A 用描线，与「词」的实心 A 区分。笔记本选 N2「两环」：两个线圈 + 两行，去掉多余线圈，与日期类图标的顶环分开。句子分析的括号改用「同一支笔」，去掉固定线宽。
