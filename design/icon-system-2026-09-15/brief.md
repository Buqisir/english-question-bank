## 0. 一句话（第二版，2026-09-15 修订）

第一版（`icons.mjs`）只是把 Lucide 加粗加圆，胖靠描边换来，清爽跟着掉，Owner 否决。
第二版（`icons-v2.mjs`）改成三条：

1. **胖在形体，不胖在描边。** 描边维持 2.25（16px 时 1.5px，与站内 14px/500 中文竖笔同重），
   胖来自封闭圆角轮廓 + 删掉内部细节线 + 两笔净空 ≥ 2 单位。16 级每个字形 ≤ 2 形 + ≤ 1 点，不用虚线。
2. **卷面原语是字母表。** 领域图标不借通用隐喻，只用教师每天看的五样拼：正文行、药丸空、折角纸、插入号、点。
   「一张卷」家族（卷 / 学生版 / 教师版 / 草稿卷）共用折角纸，只换里面的标记；
   完形 = 行首短药丸空，七选五 = 整行长药丸空，语法填空 = 药丸空里有点（给了提示词），阅读 = 正文 + 被选中的点，续写 = 正文断在半途、笔接着写。
3. **一个点承担全部「可爱」。** 全套只有一种 r 1.75 实心点：省略号、瞳孔、齿轮心、书签、打印机灯、选中的选项、导航「你在这里」。它是家族标记；拿掉它就是普通线稿。

融进桌面的两个具体做法：填充态可直接用 `--desk-hover`（图标像从同一张纸裁下来）；激活导航用点标位置，不整块变色。

## 1. 参照与边界

看过的开源集：MingCute（Apache-2.0，线/面双套，最全）、Hugeicons、Remix、Phosphor（六种粗细）、RuneIcons（Apache-2.0，24 网格 2px 圆头，WIP，无 npm 包）。
参照 Amp 的四张截图：图标是配角，灰、细、只出现在需要指向的地方；我们借它的**克制和位置感**，不借它的细线（细线在 CJK 旁边偏弱）。

必须遵守的既有约束（`PRODUCT.md`、`DESIGN.md §1`）：

- 反参照：不卡通、不糖果色、不过大圆角、不像「幼稚教育 App」。
  → 「可爱」通过**圆头、实心点、饱满外形**实现，不通过夸张比例或表情化。
- Ink-Action：黑色填充只给短控件 / 图标控件。图标本身默认 `currentColor`，不自带颜色。
- 题型六色保留、只在篇章层出现、不当装饰。→ 六色只用于题型图标，且限于「线 + 淡底」两态。
- No-Emoji-Icon：所有图标为正式 SVG。

## 2. 几何规范（提案）

| 项 | 值 | 说明 |
| --- | --- | --- |
| 画布 | 24 × 24 | 与 Lucide 同网格，便于逐个替换 |
| 活动区 | 2.5 – 21.5（19 单位） | 比 Lucide 的 2–22 略收，留给粗描边 |
| 描边 | **2.25**（默认）；`--icon-stroke` 可调 1.75–2.5 | 第一轮试过 2 + 活动区 3–21，视觉上比 Lucide 更瘦，否决 |
| 端点/拐角 | round / round | |
| 外圆角 | ≈3（矩形轮廓）、内圆角 ≈1.5 | 「胖」主要来自这里，不来自更大的形体 |
| 小细节 | 实心点 r=1.5（省略号、齿轮中心、书签点） | 小尺寸下比空心更清晰，也是「可爱」的来源 |
| 视觉中心 | 略高于几何中心（y 偏 −0.25） | 与 CJK 字面配合 |
| 变体 | `line`；`fill` = 同色 16% 不透明度底形 + 线 | 不做纯实心套；纯实心与「安静」冲突 |
| 尺寸令牌 | 16（行内/导航，**替代现有 14**）、20（工具栏）、24（独立按钮）、40（空态） | 12 仅用于密集表格且需专门缩放版 |
| 颜色 | `currentColor`；激活导航用 `fill` + `--identity #2C6E56` | 六色只给题型图标 |

`sheet.html §4` 有 12–40 尺寸阶梯与 1.6–2.5 描边阶梯，可直接肉眼比。

## 3. 词表分层（可持续扩展）

A. **通用替换层**（约 55 个，覆盖当前 `lucide-react` 全部引用）
Check、X、Plus、ChevronDown/Up/Right、ArrowLeft、Search、Settings、Trash、Save、Eye、Printer、Download、Play、Volume、RotateCcw、Ellipsis、Pencil、Sparkles……
一一对应 Lucide 名称，接口相同，可逐文件替换。

B. **领域层**（EQB 独有，是这套图标的辨识度所在）
- 题型六个：阅读（开本书）、完形（行 + 空框）、七选五（虚线槽）、语法填空（括号 + 点）、应用文（信封）、读后续写（行 + 笔）。样本见 `sheet.html §3`。
- 结构层：卷 / 篇章 / 题组 / 题 / 卷集；来源（Source）。
- 版本：学生版（无答案）/ 教师版（含答案与讲评）。
- 工作流：草稿卷、组卷、讲评、相似题、过生词、导出（打印 / PDF）。

C. **预留层**（不画，先占名）：其他学科、Agent/导题状态、评审流。

命名：kebab-case，前缀 `eqb-`；A 层沿用 Lucide 名（`eqb-check`），B 层用领域名（`eqb-type-cloze`、`eqb-paper-teacher`）。

## 4. 生产管线（提案）

```
Figma 源文件（单一事实）
  → REST 导出 SVG（按 node id；Figma PAT 存 Amp Secrets，不进聊天/仓库）
  → svgo（去 fill、统一 stroke="currentColor"、保留 viewBox）
  → 代码生成：app/src/icons/*.tsx（size / strokeWidth / variant 属性，镜像 lucide-react 签名）
  → sheet 回归页（同页对照 Lucide，防漂移）
```

- 在 Figma 建组件属性 `variant=line|fill`，导出时自动生成两态。
- 组件运行时用 `--icon-stroke` 变量，Deadpan 等主题可整体调密度。
- 无障碍：装饰图标 `aria-hidden`；图标按钮必须有可见或 `aria-label` 文案（现有代码已基本如此）。

Owner 的 Figma 会员**现在不必要**，进入 B 层批量绘制和管线搭建时需要：一个只读 Personal Access Token（放 Amp Secrets），加一个共享文件链接。

## 8. 同时发现的 UI 问题（不在本任务修，记为后续）
