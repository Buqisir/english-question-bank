## 怎么组成的

- 原图是**一株**、竖长、透明底、贴边裁，viewBox `31.6 5.4 26.64 71.4`（宽高比 0.373）。新图照这几样：一株，透明底，画框宽高比也是 26.64 : 71.4，茎根贴画框下沿。所以引用它的地方（固定 45×122 的框、只给高的 `<img>`）不用改。
- 一株由三段定稿 `mascot/objects/kelp-blade.svg`（巨藻一段，第七轮 B）沿一根茎往上接成：

  | 从下往上 | 用的什么 | 等比缩放 | 转动 |
  | --- | --- | --- | --- |
  | 第一段 | 整段 kelp-blade | 1 | 逆时针 6° |
  | 接茎 | kelp-blade 自己的那根茎（只取茎那条路径） | 0.95 | 逆时针 30° |
  | 第二段 | 整段 kelp-blade | 0.86 | 逆时针 10° |
  | 接茎 | 同上 | 0.8 | 逆时针 30° |
  | 第三段 | 整段 kelp-blade | 0.72 | 逆时针 12° |

  每一块的茎下端接在上一块的茎上端。往上一段比一段小，整株往上收。
- 叶形、气囊、中脉、颜色全是定稿的路径原样搬进 `<defs>`，用 `<use>` 引用，每块只有平移、转动、等比缩放，一笔没改。接茎没有新画的形，用的是定稿里那根茎。
- 九片叶都朝右顺水飘（第 112 条「朝一侧飘」）。
- 颜色只有定稿里的两个：深薄荷 `#2C6E56`（茎、气囊、叶）、浅雾薄荷 `#DDF1E8`（中脉）。任务说明里提到的雾薄荷，定稿巨藻里没有，没用。
- 文件从约 2.6KB 变成约 27KB（定稿路径点多）。

试过、没用的排法（都看过图，目测）：
1. 两段直接摞、中间短接茎：上一段最上面那片叶和下一段最下面那片叶挤在一起，看不出分段，高度也只占画框的 2/3。
2. 三段都转 24° 以上、让叶往上竖：画框填满了，但九片叶密密地排成一列，像麦穗或松枝。
3. 最底下先放一截光茎再接叶：茎根是一截光秃秃的断头，比现在气囊落地还怪。

## 和 house-rules 逐条对过

| 条 | 结果 |
| --- | --- |
| 一、颜色只用表里的 | 过。只有深薄荷、浅雾薄荷，正是表里给巨藻的两色（第 110 条） |
| 二、平涂；无描边、渐变、纹理、阴影；不画脸 | 过 |
| 二·1 主体色加一块次色，最多三色 | 过。两色 |
| 二·2 次色不碰外轮廓 | 过（目测，480px 下三段的叶互不相压，中脉都在叶里）。但离外沿的距离跟着缩：见下面毛病第 1 条 |
| 二·3 形状少而圆；最细处 48 像素下不小于 2 像素 | **不过**。单段在 48px 下是过的；拼成一株以后，每段在画框里只占约 1/3 高，原用途尺寸下最细处都不够，见毛病第 1 条 |
| 二·4 到 二·7（石头、脸、气泡、全身像） | 不涉及 |
| 三、直接放在页面上，不加影子、描边、垫色块 | 过。透明底，白底和 #F1F5F7 上都只靠深薄荷剪影立住（目测） |

## 自己看图后觉得不好的地方

1. **小尺寸像描边线稿**（最大的问题）。64px 高时叶边的深色只剩约 0.65px、中脉约 0.9px、茎约 0.7px；122px 高时约 1.2 到 1.7px（几何换算，按定稿 48px 下的量数折算，没渲染后量）。结果 64px 下整株读成一串空心叶的描边画，正是第六、七轮一直在躲的「深色圈里一块浅色」。旧图是实心一色，64px 下反而更清楚（目测）。要守住，得给小尺寸另画一张去掉中脉的简化版，或者只放一到两段——这都超出「叶形不改」的范围，等 Owner 定。
2. **三段一模一样，像盖章**。只差大小和几度的转动，三组「三片叶」节奏完全重复（目测）。
3. **叶太多**。旧图五片叶，新图九片，480px 下还行，122px 下叶挤成锯齿边（目测）。
4. **没有固着器**。最底下是定稿那个落在茎根上的气囊，像根结（第七轮 README 已经提过），整株看起来是插在地上，不是长在石头上（目测）。旧图有固着器。
5. **整株偏在画框左边**。叶都朝右，茎贴左，画框是照外框居中补宽的，所以左边有一条空白（目测）。放在手册那格里会显得近景往左偏一点。
6. **接茎处略有折角**。接茎和段的转角差 18° 到 24°，接缝在气囊下面，大尺寸能看到茎在气囊上方拐一下（目测）。
7. **没有远景、深水两个变体**。旧规则里巨藻远景整株换浅色、深水里换雾薄荷（§3.4），新画法有次色，没法「整株换一色」，这两个变体这次没做。
8. 体量和颜色仍是全套最重的一样（第七轮的保留意见照旧）。
