# 生态物件 · 第一轮矢量稿（2026-11-14）

状态：对比稿，**提案 · 单一来源**。下面除了标「Owner 原话」和「BRAND.md 已定」的，全是 agent 的提案，没有一条是「已定」。母版、`mascot/`、`illustration/`、`logo/`、BRAND.md 和网站代码都没改。

## 从哪来

- Owner 对品牌形象的三条要求：「形象要够成熟，平易近人，丰富生态」。「丰富生态」Owner 说两件都要：獭獭周围的世界更丰富，素材的种类也更多（`../brief.md`）。2026-11-14 又说：「可以扩大生态」。
- `../brief.md` 第 4 点：生态当成一套系统做，列出有哪几样东西、各代表什么、谁是道具谁是角色、相互大小、各在哪些界面出现，数量有上限。
- 第一批草图的结论（`../sketches-batch1/README.md`）：物件以 E3 为底，只用品牌色、都没有脸；海胆减重，石头去花纹；场景取 E2 的安静留白和 E4 的平涂。这一轮只做物件，不做场景。
- 画法照现有矢量（`mascot/otter-head.svg`、`illustration/kelp.svg`、`mascot/props/`）：纯平涂、无描边、无渐变，圆润的几何形。

### 3. 谁是道具，谁是角色

- **只有獭獭有脸。** 别的一律没有眼睛、没有脸、没有表情，也不能被画成在「看」或「说话」。
- 物件不算「一只」，所以同一屏里獭獭加几样物件不破「一屏一只」（BRAND.md §4.7）；但一屏里物件最多 3 样，免得变成贴纸墙（提案）。
- 物件不当底纹、不铺满、不重复排列（BRAND.md §1.6「界面不加品牌花纹」）。

### 7. 画法规矩

- 纯平涂，无描边、无渐变、无阴影、无高光，透明底。
- 每样由 1 到 4 块圆润的几何形拼成；转角都是圆的，刺和臂的尖也是圆头。
- 细节密度一致：每样最多一层「里面的浅色」（蛤一圈生长纹、扇贝四道肋、敲开的蛤一道里层），石头、海胆、海星、气泡没有里层。
- 剪影先要成立：转成单一墨色时只靠轮廓也要认得出（`mono.png`），浅色细节只是加分。
- 48px 贴边裁还认得出（`sheet.png` 每样第三格）。
- 手写路径，坐标取整到 0.5。

## 三、自查和返工（目测）

第一轮出图以后改了三轮：

1. **第一次**：巨藻叶是一片细长尖叶接一根细柄，像一根羽毛；蛤是一个圆顶加一道横带，像一个馒头或头盔；石头 B 像饭团。改：巨藻叶加了竖着的主茎、圆头、叶边起伏；蛤换成壳顶偏左的圆三角，生长纹改成顺着壳边的一圈（同一外形缩 0.8 和 0.7 叠出来）；石头 B 改成顶往左歪、右下最胖。
2. **第二次**：放在獭獭旁边看，石头偏大、偏重（獭獭的石头 0.5 像半张脸）；蛤的剪影没有壳顶，单色时像一个土丘。改：四块石头整体缩小 8% 到 16%；蛤加了一个往左勾的壳顶小尖；獭獭的石头左边的平面收软一点。
3. **第三次**：巨藻主茎太长，贴边裁以后整张变成一根细杆，叶子只占一小角。改：主茎只画到气囊上面一点。

  - §3.4「巨藻……不画气囊和叶脉」：巨藻叶带气囊画了气囊。

## 六、要 Owner 定的问题

1. **石头和海胆用墨，能不能接受？** 墨是 BRAND.md 里石子已有的颜色，但一排墨色石头比薄荷色的贝类重得多。另一条路是给石头在雾薄荷色阶上加一档中灰绿，那要先写进 §1.5 再用。
2. **§3.4 那两条要不要为生态松开？** 一是石头从「只在状态插画里」扩到空态和装饰；二是巨藻可以画气囊。
3. **第二节那张「代表什么」的表，要不要进界面？** 比如组卷、导出完成那一屏出现敲开的蛤。还是这些意思只留在品牌故事和装饰里？
4. **「獭獭自己的那块石头」要不要一个单独认得出的记号？** 不加花纹的前提下，现在只靠一面略平，单独看认不出是「它的」。可选的是固定形状加固定出场方式（永远在獭獭爪里或身边），不靠记号。
5. **海星和海胆留不留？** 海星和界面里的收藏五角星有撞的风险；海胆容易被读成「危险、出错」。
