# 生态物件 · 第七轮：巨藻一段重画（对比稿 · 提案 · 单一来源 · 2026-11-14）

这一轮只重画巨藻一段，别的物件没动。

第六轮的 k1、k2 没过复核，原因有三条：
- 叶子是「深色圈里一块浅色」，读成描边的环。
- 整体像一根带叶的小树枝或橄榄枝。
- 气囊是小圈。

这一轮照真的巨藻（Macrocystis）重画：一根略弯的茎，三片长的宽飘带叶都顺着水流往同一侧飘，每片叶的根部有一个水滴形气囊接在茎上。

## 两个候选

两个候选共用下面这些画法：

- **茎**：一根略呈 S 形的深薄荷实心带，下面略粗。
- **叶**：三片，都长在茎的右边，顺着水流往右上飘。
  - 每片叶的中线有一道缓的 S 波，叶边有小波。叶根和叶尖处的小波收掉，免得起疙瘩。
  - 叶根收成颈，往上很快宽到最宽，中段一直保持宽，再往叶尖慢慢收成圆头。
  - 三片叶的方向从下往上依次抬高：最下面一片几乎水平，最上面一片斜着往上。三片叶不平行，也不像左右张开的树枝。
- **气囊**：水滴形，圆头压在茎上，尖头接着叶根。从茎到叶依次是茎、气囊、叶。
- **画框**：240 = 獭獭头宽，物件整体等比缩放后居中，画框约定和前几轮一样。
- **配色和画法**：只用深薄荷 #2C6E56 和浅雾薄荷 #DDF1E8。没有描边、渐变、阴影。

**候选 A（浅色气囊）**
- 叶和茎全是深薄荷实心。
- 气囊整个是一块浅雾薄荷的实心水滴，外面留一圈深薄荷。浅色水滴是把气囊外形往里收出来的，所以那圈深色各处一样厚。
- 浅色要占到 15%，气囊得画大（48px 下约 11px 宽），叶也比 B 短一点。

**候选 B（浅色中脉，推荐）**
- 气囊是深薄荷实心水滴。
- 每片叶中间一条浅雾薄荷中脉带，顺着叶中线走。中脉从叶根的颈往上一点开始，到叶尖前停住，两头圆。
- 中脉宽度封顶，比两边的深色略宽，所以读成叶脉，不读成叶里挖出的洞。

## 自审记录

每版都用 Read 看了图。

1. **第一版**：叶从竖直的茎往右上斜，和茎成三十多度角，叶尖收细。
   - 三片叶挨在一起，连成一片，剪影像一扇翅膀或一根羽毛。
   - 上面的叶超出了画框。
2. **第二版**：叶改成几乎水平地往右飘、往下垂。
   - 三条平行的横带，像字母 E 或一把梳子。
   - 气囊太小，看不出来。
3. **第三到第五版**：试了几种排法。
   - 叶顺着茎往上飘：叶和茎贴在一起，剪影成一根棍。
   - 整根往右斜着飘：像一片羽毛。
   - 叶左右交替、都往右弯：又回到小树枝的样子。
   - 最后定成「茎略呈 S、三片叶从下往上一片比一片抬高、每片叶中线带一道 S 波」。
   - 叶和叶之间的空隙大约是「茎上相邻两个气囊的距离 × 叶与茎夹角的正弦 − 叶宽」。照这个思路把叶放平一些、和茎拉开角度，叶不再连成一片（目测）。
4. **第六版**：加了自动放进画框的步骤（等比缩放不改量数），叶加宽。
   - B 的中脉太宽，深色边只剩一圈，又像第六轮那种描边的环。把中脉宽度封顶，深色边留宽一点。
   - A 的浅色水滴原来是另画一个小一号的水滴，离外沿最近处只有 1.7px，深色那圈在开运算里被抹掉 20%。改成把气囊外形往里收出浅色，深色圈各处一样厚，再加大气囊。
5. **第七版**：放大到 320px 看。
   - 叶尖有一个小球，像火柴头。原因是叶边的小波一直延到叶尖。改成小波在叶尖前收掉、叶尖收成圆头的窄尖。
   - A 的叶短，小波看着像一串疙瘩，把小波减少。
6. **第八版**：试了「叶更宽、中脉更窄」，想让 B 的深色边更厚。
   - 浅色占比掉到 13% 到 14%，不够 15%。
   - 叶加宽以后，叶和叶之间的空隙变窄，48px 剪影糊成一团。
   - 没采用，回到第七版。
7. **放进全套看**（`compare.png` 下面两组）：
   - B 的剪影是一根茎带三条往右上飘的波浪带，叶根有鼓包，读成海藻，不像麦穗（麦穗是两边对称的粒）。目测。
   - A 的气囊在 48px 下读成三个小圈。目测。

## 推荐 B 的理由

- 48px 剪影里，B 的叶更宽更长，气囊是深色鼓包，整体最像一丛顺水飘的巨藻。目测。
- A 想让浅色到 15%，气囊得画得比叶还宽。结果整体重心在三个大气囊上，48px 下浅色水滴加深色圈仍然读成小圈，正好是第六轮被退回的那一条。目测。
- B 的中脉和合着的蛤、扇贝的浅色纹是同一种「主体上一条次色带」的画法，放在一排里密度接近。目测。

## 还不好的地方

- **B 仍是「深色里一条浅色」**：中脉比第六轮窄得多，也不贴着叶根和叶尖，但 48px 彩色图里还是带一点描边感，深色边约 2.1px，中脉约 3px。目测。想让深色边更厚又要保住 15%，只能加宽叶，这样叶和叶之间就挤了（第八版）。
- **剪影有一点像一只张开的手或一把耙子**：三片叶都往右，叶尖圆。目测。比第六轮的小树枝好，但不算完全解决。
- **最下面的气囊压在茎的最底端**，像一个根结，没有画固着器。目测。
- **A 的叶短、气囊大**，整体像豆荚或一串珠子，不太像巨藻。目测。
- **体量偏大**：巨藻在全套里还是最大、最深的一样。和第六轮一样，没改。
