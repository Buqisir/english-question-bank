## 做法

1. **变换**：两眼圆心（睁眼的取圆心；01 空闲的眼睛画成路径，取面积中心；04 闭眼取弧线外框中心）定出相似变换：缩放 = 两眼间距 ÷ 345.7，角度 = 两眼连线角度，两眼中点对母版 (512, 375.5)。
2. **眼睛**：rx、ry（或圆的 r，或路径整体绕自己的中心）×1.16；圆心按变换外移 3.05、上移 4.25（母版坐标乘缩放、按角度转）。
3. **脸斑**：七张图的脸斑路径都和母版对不上一一对应——母版每瓣下沿只有「最宽处 → 瓣底 → 缺口」三个锚点，这七张有的多一个外下角锚点（03、05、登录页），有的右瓣没有瓣底锚点（全身、01、02、04），锚点位置也各不相同。所以没有逐点照抄，而是把母版「旧脸斑 → F」每个控制点的位移（缺口和缺口把手上提 30；瓣底和它内侧把手内收 12、上提 2.5；瓣底外侧把手内收 25.5、上提 2.5；最宽处下把手上提 16.5，即外下把手变短；上沿和两侧位移 0）做成一张位移表，在母版坐标里按距离平方反比插值到这张图脸斑下沿每个锚点和把手上，再换回图里坐标。附加约束：
   - 只动下沿那几段（两侧最宽处之间）；上沿、两侧锚点和它们的上把手一个数不动；两侧锚点的下把手只沿原方向伸缩。
   - 下沿中间原来圆滑的锚点，两个把手一起转同一个角度，保住圆滑；缺口尖（原来就是尖的）不做这一步。
   - 结果：七张的缺口都只在中间这个尖上，没有新出的尖角；03、05、登录页左右对称（原图对称的地方仍对称）。
4. **两种做法比过**：before-after 第四格是「母版 F 脸斑整条按变换放过去」。它会把这几张图各自的脸斑上沿和两侧也换掉（仰躺的四张原来脸斑右瓣更大、缺口偏左，整条换掉以后缺口跑到正中、轮廓变成母版的样子，和这张图的头型、鼻子位置不搭），所以七张都采用第 3 条的做法（目测）。
