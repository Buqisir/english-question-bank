## 一、敲开的蛤：侧面半开

### 怎么画的

两个候选用同一只蛤，都是正侧面看：
- **下片**：一只浅碗平放，露外面。外面是雾薄荷，带两道浅雾薄荷生长纹。
  - 生长纹和合着的蛤是同一种画法：同一外形缩放成环。
  - 缩放中心挪到壳顶右边一点。纹的两头藏在铰合点的小圆下面，上端用同色的唇盖住，所以纹不碰外轮廓。
- **上片**：和下片同一个外形。在左边的铰合点连着，往上掀开约 42°，像掀开的盒盖。
  - 掀开后看到的是它的里面，用雾白，四周留雾薄荷边。
  - house-rules 第一节规定雾白用于贝壳的里面，所以里面不再用浅雾薄荷。
- **宽度**：0.53 头宽，和合着的蛤一样。

两个候选的差别：
- **候选 a · 不带石砧（推荐）**：就是一只半开的蛤。三色：雾薄荷、浅雾薄荷、雾白。
- **候选 b · 垫石砧**：同 a，下片底下垫一块扁扁的石色石砧，左右各比壳宽出约 12。

### 剪影对着三样查（48px，目测）

- **吃豆人**：吃豆人是一个整圆切掉一个楔，楔尖在圆心。这只蛤的楔尖在最左边的铰合点，上下两片都是扁的弧形，合起来不是圆。剪影读成张开的贝或夹子，不读成吃豆人。
- **嘴巴卡通**：卡通嘴是正面看的弯月或 D 形，常有舌头和牙。这里是侧面，铰合点在一端，上片是一整片硬壳。不像嘴。
- **汉堡**：汉堡是上下平行叠的几层。候选 a 只有两片，上片斜着掀开约 42°，不是平叠，不像汉堡。
  - 候选 b 多了一层石砧，下片和石砧在剪影里是平行两层，加上上片，有一点汉堡感。

### 推荐 a，理由

1. **读得出是「张开的贝」**（目测）。和合着的蛤并排，能看出是同一种壳打开了。
2. **剪影最干净**（目测）。只有两片加一道楔形开口，没有汉堡风险。
3. **颜色合规**。三色，合 house-rules 第二节第 1 条（最多三色）。
   - 候选 b 加上石砧是四色。
   - 而且 b 的石砧没有石面顶面：顶面会被壳挡住，加了也看不见。这和第 4 条「石头只有一种画法」有出入。
4. **最细处合规**。候选 a 每块面在 48px 贴边裁下都不窄于 2px；次色面离外轮廓 2.1px，雾白离外轮廓 3.3px。
   - 候选 b 多了石砧，整体框变大，生长纹在 48px 下有 26% 的面窄于 2px。

要表现「在石头上敲开」时，可以把候选 a 放在任一块石头物件上，而不是把石砧画进蛤里。

## 三、对照 house-rules.md 查全套

### 怎么查的

- **颜色**：读每个 SVG 里的 fill，并逐像素认色。
- **次色面离外轮廓**：从背景往里一层层扩，量到第一块次色面的距离，换算成 48px 贴边裁下的像素。
- **最细处**：每个颜色面和整个剪影都在 48px 贴边裁的 10 倍上做开运算，半径相当于 48px 下 1px。窄于 2px 的部分会被开运算抹掉，记被抹掉的面积占比。
  - 圆角和尖头本身也会被抹掉一点，所以占比在 6% 以下的只当边角，不算出入。

### 全套总览

全套都没有用表外的颜色。墨和石板墨都没出现在物件上。

| 物件 | 颜色 | 次色离外沿（48px） | 窄于 2px 的部分 |
| --- | --- | --- | --- |
| 獭獭的石头 | 石色、石面 | 0.1px（平切面贴边，见下） | 无 |
| 石头 · 扁长卵 | 石色、石面 | 1.9px | 顶面上方的石色边略窄（5%） |
| 石头 · 圆墩 | 石色、石面 | 2.0px | 无 |
| 石头 · 小扁片 | 石色、石面 | 1.2px | 顶面上方的石色边窄（6%） |
| 蛤（合着的） | 雾薄荷、浅雾薄荷 | 0.1px（纹在壳顶相交处贴边） | 生长纹 69% |
| 敲开的蛤（本轮 a） | 雾薄荷、浅雾薄荷、雾白 | 2.1px / 3.3px | 无 |
| 扇贝 | 雾薄荷、浅雾薄荷 | 3.1px | 肋间浅色缝 39% |
| 海胆（第三轮 L） | 石色、石面 | 0.7px | 无 |
| 巨藻一段 | 深薄荷、雾薄荷 | 0.1px（气囊长在叶边上） | 茎和叶尖 19%（剪影 11%） |
| 海星 | 雾薄荷、浅雾薄荷 | 4.0px | 无 |
| 一串气泡 | 雾薄荷、浅雾薄荷 | 0.6px | 无 |

### 有出入的，按条列

- **第一节，颜色只用在规定处**：巨藻的气囊用了雾薄荷。表里雾薄荷只用在獭獭、贝类、海星、气泡，巨藻规定用深薄荷，这一处有出入。
- **第二节第 1 条，次色不是高光**：
  - 气泡的浅色小点像高光，已知，照第 6 条先留着。
  - 石头的石面顶面是一块面，不是高光，没问题。
- **第二节第 2 条，次色面不碰外轮廓**：
  - 獭獭的石头：石面就是那一刀平切面，贴着外沿。这是第 4 条规定的，算有意的例外。
  - 合着的蛤：两道生长纹在壳顶相交，贴外沿。
  - 巨藻：气囊长在叶边上，贴外沿。
  - 海胆：石面顶面离外沿只有 0.7px，48px 下几乎贴边。
  - 一串气泡：浅色小点离外沿 0.6px，已知。
  - 石头 · 小扁片 1.2px、石头 · 扁长卵 1.9px：不贴，但留的边不到 2px。
- **第二节第 3 条，最细处 48px 下不小于 2px**：
  - 合着的蛤：生长纹太细。
  - 扇贝：肋间的浅色缝太细。
  - 巨藻：茎和叶尖太细。
  - 小扁片和扁长卵：顶面上方的石色边略窄，原因同上一条。
  - 海胆：刺按根宽 14、头宽 9 算，在 48px 下已合规。
- **第二节第 1 条，最多三色**：全套合规。只有不推荐的候选 b 是四色。

这一轮只改了敲开的蛤，上面这些旧物件都没动，只列出来。改不改、怎么改，等统一检查那一步再定。

## 自审记录（每轮都用 Read 看了图）

1. **上片露外面的版本**：
   - 上片和下片都画成唇里夹一条浅色里面。浅色里面太窄（48px 下不到 2px），上片的唇又往开口里鼓，把楔形开口挤没了。
   - 剪影成了一团，带一道缺口。
   - 右端还有一个尖头，不合「没有尖角」。
   - 改法：右端收圆。
2. **对照 house-rules**：
   - 里面改用雾白。
   - 上片改成露出里面（雾白，四周留雾薄荷边）；下片露外面，带生长纹。
   - 开口变成干净的楔形，剪影读成张开的贝。
   - 跑检查后发现生长纹在 48px 下 36% 窄于 2px，而且纹顶到了上沿。改法：碗加深到 40，纹和间隔各留到 48px 下 2px 以上；纹的上端用同色唇盖住，离上沿至少 6。
3. **出全套和对比图，一起看**：
   - 宽度从 0.58 缩到 0.53，和合着的蛤一样。
   - 剪影对吃豆人、嘴巴卡通、汉堡逐个查过，定 a。
   - 改色副本看了改前改后和放大，顶面位置和 U8 一致。
