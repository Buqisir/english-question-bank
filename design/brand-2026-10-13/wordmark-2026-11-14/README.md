`svg/` 的命名：`wordmark-<方向>[-large|-small]-<ink|reverse>.svg`（字标），`lockup-<h|v>-<方向>[-large|-small]-<ink|reverse>.svg`（横排 h、竖排 v 组合）。`ink` 是墨 `#191D18`；`reverse` 是雾白 `#F2FAF6` 字、透明底，放在墨或深薄荷底上用（单看文件是白底上的白字，看不见）。A、C 只有一档；B、D 分大档（>16px）和小档（≤16px）。

- 字标 SVG 的 viewBox 高 1000 = 一个字号（em 框），所以按 `height = 字号` 放，就和同字号的文字一样大。
- 组合 SVG 的 viewBox 贴着墨迹，没有留白；用的时候四周另留至少 ¼ 标志高（照 §3.1 图形标志的安全距离）。
- 组合里的图形标志是 `logo/mint/mark.svg` 原样（雾薄荷彩色版，路径一笔没改）。反白组合里标志仍用彩色版：§3.1 写明不做反白标志，墨底上用彩色版。
- 颜色只用了 BRAND.md §1.5 里已有的：墨 `#191D18`、雾白 `#F2FAF6`、深薄荷 `#2C6E56`（只当反白的底）、标志自带的雾薄荷 `#72BFA4`。示意图的浅底用了桌面色 `#E6EDF0`（DESIGN.md 08 雾海色阶，不在字标里）。

## 来源字体和授权

| 方向 | 字体 | 从哪来 | 版本 | 授权 |

| C | Noto Serif SC（思源宋体同一套字形），可变字体，字重轴 200–900 | npm 公共包 `@fontsource-variable/noto-serif-sc@5.3.1`（fontsource 元数据 v36，2026-10-01） | `Version 2.003-H1` | SIL OFL 1.1 |

- fontsource 把中文切成约 100 片 woff2，脚本按包里 `index.css` 的 unicode-range 找到含这个字的那一片：「獭」在第 55 片，「石」在第 115 片（两款字体都是）。
- 取轮廓用 fontTools 4.55.3（pip 公共包，带 brotli 1.1.0 解 woff2），按字重直接从可变字体里取实例，不经过本机字体。
- 字体文件、fontTools 都只装在临时目录，**没有进仓库**；仓库里只有导出的两个字的轮廓（在 SVG 里）。
- 字体里的版权行是「(c) 2014-2021 Adobe, with Reserved Font Name 'Source'」。OFL 管的是字体软件本身；拿字体排成图形（字标）不是分发字体，OFL 允许，也允许商用。D 改过轮廓，也是图形，不是改过的字体。保留字体名「Source」只限制改过的**字体**叫这个名字，和字标无关。字标要去注册商标时，用开源字体的字形做商标图样有没有问题，请商标代理人一起看（拿不准）。
- 仓库里原有的 `app/public/fonts/paper/source-han-serif/`（思源宋体 CN Regular、Bold，`Version 2.003`）和 C 是同一套字形设计，但只有两个静态字重，取不到 600，所以 C 用了 Noto Serif SC 可变字体。

## 四个方向怎么做的

所有方向：两个字各占一个 em（字宽 1000，字体自带的前进宽），按字体原样排，只在两字之间加字距（如有）。没有拉伸、加描边、加阴影。

| 方向 | 怎么做 | 参数 |
|---|---|---|
| **A 黑体直排**（基准） | Noto Sans SC 直接排，所有字号同一档 | wght 600（和网站顶栏、登录页现在的品牌字一样，实算 15px/600），字距 0 |
| **B 黑体分两档** | 大字和 A 一样；≤16px 换细一档、略放字距，让「獭」的笔画之间留出白 | 大档 >16px：wght 600，字距 0；小档 ≤16px：wght 400，字距 +60（6% 字号） |
| **C 宋体** | Noto Serif SC 直接排，所有字号同一档 | wght 600，字距 0 |
| **D 在 B 上给「獭」收细** | 只改「獭」右半边的「赖」，见下 | 大档 wght 600 / 「赖」550；小档 wght 400 / 「赖」350；字距同 B |

B 小档的 400 和 +60 是先在临时页面上排了 300–700 七档字重、0 / +60 / +120 三档字距，在 1x、2x 屏截图里比出来的（目测）：300 在 11px 太淡，「石」像要断；+120 两个字像分开的两个字；400 / +60 是这一轮看着最平衡的一组。

**D 改了什么（逐条）**：

1. Noto Sans SC 2.004 的「獭」由 16 个轮廓组成（脚本数出来），0–2 号是「犭」，3–15 号是「赖」（其中 3–8、12 号是「束」，9–11、13–15 号是「负」）。
2. D 把 3–15 号这 13 个轮廓，换成**同一字体**里轻 50 的字重下的同号轮廓：大档 600 → 550，小档 400 → 350。效果是「赖」的横竖笔都略收细，最密的「束」和「贝」里的白多一点。
3. 「犭」和「石」不动。字的外形、字宽、部件的位置都不动（可变字体不同字重的同号轮廓位置一致，只是笔画粗细不同）。
4. 没做的：没有手工挪任何点，没有把部件拉开、没有改「獭」的字宽、没有为单个像素网格对齐。这些要动笔画位置，这一轮没把握做得克制，**没做**。

脚本里写死了「獭」是 16 个轮廓（宋体 18 个）；字体版本一变、轮廓数对不上，脚本会停下报错，不会悄悄改错部件。

## 组合怎么排的

- **横排**：标志高 H；字号 0.75H；标志右边到字的墨迹左边 0.4H；字的墨迹和标志上下居中。比例取自现在的顶栏（标志 20px 高配 15px 字、间距 8px，§3.1「组合」）。
- **竖排**：标志在上；字的墨迹宽 = 0.9 倍标志宽；标志下沿到字的墨迹上沿 0.22H；水平居中。这一组比例是这次随手定的起点，没有比过别的（提案）。
- 小档组合（B、D 的 `-small`）用小档字形，用在横排标志 ≤ 约 21px 高（字 ≤16px）的地方，比如顶栏。

## 观察（全部目测，除注明「量」的以外）

- **A**：64px、32px 下扎实，和标志的分量相当。15px 下「獭」明显比「石」黑；11px 1x 屏上「獭」糊成一块，认得出是个字，部件分不清。和试穿图里看到的一样。
- **B**：小档在 15px 下「獭」右半边能分出几道白，整体比 A 淡一档，和顶栏右边的导航字分量接近；11px 1x 屏仍然灰成一片，但不再是一块黑。代价是「石」在小档里显得单薄。量出来的「獭 ÷ 石」反而从 1.42 升到 1.50：两个字都变细，「石」的笔画少，变细后掉得更多。所以 B 减的是「整体发黑」，不是「獭比石黑」。
- **C**：64px、32px 下最有书卷气，笔画有粗细对比，像印出来的书名，接得上宣传图的思源宋体标题。但同样 600，宋体整体比黑体轻（量：石 20.1% 对 35.5%），在顶栏里放在黑体导航字旁边显得发虚，不像「签名」。「獭 ÷ 石」是 2.00，四个方向里最大：宋体的「石」横细、留白多，「獭」挤在一起，小字号下一黑一白最明显。至少这一轮看，宋体在小尺寸里没有更有分量，反而让「獭」更突兀。
- **D**：15px 2x 屏上「獭」看着比 B 略清一点，右半边的白多一点，差别要并排才看得出；11px 1x 屏上和 B 几乎分不出来。64px 下「赖」比「犭」轻 50，正常阅读看不出粗细不一。量出来「獭 ÷ 石」从 1.50 降到 1.40，是四个方向里小档最低的。改动很小，作用也小。
- **所有 SVG 方向共有的问题**：1x 屏上 SVG 轮廓没有字体微调（hinting），竖横笔落在两个像素之间会发灰；「现状」一行是本机的文泉驿正黑实时文字，有微调，笔画对齐像素，在 1x 屏上反而最「实」，虽然字形更粗糙。也就是说，在 1x 屏的 11–15px，把字标做成 SVG 图片可能比直接写字更糊。2x 屏上没有这个问题。
- 顶栏、登录页里换上字标后，位置、行高和原来一样，没看到挤或错位。

## 推荐（提案，不是已定）

1. **界面里的小尺寸（≤16px）用 B 或 D 的小档**。D 比 B 好一点点但不明显（量出来獭 ÷ 石 1.40 对 1.50）；如果 Owner 觉得改字没必要，B 就够，少一层要维护的东西。我倾向 **D**，因为改法完全可逆、只用字体自己的字重，不碰字形。
2. **大尺寸（>16px，宣传、手册、开屏）用黑体 600（A = B 大档 = D 大档 几乎一样）**，和标志的分量对得上。
3. **宋体 C 不推荐当字标**：在小尺寸里加重了「獭」的突兀，在顶栏里发虚。宣传标题继续用思源宋体不受影响；字标是黑体、标题是宋体，两条字道各管一处，§3.3「字标定了以后回头看标题要不要跟着换」这一条可以答「不换」（提案）。
4. **11px 和 1x 屏的 15px 另做逐格版**：照图形标志 `mark-16` / `mark-32` 的办法，在像素网格上逐格画「獭石」（例如 11px、15px 两档），只按原尺寸显示；或者这两处继续写实时文字、不用图片。这一轮没做，是下一轮的建议。

## 这台机器的限制

- 没有 PingFang SC（`fc-list` 数出来 0 个），也没有 Paper Mono（0 个）。「现状」一行和网站里的中文都由文泉驿正黑显示，和老师在苹果设备上看到的字形、字重不同。字标 SVG 本身不受影响（是轮廓），但它旁边的导航字、登录页标题都是文泉驿正黑，比较「分量」时要记住这一点；要在 Mac 上再看一次。
- 截图是 Chromium 无头浏览器渲染的，1x 屏的抗锯齿和苹果、Windows 的系统渲染不完全一样。
- 手机图标那一格是示意，不是真机桌面。

## 重跑

```sh
# 字体和工具装在临时目录，不进仓库
TMP=$(mktemp -d)
npm install --prefix "$TMP" --ignore-scripts @fontsource-variable/noto-sans-sc@5.3.1 @fontsource-variable/noto-serif-sc@5.3.1
pip install --target "$TMP/pylib" fonttools==4.55.3 brotli==1.1.0
WORDMARK_FONTSOURCE_DIR="$TMP/node_modules" EQB_FONTTOOLS_PATH="$TMP/pylib" node scripts/brand/wordmark-drafts.mjs
# 只出 SVG：加 --svg-only；用已在跑的本地网站：加 --base http://127.0.0.1:端口
```

脚本每次先清掉本目录下的 `svg/` 再写（这个目录只放脚本的输出），然后覆盖 `compare.png`、`lockups.png`、`wordmark-run.json`。README 是手写的，脚本不碰。
