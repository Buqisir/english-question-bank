# 名字试穿 · 2026-11-14

BRAND.md §2「流程」里有一步：「每个做成字标草稿，放进顶栏、登录页、App 图标里看」。这里是这一步的拍照脚本和第一次跑出来的图。脚本可以反复用：给它几个名字，每个名字出一张试穿图，另出一张并排的总图。

这次只用「他石 / Tashi」做样例跑通。它是 Owner 2026-10-14 选过、2026-11-08 因第 9 类商标撞名暂停的名字（BRAND.md §2），这里只拿来试脚本，不表示重新推荐它。其他候选名字还没过商标这一关，没有出图。

同一天稍后 Owner 说总表里的几个都不太喜欢，「青玉案的话可以试一试」，所以又跑了一次：`"青玉案/Touchstone" "他石/Tashi"`，出了 `fit-青玉案.png`，`fit-all.png` 换成这两个名字并排。青玉案是 Owner 2026-10-14 自己提的（BRAND.md 第 60 条），Touchstone 是当时暂用的英文工作名，和剑桥的英语教材同名，BRAND.md §2 记着不推荐。青玉案的商标还没查。下面「没做的事」里「没有用别的候选名字出图」说的是第一次跑。

## 怎么跑

```
node scripts/brand/name-fitting-shots.mjs "他石/Tashi" "某名" "某名/Latin"
```

- 斜杠前是中文名，顶栏和登录页里放它；斜杠后是拉丁写法，可以没有。只给拉丁写法时，顶栏和登录页放拉丁写法。
- 脚本照 `scripts/component-inventory/` 的拍照脚本：用 `rig.mjs` 起一个临时数据库加 Vite 的本地网站（测试数据，owner 账号），跑完自己关掉。端口默认错开 41（网页 5340、接口 9953），临时数据在 `.scratch/component-inventory/rigdata-41/`，不碰别人同时在跑的清点网站。要换偏移，设 `INVENTORY_PORT_OFFSET`。
- 已经有本地网站在跑时，可以加 `--base http://127.0.0.1:端口` 直接用它，账号用 `NAME_FIT_USER` / `NAME_FIT_PASSWORD`（默认是清点网站的 owner 账号）。
- 本机没装 Paper Mono 时，用 `PAPER_MONO_FONT=/路径/字体文件.woff2`（也认 .otf / .ttf / .woff）指给它，脚本把字体嵌进拼图页。
- Chromium，deviceScaleFactor 2，reducedMotion reduce，locale zh-CN。耗时约一分钟（目测）。

输出都在这个目录：

| 文件 | 内容 |
| --- | --- |
| `fit-<名字>.png` | 每个名字一张，五块（下表） |
| `fit-all.png` | 所有名字并排，一个名字一行：顶栏 1440 左段、顶栏 390、登录页左上角、桌面图标、28px 和 16px 字标。只有一个名字时也出 |
| `fit-run.json` | 这一次跑的记录：页面上原来写的是什么、实算字号、本机字体、图标名有没有被截断、页面报错 |

脚本不删这个目录里的旧图。换了名字重跑，上一轮别的名字的 `fit-*.png` 还留着，要自己清。

## 现在页面上显示的产品名

- **顶栏**：首页顶栏显示「英语题库工作台」，实算 15px / 600，墨色（`rgb(27, 43, 51)`），左边是 32 × 20 的图形标志。1440 宽时这一块不在页面最左边，在 x ≈ 332 的地方（顶栏内容有居中的宽度限制）；390 宽时标志和名字在第一行，导航按钮折成下面两行。两个宽度都显示产品名，所以没有用示意条。子页面（草稿卷、个人空间等）的顶栏也写「英语题库工作台」，是 13px / 500 弱墨，这次没拍。
- **登录页**：左上角标志旁边写「英语题库工作台」，实算 15px / 600。登录页现在是 08 雾海（BRAND.md §3.1，第 67 条）：海獭是白身线稿，在右半屏（窄屏是上半屏）的雾海插画里往下潜，不是在卡片边探头。

## 绕过了什么

- **没登录真实网站**：用的是 `rig.mjs` 起的本地测试网站和测试账号，页面数据是固定测试数据。顶栏右边的「owner」和头像「ow」是测试账号。
- **只改 DOM 文字**：顶栏和登录页里名字的字号、字重、颜色、位置都是网站现在的样式，名字换成两个字以后宽度变短，别的东西跟着挪的样子也是真实排版。
- **字体**：网站只按名字写 `Inter, "PingFang SC", …`，不带网页字体文件，显示什么取决于本机装了什么。这台机器装了 Inter，**没有 PingFang SC**，中文由文泉驿正黑（WenQuanYi Zen Hei）显示。所以图里的中文字形和老师在苹果设备上看到的不一样，16px 糊不糊这件事在这张图里**不能下结论**，要在苹果设备上再看一次。
- **Paper Mono 缺**：仓库里没有 Paper Mono 的字体文件，本机也没装；Google Fonts 上查不到这个字体，它在 GitHub 上的页面这次会话里被网络拦下，没有下载。所以图里标着 Paper Mono 的两行实际是回退的等宽字 DejaVu Sans Mono，图里用红签「缺字体」标了出来，**不能当 Paper Mono 看**。拿到字体文件以后用 `PAPER_MONO_FONT` 重跑即可。另外 Paper Mono 本来就没有中文（BRAND.md §3.3），中文那一行即使字体到位也会回退到中文字体。

## 自己看过图以后的观察（目测，不是结论）

- 「他石」两个字比「英语题库工作台」短得多，顶栏左边显得空，标志和名字的比例变了：标志 32 × 20，两个 15px 的字约 30px 宽（目测），几乎和标志一样宽。
- 桌面图标下「他石」「Tashi」都没被截断。
- 文泉驿正黑下 16px / 600 的「他石」能看清；这两个字各 5 画，本来就不是条件 4 担心的那种字。
