# 详情页北星原型 · Reading C

## 相对现版的视觉变化

- 页底从灰白 SaaS 底改为 `#F3F5F1` 软绿白纸；速览头不再包卡片，直接落在页底上。
- 主按钮从墨绿改为墨黑 `#1F1F1D`；次动作改为无框 quiet 按钮，悬停 `#E9ECE6`。
- 真题徽章改为软底 `#E9ECE6`、无描边；话题芯片同为软灰，不再用 teal。
- 卷面是唯一材料对象：白底、4px 圆角、双层阴影，默认露一角 300px + 底部渐隐 + 「展开卷面」丸；展开后「收起卷面」sticky bottom 24px。
- 顶栏、920 栏宽、草稿丸与首页北星原型一致；墨绿仅品牌点与头像。

## 沿用的信息架构（owner spec）

返回找题 → 速览头（meta · 标题 · 大意 ≤68ch · 题型/考点 chips · 话题 chips · 动作行）→ 一张纸露一角。动作含加入草稿卷、看整卷、阅读解析、相似篇章；编辑/删除收入 `…` 菜单。

## 应用的规则

- 字号只许 12/13/14/20（卷面占位标签 11px 例外）；大意 13px muted。
- 模拟卷不标徽章；卷子层不配色。
- 题型分布无数据时不渲染该行（不占位、不造假）。

## 占位说明

- 卷面内容为 Times 占位排版，非 PaperSurface 只读挂载；右上角标注「原型占位 · 正式版挂载 PaperSurface」。**此标签仅属静态原型，`app/` 正式实现不得出现。**
- 看整卷 / 阅读解析 / 相似篇章 / 编辑 / 删除 无真实跳转。
- 草稿卷计数仅前端 toggle，不写库。
