# 走查：找题 → 组卷 → 导出

提案 · 单一来源。走查记录，没有改任何源码。

2026-11-14。像一位高三英语老师那样，在本地网站上走一遍：首页找题，点开一个题组看一眼，加进草稿卷，在草稿卷里调顺序、移除再撤回，然后导出题卷和答案。桌面宽 1440 和手机宽 390 各走一遍。

- 脚本：`scripts/ux-walkthrough/find-compose-export.mjs`（可以重跑；只重走一种宽度用 `WALK_ONLY=390`）
- 截图：`shots/`（路线 `d01…d16` 是 1440，`m01…m16` 是 390；状态图是 `state-*.png`）
- 每一步的原始记录：`walkthrough.json`（地址、动作、点击数、屏上可点的东西、提示、草稿卷实际顺序、下载）

## 怎么走的

- **网站**：清点脚本用的本地网站（`scripts/component-inventory/rig.mjs`），端口偏移 43，临时数据库，owner 账号登录。Chromium，DPR 2，减少动态效果。
- **数据**：固定测试数据只有一套卷「2026 新课标Ⅰ卷」的阅读 A、B、C、D 四篇。整卷没有上线，没有听力，没有审过的参考答案。这一点限制了能走到哪里，见文末「没走到的地方」。
- **找题的说法**：「2026 阅读」。另外试了输入框占位符里那句「找一道讲生态恢复的阅读 C，主旨概括」，和一个搜不到的词。
- **加载中、出错**：在浏览器里拦接口制造（延迟或返回 500），每张图在 `walkthrough.json` 里写了怎么触发。没有改网站。
- **计数口径**：点击 = 鼠标点一下（窄屏是手指点一下），原生下拉框选一项算 2 次（点开 + 选中）；按键 = 回车、Esc；打字单独记，不算点击；滚动 = 要点的东西不在屏上、得先滚过去，记 1 次。
- **时间**：都是本地网站上量的，只说明「这一步要等」，线上多快拿不准。

## 二、卡点

按严重程度排。每条：在哪一步，看到了什么，为什么是问题（违反哪条规矩），建议怎么改。改法都是建议，没有定。

### 1. 调了顺序，卷面不跟着变（第 7、8 步）

- **看到的**：草稿卷接口和左栏的顺序都是 D篇、C篇、A篇（`d07-打开草稿卷.png` 左栏），卷面上第一篇却是 A篇的正文（SoFi Stadium，测试库里属于 A篇），标题印的是「A」。另跑了一次读卷面里的字：左栏 D、C、A，卷面 A、C、D。下移以后左栏变成 C、D、A（`d08-把第一个题组往后挪一位.png`），等了约两分钟卷面回来，第一篇还是 A篇（`d14-下载题卷-PDF.png`），第二篇是标「C」的那篇（`d09-采用前.png`）。
- **为什么是问题**：老师调了顺序，看不到结果，会以为没调成，或者印出来才发现不对。PRODUCT.md「Design Principles」第 5 条「正确、可读、可预期就是信任本身」；BRAND.md §5.5 质感六条「熟悉」（同一样东西每次都在同一个位置）。
- **拿不准**：卷面是不是有意按原卷的 A、B、C、D 排（标题印的就是原卷字母）。如果是有意的，那左栏的「上移 / 下移」就是在骗人。导出的 PDF 里是什么顺序没打开看（这一步不评判 PDF）。
- **建议**：先定卷面跟谁（见「要 Owner 定的问题」第 1 条）。跟老师的顺序走的话，卷面标题字母跟着重排；跟原卷走的话，左栏去掉上移下移，写明「按原卷顺序」。

### 2. 每改一下，卷面消失一两分钟（第 7–11 步）

- **看到的**：下移、采用分页建议、移除、撤销，每一次卷面都整块换成一行「正在生成分页预览…」，本地等 86–147 秒（上表）。等的时候左栏还能点，但卷面上什么都没有。第一次打开要约 36 秒，开头只有左上角一行字。导出时看不出在做事。
- **为什么是问题**：组卷要来回挪、来回试，一次两分钟，老师调三次就放弃了。BRAND.md §5.5 和 DESIGN.md §5「质感六条」的「现代」：回车以后马上有可见的变化，过程看得见，**不用整屏白屏**。这一条写着「多快算马上，等第一条路的走查量出现状再定」，上表就是现状。
- **拿不准**：线上服务器会不会快很多；这里只能说本地要等这么久。
- **建议**：改动时保留旧卷面，盖一层淡色，顶上一行「正在重新排版…」；左栏先变。导出时「导出」键上直接写「正在生成…」并且不能再点。

### 3. 出错时老师看不到真话，或者看到的是程序的话（首页、加入、整卷预览、导出）

- **看到的**：
  - 首页题组接口出错时，页面不报错，悄悄换成另一套内容：「浏览全部 10 套卷」「今天翻到 阅读 B 2023 新课标 I 全国高考」，草稿丸写「草稿卷（0 组）」，而草稿卷里其实有 3 组（`state-home-error-1440.png`、`state-home-error-390.png`）。
  - 加入草稿卷失败时，弹出浏览器自带的警告框，内容是服务器原样返回的「boom」（`state-home-add-error-*.png`，截图里看不到警告框，记录在 `walkthrough.json` 的 `dialogs`）。
  - 整卷预览打不开时，页面上写「错误信息：Cannot read properties of undefined (reading 'blocks')」（`state-paper-preview-error-*.png`）。
  - 导出出错时，页面最上面、贴着左边（x=0，没有边距）一行红字「导出 PDF没成功，可以再试一次。」（少一个空格，`state-export-error-1440.png`）。纯答案版、大字完整版不可用时也是同一个位置、同一种红字（`d16-下载答案-PDF.png`、`state-export-largecomplete-1440.png`），卷面中间再重复一遍。
  - 下载成功的提示也在这个位置，一行灰字「PDF 已开始下载。 本卷采用小四（12pt）。 已满足长卷页数上限和正文版式，仍有 1 个题组跨 A3 正反面，请检查分页。」（`d14-下载题卷-PDF.png`）。当时选的是 A4 散页，提示却在说 A3。
- **为什么是问题**：草稿丸写 0 组，老师会以为刚组的卷没了。PRODUCT.md「Design Principles」第 5 条「不出意外、不丢数据」；DESIGN.md §5「Notices 提示条」（说明和报错都是一行次要灰字加 16px 图标，只有「没保存」「会丢东西」才上危险色）；BRAND.md §1.3（话短，跟老师说人话）。
- **建议**：做一个共用的提示行（见「路上的构件」第 1 名），所有提示放在同一个位置，有边距，一行说完；出错写清楚哪里出错、东西还在不在、可以做什么。首页拿不到数据时明说「题库没连上」，并保留草稿丸的真实组数。

### 4. 拿不到答案和解析（第 15、16 步）

- **看到的**：换成「纯答案版」后，卷面写「纯答案版不可用：选中的题组没有同版本已审源参考答案；不能以教师卷替代」，导出时同样报这句（`d15-换成-纯答案版.png`、`d16-下载答案-PDF.png`）。「大字完整版」报「大字完整版需要完整的两个听力题组」，卷面写「生成分页预览没成功，可以再试一次。」，再试也不会好（`state-largecomplete-preview-1440.png`）。下拉框里四个版本看起来都能选。
- **为什么是问题**：这条路的终点是「一份能印的卷子加解析」，这里走不到。选了才告诉老师不行；「再试一次」是在让老师做没用的事。「已审源参考答案」「教师卷」是后台的话。PRODUCT.md「Design Principles」第 4 条（为真实工作流减负）；BRAND.md §1.3。
- **拿不准**：测试数据本来就没有审过的答案、没有听力。真实题库里多少卷能出纯答案版，不知道。
- **建议**：下拉框里，当前选的题组用不了的版本直接标「用不了」，后面一行写原因（比如「这几篇还没有审过的答案」）；不让老师选了再失败。

### 5. 窄屏上换 PDF 版本要绕路（第 12、15 步，390）

- **看到的**：390 宽时，草稿卷顶栏折成三行（`m07-打开草稿卷.png`），「PDF 版本」和 A4 / A3 收进顶栏「⋯」面板（`m12-面板.png`）。选完版本面板不关，要再按 Esc（`m15-换成-纯答案版.png`）。导出菜单直接盖在卷面上。
- **为什么是问题**：路能走完，但比桌面多 1 次点击、1 次按键，而且「⋯」面板的名字是「草稿卷更多信息」，老师想不到版本在里面。BRAND.md §5.5 质感六条「熟悉」（同一样东西每次都在同一个位置）。
- **建议**：把版本放进「导出」菜单的第一层（比如「下载 PDF」下面列四个版本），桌面和窄屏一样，顶栏少一个下拉框。

### 6. 看不出哪些是建议、哪些是老师定的（第 6、9 步）

- **看到的**：
  - 结果行加入以后，只有右边的「+」变成墨色圆里一个勾，行的底、边、字都没变（`d06-在结果行加入-C篇-D篇.png`）。
  - 详情页加入以后，按钮变成薄荷绿底的「已在草稿卷」（`d04-在详情页加入草稿卷.png`）。同一件事，首页叫「已在草稿卷中」，详情页叫「已在草稿卷」，一个墨色勾一个薄荷绿底。
  - 采用一条「建议前置分页」以后，屏上还剩 2 个「建议前置分页」，看不出哪一条已经采用了（`d09-看分页建议并采用一条.png`）。
- **为什么是问题**：BRAND.md §5.5「提议是轻的，决定是实的」：老师点过的东西变成墨色的实物，底、边、字三处一起变，不用薄荷绿。DESIGN.md §5「Proposal → Decision」（「不准」一条：点睛色只给本页唯一的主键）。
- **拿不准**：DESIGN.md「Proposal → Decision」的「不用在」写着推荐理由保持灰字、分页小签只有提议的样子，采用后的结果是纸上的分页线。所以分页建议看不出已采用，可能是按规矩做的；但卷面要等一分半才回来，那条分页线老师在点完的当下看不到。结果行算不算「决定」那种卡片，也拿不准。
- **建议**：加入后的样子两页统一成一种，用墨色不用薄荷绿，字统一成「已加入」；分页建议点完后，那个小签当场变成「已前置分页 · 撤回」，不必等卷面。

### 7. 有的撤销有，有的没有（第 6、10、11 步）

- **看到的**：草稿卷里移除题组，底部出「题组已移出 撤销」，点撤销能回来（`d10`、`d11`）。首页结果行上再点一下那个墨色勾，题组直接从草稿卷里移出，没有任何提示（走查前试探时看到，没截图；读屏名字写着「从草稿卷移出」，记录在 `walkthrough.json` 第 5、6 步的可点列表里）。
- **为什么是问题**：同样是「移出草稿卷」，一个能撤一个不能，而且勾看起来像「已完成」不像「移出」。DESIGN.md「Proposal → Decision」里的撤回规矩，和 DESIGN.md「The Deletion-Cost Rule」（可恢复的删除 = 即删 + 撤销提示）。
- **建议**：结果行上移出也给同样的撤销提示，或者勾只表示状态，移出放进行上的「⋯」。

### 8. 同一样东西叫法和位置不一样

- **看到的**：
  - 同一篇：结果行「A篇」，详情页大标题「Reading A」、副标题也是「Reading A」（`d04`），卷面标题「A」，左栏「A篇」。
  - 新加的题组排在最上面：先加 A、再加 C、D，草稿卷顺序是 D、C、A，不是老师点的顺序（`d07` 左栏）。
  - 顶栏：首页和详情页的顶栏是居中窄栏，草稿卷的顶栏铺满全宽、多一个「返回找题」（`d02` 和 `d07` 对比）。
  - 首页搜索后，「思考模式」字号 16px，结果行标题 13.5px，「思考模式」比结果还显眼；「筛选」单独飘在下面一行（`d02`）。
- **为什么是问题**：BRAND.md §5.5 质感六条「熟悉」「有分量」（层级靠字号站住）。
- **建议**：一篇题统一叫「阅读 A」这种老师说的话；新加的排在最后；「思考模式」降到和「筛选」同一档。

### 9. 小事

### 做成共用件后最能让这条路顺的三个

1. **提示行（说明、等待、成功、出错、撤销，一个件）**。卡点 2、3、4、7 都落在它上面：现在至少五种手写写法，位置有的贴左边 x=0，有的在卷面中间，有的是浏览器警告框，有的直接露程序报错。做成一个件，定死位置、一行、图标、语气，DESIGN.md「Notices 提示条」的规矩就一次落地；等待态（保留旧内容 + 一行进度）也在这里给。
2. **加入键（加入 / 已加入 / 移出，首页结果行和详情页同一个）**。卡点 6、7、8 落在它上面：现在结果行手写一个，详情页用 `Button` 另配一个，字、颜色、能不能撤销都不一样。做成一个件，§5.5 的「决定」样子和撤回只写一次。这条路上每加一个题组都要碰它（本路线三次加入，两次在结果行的手写件上，一次在详情页的 `Button` 上）。
3. **选项字段（下拉框 + 分段选择，带「这一项用不了」的说明）**。卡点 4、5 落在它上面：PDF 版本下拉框、A4 / A3 分段都是手写，窄屏时整块被收进「⋯」面板；版本用不了时没有地方提前说。做成一个件，桌面和窄屏放法一起定，不可用的选项带一行原因。

没排进前三的：左栏目录项（`div` 当键用，卡点 1 定了以后再说）、草稿丸、搜索框。`design/components-2026-11-13/` 的清点也把顶栏两种高度列为待统一，和卡点 8 对得上，这次不重复。

## 四、要 Owner 定的问题

1. **卷面顺序跟谁走？** 跟老师在左栏排的顺序，还是跟原卷的 A、B、C、D？建议：跟老师的顺序，卷面字母跟着重排。原卷字母放进左栏小字当来源。
2. **「马上」是多快？** DESIGN.md「质感六条·现代」等这次走查的现状再定。现状：打开约 36 秒，每改一次 86–147 秒（本地）。建议：点完 0.1 秒内要有看得见的变化（左栏先动、按钮变「正在…」）；卷面重排期间保留旧卷面，不白屏。具体秒数等线上量过再定。
3. **新加的题组排在哪？** 现在排最上面。建议：排最后，和老师点的顺序一致。
4. **用不了的 PDF 版本怎么处理？** 建议：下拉里照样列出，标「用不了」并写一行原因，不能选；不要选了再报错。

6. **结果行和详情页「已加入」的样子要不要照 §5.5 的「决定」做？** 建议：要，两处统一成墨色、同一句话，移出都能撤销；如果结果行不算，就在 DESIGN.md「不用在」里写明。
7. **首页拿不到题库时说什么？** 现在悄悄换成别的内容，草稿丸写 0 组。建议：明说「题库没连上」加重试，草稿丸的组数不跟着变 0。
