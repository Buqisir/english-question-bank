# 登录页重做 · 三个方向的样张（2026-11-17）

状态：**提案 · 单一来源**（agent 一人的判断，没做同事访谈）。Owner 说「外面这个页我打算重新做」「登录页按 ABC 方向做样张吧」，这里是三张样张，还没选。

可点的样张：claude.ai 上的私有页面「獭石登录页样张」，右下角切 A / B / C，能输入、点登录（不连账号，只演示忙和出错）。

## 为什么重做

现在的登录页和登录后的页面是两套东西（`shots/board-1440.png` 上面两张，都是 2026-11-17 线上实拍）：

1. 登录页有自己一套颜色（`--login-*`），输入框白底灰边、登录键手写；里面已经是纸、阴影、共用构件。
2. 太满：雾色（黄、青、紫）、光束、巨藻、气泡、大海獭，标题 64px，装饰比内容重。
3. 第一次打开时海獭先画线稿，约 0.8 秒只有轮廓，1.5 秒左右才填色（实拍里那一帧正好拍到）。
4. 看不出这是题库。

## 三个方向

| | 做法 | 用到的已定素材 | 碰到的已定规则 |
|---|---|---|---|
| A 纸在桌上 | 页底和登录后首页同色，标志和字标的位置和首页顶栏一样（1440 宽时 x=292），中间一张纸（卡片圆角 12、`--elev-2`）放口号、两个输入框、登录键 | 标志、字标 | 没有獭獭：第 118 条已定「登录页探头不放」，所以 A 不放 |
| B 收着的雾海 | 结构照现在，雾只留雾薄荷一团，去光束和巨藻，海獭从约 52% 宽缩到 40%，直接完整出场，标题 64 → 48 | 现在的线稿海獭（`app/src/auth/login-otter.svg`，没改） | 雾色是第 67 条定的，B 只用了其中的雾薄荷；海獭摆动是图标动效，样张里先停着 |
| C 题海 | 左边和 A 一样一张纸；右边是一片淡的题（题海），獭獭仰躺浮在上面，前面一张清楚的题就是「一瓢」 | `mascot/otter-float.svg`（第 114 条留下的仰躺抱石，没改） | 题海里的题是 agent 编的例句，不是真题；正式做要不要换真题库里的题、要不要画「捧起一张」的新姿势，都要 Owner 定 |

三个方向都：口号「题海三千，只取一瓢」和字标照第 121 条；输入框用共用的 `TextField`（lg，高 36，标签看得见）；登录键用共用的 `Button`（solid、pill，照 Owner 2026-11-15 定的胶囊大号）；颜色全用 `tokens.css` 的变量，雾薄荷 `#C4ECDD` 是唯一写死的颜色（照第 67 条）。

## 查过的

- 1440 × 900 和 390 宽各拍一张（`shots/`），两种宽度都没有横向滚动（scrollWidth 等于视口宽），页面没有报错。
- 首帧（`shots/frames-0-300-800-1500ms.png`，从开始导航算起）：0 毫秒时 A、B 还是白屏，那是本地开发服务器还没把脚本送到，不是设计；300、800、1500 毫秒三帧都是完整的画面，没有只有轮廓的那一帧。
- 对比度（WCAG 算法算的）：标题墨对页底 13.29，说明弱墨对页底 4.99、对纸 5.47，标签对纸 8.17，登录键白字对石板墨 10.60，都过 AA。C 的题海淡字对纸 2.57，不过 AA；它只是背景装饰，读屏不念（`aria-hidden`），不需要读清。
- 没拍到：深色模式（网站现在没有深色模式）；真实账号登录后的跳转。

## 要 Owner 定的

1. 选 A、B、C，或者混（比如 A 的纸 + C 的题海做背景）。
