## 守住的几条

- 用户名、口令只做成「空」，不做成选项（做成选项等于把账号列出来）。
- 都是真 `<input>`：`autocomplete="username"` / `"current-password"`，口令 `type="password"`，读屏标签是「用户名」「密码」；Tab 从用户名到口令，回车提交。
- 出错不说是哪一空错（不泄露用户名存不存在），两空一起标。
- 批改那一行是常驻的 `role="status"`，出错和对了都会被读屏念到。
- 示例题和正文都是这次写的，不是题库里的真题。
- 獭獭默认不放（第 118 条「登录页探头不放」）；控制条里可以勾上看仰躺抱石那张，放不放等 Owner。
