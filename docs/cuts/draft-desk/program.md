# draft-desk — 草稿卷「备课桌」大计划（program，非单刀）

Owner 拍板 2026-07-09（拆刀草案「听你的」）。本文件是 program 级决策记录；
每把刀开工时另立自己的 `docs/cuts/<CUT>/plan.md`，本文件只管方向与拆刀边界。

## 三根柱子（方向共识）

1. **排版是标准的，调的是结构。** 卷面 typography 由
   `docs/product/exam-paper-format-standards.md` 全权负责，不给老师字体
   字号选择器；老师调的是结构：题序、大题分组、编号语言、写作答题区、
   学生版/教师版。
2. **纸是主体，所见即所印。** 工作台 A4 预览升为页面主体：真实分页多页
   纸、页码、页数（"共 N 页 · 双面 M 张"）常驻。整卷页的纸是读的
   （连续单纸），工作台的纸是印的（分页）——同一纸语言的两种姿态。
3. **调整动作贴纸，骨架复用整卷页。** rail 目录贴左 + 纸居中 + scrollspy
   联动（整卷页已磨顺的骨架直接搬）；分页干预用"线"的语言——换页销是
   剪刀线的表亲（批注层，不改写纸）。
