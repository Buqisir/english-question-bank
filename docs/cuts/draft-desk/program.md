# draft-desk — 草稿卷「备课桌」大计划（program，非单刀）

Owner 拍板 2026-07-09（拆刀草案「听你的」）。本文件是 program 级决策记录；
每把刀开工时另立自己的 `docs/cuts/<CUT>/plan.md`，本文件只管方向与拆刀边界。

## 三根柱子（方向共识）

1. **排版是标准的，调的是结构。** 卷面 typography 由
   `docs/product/exam-paper-format-standards.md` 全权负责，不给老师字体
   字号选择器；老师调的是结构：题序、大题分组、编号语言、写作答题区、
   学生版/教师版。
2. **纸是主体，所见即所印。** 工作台 A4 预览升为页面主体：真实分页多页
   纸、页码、页数（"共 N 页 · 双面 M 张"）常驻。整卷页的纸是读的
   （连续单纸），工作台的纸是印的（分页）——同一纸语言的两种姿态。
3. **调整动作贴纸，骨架复用整卷页。** rail 目录贴左 + 纸居中 + scrollspy
   联动（整卷页已磨顺的骨架直接搬）；分页干预用"线"的语言——换页销是
   剪刀线的表亲（批注层，不改写纸）。

## 关联决策

- 工作台/个人空间"丑在掉队"诊断（owner 2026-07-09）：07-08 双刀是合规刀，
  缺编辑主张；本 program 即编辑刀。页谱：工作台=产出，个人空间=备课成果。
- 原型拍板流水线沿用 scissor-select-feel 跑通的：原型 artifact → owner
  逐裁点拍板 → prototype.html 入 cut 目录 → plan → DEV。
- **割裂议题 grilling 落锤（owner 2026-07-10，五裁点）**：
  1. 病根=「纸不像纸」（非骨架/零件），program 方向不变，不补新方向。
  2. **色温法**：纸页入暖（整卷/讲评/工作台预览=暖纸桌+暖纸），工具页
     中性；整卷/讲评现有暖色值转正为 `--paper-*` token 家族。my-space
     微缩 A4 卡=暖纸卡浮中性页。条文随暖纸转正小刀入 DESIGN.md。
  3. **命名法**：对外统一「个人空间」（页题弃「已保存的草稿卷」），
     页内分区叫「草稿卷」。卷宗柜刀顺手收（顶栏/页题/保存弹窗措辞）。
  4. **删除法**：分两档——改草稿（删题组）=即删+可撤销；毁成品
     （删草稿卷+PDF）=站内确认弹窗+danger。my-space 原生 confirm 升级，
     归卷宗柜刀。
  5. **排期**：部署六刀 → lecture-rail → **暖纸转正小刀**（新增先行刀：
     token 转正零视觉变化 + 工作台预览暖桌+纸阴影收 P0-D1 + 三法入
     DESIGN.md）→ 刀A 原型 + 卷宗柜原型并行拍板/施工 → motion-pass。
     owner 议题3（A4 预览背景灰怪）由暖纸转正小刀闭环。
- **议题2 grilling 落锤（owner 2026-07-10，六裁点，原型
  `prototype-print-form-v2.html`）**：
  1. 核心事实（owner 改判，掀翻初版方案）：断篇判决随打印形态变——
     A3 对折时背面版3+版4 同面并排可见不算断，版2→版3 要翻面才是
     真断；A4 散页所有跨版都断。**打印形态是建议引擎的必要输入**，
     形态盲猜的建议会报假警漏真警（Super Teacher Boundary 最忌
     不可信建议）。
  2. 方案二轻量版：卷头 A4/A3 切换，只影响建议判据+「共 N 版 · M 张」
     计数，不做按张分组预览视图。
  3. 默认 A4、记住上次选择；不设设置页、不卡新建入口。
  4. 重排自由度=任意序（组题场景多为同类题攒卷，混排本来就少）。
  5. 建议交互：一键应用+可撤销（轻档），安静常驻，建议+确认，
     永不自动重排。
  6. 落刀：B 扩容 + 新立刀E（排 C 后）；A3 拼版 PDF 导出为 E 的
     后续兼容追加。不加塞既定队列。B 自身的技术侦察 + PA + grilling
     照 program 原规矩另行专场。
- **刀B 方向演进（owner 2026-07-12 拍板，全文 `draft-desk-b/decision.md`）**：
  技术侦察 + 内外调研 + headless Chromium spike 后，刀B 从「喂断点给 Vivliostyle」
  演进为**「服务器当唯一排版真源 + 分页活页面」**（路甲）：服务器排一次分页，出

  引擎换掉 Vivliostyle（旧系统孤儿路由不动）；退役自研 `paginateA4Preview`。长阅读拆段落 /
  画布对齐 / 提取分页三个老问题走此路后自动消解。**A4/A3 打印形态 + 分页建议引擎改真分页
  衍生 挪出本刀、排后面单独做**。进 formal PA（不降 PA-lite：换出片引擎 + 预览架构重构）。
