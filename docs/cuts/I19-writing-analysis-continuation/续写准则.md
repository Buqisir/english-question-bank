本文件是 I19 续写解析「范文 + 情节设计思路 + 亮点表达」生成的**规格书**，是 `buildContinuationAnalysisMessages` prompt 的来源。

> 姊妹篇：应用文 `docs/cuts/I18-writing-analysis/范文准则.md`。**很多裁定（水平二天花板、课标词、亮点逐字命中）沿用；续写专属的是：情节设计（命门）、衔接、描写重心、语法受控提升。**

## 0. 目标水平裁定（最关键）

- **水平二铁律仍管用（课标 p47）**：高考命题不超过学业质量水平二。所以续写范文**不是炫技母语者范文**，是"面向努力的中上水平学生、照着能学会、下次能自己写出八成"的**第五档（21–25）执行**。
- **续写考"创造性表达"（课标 p33–34 选必/选修表达性技能："借助语句生动形象传递思想情感""使用丰富的词汇和句式创造性表达"）**——比应用文更靠表达技能的提高端。
- **两者的张力裁定（owner 拍，2026-06-05）**：续写的"创造性 / 丰富"落在**内容与描写**（情节合理新颖、描写细腻多样），**不是**语法复杂度的放飞。语法仍受课标节制（见 §2 受控提升）。即：**内容可创造（受约束）、描写可丰富、语法够得着**——三者合起来才是第五档，不靠堆复杂句。

**评分标准第五档（操作尺，三维度）**：① 内容（与原文融洽度高 + 与两个段首语衔接非常合理 + 新颖丰富合理有逻辑 + 续写完整）② 语言（语法词汇丰富准确、错误很少）③ 连贯（连接成分自然有效、前后呼应、意义连贯）。

## 1. 创作准则（按优先级，每条带依据）

**① 情节 / 内容 —— 命门（续写的命脉在这，不在辞藻）**
- **九成情节来自原文线索，自己只补 2–3 句过渡**（外脑公约数）。读懂原文：人物人设/关系、时空、重要意象、未解决的问题、主旨。续写是顺着原文逻辑往下走，不是另起炉灶。
- **排序：简单稳妥 > 紧凑 > 丰富 > 故事性**（艾米原话）——**先保证合理，再谈丰富**。情节不合理/逻辑不强直接掉到第三档。
- **NSDD 骨架**：需求(Needs)—困难(Difficulties)—方法(Solutions)—结局(Denouement)。两段大致 = [段1 承接 starter1，面对/制造一个冲突或困难、给出行动] → [段2 承接 starter2，解决需求、收束、呼应原文意象、点题升华]。
- **与原文融洽**：人物性格/关系/基调一致，读起来像原作者写的；沿用原文的意象/物品/地点。
- **前后呼应 + 点题**：结尾呼应原文主题/意象，是拉开第五档的关键。**绝不抄原文**（抄写直接掉到第一档/0 分）。
- **意象护栏（2025-i 压测教训，命门）**：点题 / 中心意象必须**锚定原文真实强调过的人物 / 物品 / 主题 / 情感**——结尾回扣的那个意象，必须是原文真出现过的（如 Gunter 的 big smile、开篇 cold/wet evening、Toby）。**绝不新造一个原文没突出的象征物**。（2025-i 首测病根：原文结症是"怕湿狗进屋 + 撞到孩子 + 我要把聚会弄得井井有条 + 面子/自尊"，范文却造了个原文没有的 "clean floor" 当中心意象——这是融洽度失分点。）
- 依据：课标语篇知识 p22–24（记叙文的情节连贯、逻辑次序）；评分第一维度（与原文融洽度）。

**② 衔接 —— 续写专属（接住原文 + 两个段首语）**
- **接段首给定句**：把段首句当"已发生的事实"，紧跟一句**评价/承接**再展开（如 `Sb did sth, which turned out to be…` / `To my great disappointment, …`）。
- **段间过渡**：时间衔接（then/soon/later/suddenly/instantly/eventually；`Before I could react` / `After what seemed like a century`）、空间衔接、情感衔接。
- **结尾呼应**：茅塞顿开 `It suddenly struck me that…`、从此以后 `From then on…`、睹物思情、`Had it not been for…` 等点题句式。
- 依据：评分第三维度（连接成分、前后呼应）；课标语篇知识衔接连贯。

**③ 描写 —— 续写的语言重心（应用文没有的侧重）**
- **描写占比要够**（外脑："描写占比多是关键，续写比例与原文一致"）——纯叙事流水账会失分。
- 三类描写按需铺开：**动作链**（拆身体部位逐个动作 / 非谓语串联）、**心理情绪**（情绪递进/转变/袭来，形容词作状语，独立主格）、**环境烘托**（正衬/反衬，结尾 `Amid…, sb realized that…`）。
- 依据：课标 p33–34"生动形象传递思想情感"；评分"内容丰富"。

**④ 语言 / 语法 —— 受控提升（服务以上，集中在亮点处）**
- **课标词 + 高频词块为主**，不堆生僻。
- **主体守必修(\*)级**（限制性定从、非谓语、省略、被动）。
- **受控提升（续写 vs 应用文的关键差异）**：刻意埋若干 **/\*\*\* 级"够得着的高分记叙句"作亮点——独立主格、非谓语作状语、`No sooner…than` 倒装、虚拟后悔（`should have done` / `If only…`）、部分倒装强调情绪（`So + adj. + was sb that…`）。**理由**：这些是续写描写的家常工具、全在课标语法项目表内、评分奖励"语法丰富"、一线老师都这么教。**但仍"够得着"——埋几处作亮点，绝不满篇堆复杂。**
- 依据：§2 表；评分第二维度。

**⑤ 词数**
- **学生续写部分目标 ≈ 150 词**（瞄 140–160，评分门：少于 120 酌情扣分）。modelAnswer **含两个 starter 句**（各领一段、读起来完整），但词数以"学生续写"算。
- 两段篇幅大致均衡。拼写体系前后一致。

## 2. 语法天花板分级（课标语法项目表 附录3 p133–140）

星级 = 课标分级。**与应用文同表，但"续写用法"栏放宽到受控提升。**

| 级别 | 代表结构 | 续写范文用法 |
|---|---|---|
| **必修(\*)** | 限制性定从；非谓语（不定式/-ing/-ed 作定语/状语/补语）；省略句；进行/完成时被动 | ✅ **主力**——范文主体自信用 |
| 选择性必修(\*\*) | 非限制性定从；主语/表语从句；过去完成/现在完成进行时 | ✅ **受控亮点区**——续写描写常用，刻意埋 |
| 选修提高(\*\*\*) | 倒装（`No sooner…than`/部分倒装强调）；虚拟语气（后悔/`If only`）；独立主格；强调句 | ⚠️ **受控亮点区（续写专属放宽）**——埋少数几处作"够得着的高分记叙句"，自然得体；**绝不满篇堆** |

**与应用文的差别**：应用文把 \*\*\* 级划成 🚫"高考之上"；**续写把 \*\* / \*\*\* 级当"受控亮点区"**——因为续写描写离不开独立主格/非谓语作状语/倒装/虚拟，且都在课标内。天花板没破（仍课标内、仍够得着），只是密度比应用文高。

## 3. 词汇准则

- 以**课标词汇表（附录2 p73+）**为范围；丰富 = 课标词内的恰当多样，不是生僻炫技。
- 描写词块（动作/情绪/环境）可丰富，但仍以课标高频为主。
- 校验期用 `guokao-vocab-checker` skill 查超纲（带中文注释的超纲词可接受、未注释超纲词需改）。

## 4. 亮点表达（Highlight Expression）甄选准则

- 3–5 条 `{text, note}`；`text` 必须在 modelAnswer 中**逐字出现**（强制"从范文里挑"、不许现编）。
- **续写亮点偏描写句式**（动作链 / 心理情绪 / 环境烘托 / 高级记叙句式 / "说"的多样化 / 修辞虚拟），而非应用文的框架句。
- `note` 用中文讲**功能 + 怎么迁移套用到别的续写**（类别写进 note，如"这是动作链：先拆身体部位逐个动作…"——**不设结构化 category 字段**）。

## 5. 情节设计思路（Continuation Design）准则 —— 续写专属（命门的显性化）

讲"**为什么这么续 + 怎么接住原文和两个 starter**"的设计逻辑，**不是剧情复述**。一线老师讲评续写的标配（主旨 + 线索路线图）。形状（见 §6）：
- **`theme`**：一句话锚定续写要服务的主旨（主题语境 + 价值取向，如"人与自我·亲情·和解：放下傲慢、主动弥合"）。续写的所有情节都向它收束。
- **`paragraphs[0]`（第1段设计）**：怎么承接 starter1（把它当已发生事实接住）+ 这段制造/面对什么冲突或转折 + 用了什么关键原文线索。
- **`paragraphs[1]`（第2段设计）**：怎么承接 starter2 + 怎么解决需求/收束 + 怎么呼应原文意象、点 `theme`。
- 每条**一句话讲解**（讲设计逻辑，不复述句子）；写给"想学怎么构思续写"的学生看。

```json
  "continuationDesign": {

    "paragraphs": [
      "第1段设计：承接 starter1 + 冲突/转折 + 用了哪些原文线索（讲设计逻辑，不复述）",
      "第2段设计：承接 starter2 + 解决/收束 + 呼应原文意象、点题"
    ]
  },
  "highlightExpressions": [
    { "text": "范文中逐字出现的高分描写句块", "note": "中文：功能（哪类描写）+ 迁移用法" }
  ]

```
- `paragraphs` **恰好 2 条**，按 `continuationStarters` 顺序一一对应（数据 12/12 均 2 starter）。
- `highlightExpressions` 3–5 条，每条 `text` 在 `modelAnswer` 内逐字出现。

## 8. 三源关系判定（地基判定，2026-06-05）

- **课标为纲、评分为尺、外脑为操作手册**——三源无方向性打架：评分第五档"内容新颖丰富合理有逻辑"≈ 外脑"NSDD + 描写 + 点题"≈ 课标"创造性表达 + 记叙语篇连贯"。
- **唯一要知情的张力 = 评分"语法词汇丰富" ↔ 课标"高考不超水平二"**：裁定同应用文——透过课标读"丰富"为"课标内的范围与控制"；但**续写比应用文多让一步**（\*\* / \*\*\* 级进受控亮点区），因为续写描写离不开这些句型、且都在课标内（见 §2）。这一步是续写体裁的内在要求，不是向应试妥协。
- **发散性的护栏 = §1① "九成情节来自原文线索、简单稳妥优先"**——防止"创造性"反噬成天马行空/逻辑崩坏（续写的首要失分点）。
