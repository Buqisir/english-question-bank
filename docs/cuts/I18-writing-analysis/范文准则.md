# 应用文范文准则（Model Answer Doctrine）— 课标为纲·评分为尺

本文件是 I18 写作解析「范文 + 亮点表达」生成的**规格书**，是 `buildWritingAnalysisMessages` prompt 的来源。
**权威排序（owner 定，2026-06-05）：以《普通高中英语课程标准（2017年版2025年修订）》为最高权威纲领，再结合高考应用文评分标准为操作尺。**

## 0. 目标水平裁定（最关键，课标 p47）

> 课标 p47：「高中毕业 = 水平一；**英语高考命题不超过学业质量水平二的要求**；水平三用于更高需求学校 / 其他测评。」

- **水平二 2-2（p44，高考写作标尺）**：「有效地进行描述、说明、解释、论证和评析，**表达清晰、得体、连贯**；有理有据」——未要求复杂句式。
- **水平三 3-2（p46）**：「自然、恰当地运用**复杂句式和多样的衔接手段**」——复杂句式是水平三，**在高考之上**。
- 附录1 阶梯：二级「**有效地**陈述…运用**已有**语言知识」→ 三级「**准确、熟练、得体**…**较为复杂**」。

**裁定：范文 = 「水平二的优秀执行 = 评分第五档(13–15)」。** 面向一个努力的中上水平学生——"照着能学会、下次能自己写出八成"。**不是炫技的母语者范文。** 评分标准第五档"较多复杂高级结构"须透过课标读：是相对水平一的**范围与控制**、是"尽力使用较复杂结构"（第五档(3)），不是水平三的复杂。

## 1. 创作准则（按优先级，每条带课标依据）

**① 内容 —— 命门（中档冲高档全靠它）**
- 覆盖题面**所有**内容要点（漏点直接掉档；评分第一条）。
- **具体到有画面感**：不写空泛（"很开心/很有意义"），写可感细节。细节要从活动**过程**里来（含一个具体动作 / 小转折）。
- **有真实的个人体验 / 小领悟**：从"做了什么"升到"有什么不一样"，且感想要**从那个具体过程里长出来**——不要贴"放慢脚步享受生活"这类万能升华句。
- 依据：课标必修表达性技能"叙述起因发展结果""简述个人看法态度"。

**② 得体 —— 应用文专属（课标语用知识 p25-26）**
- 语域 = f(场合正式程度、行事程序、与对象的情感距离/身份事由)。朋友→亲切口语化、可短句；师长/陌生人→正式、礼貌、间接、先共情。
- 称呼/落款匹配语域。
- 依据：语用知识必修第1条、选必第3条（"书面交际按对象身份、事由、正式程度选择得体语言形式"）。

**③ 连贯 & 合体裁（课标语篇知识 p22-24）**
- 开头点明目的 → 主体覆盖要点 → 得体结尾。
- 高频显性衔接（first / also / what's more / in a word…）、主题句、过渡句。
- 依据：语篇知识必修第2条（应用文基本格式结构）+ 第5条（显性衔接）+ 第6条（段首/主题/过渡句）+ 选必第7条（句群逻辑：次序/因果/概括例证）。

**④ 语言 —— 服务以上，不喧宾夺主**
- **课标词 + 高频短语为主**，不堆生僻（用 realize 不用 acknowledge，用 have a good time 不堆 pleasurable experience）。
- 主体自信运用**必修(\*)级**较高结构（见 §2）。
- **刻意埋 3–5 个"够得着的高级句"作亮点**，"好"集中在这几处，其余朴实可复现。

**⑤ 格式 & 词数**
- **合体裁**——书信/邮件用称呼+落款；**报道/投稿用标题+正文（不用称呼落款，别硬套 Dear/Yours）**；演讲用呼语开场。用好题面给定的骨架（标题/称呼/开头句/落款）。（2020 报道、2021 投稿压测证实：必须体裁自适应。）
- **词数 = 仅学生所写部分（不含题面已给的称呼/开头句/落款），目标 110–120，瞄 ~113–117，绝不破 120**（评分原则第3条：少于80或多于120扣2分）。**要写"满"**——即使题面写"80左右"，安全区是 80–120，写满到上限内更能拿分。owner 2026-06-05 定。
- 拼写体系前后一致（统一英式或美式；评分原则第5条英/美拼写均可）。

## 2. 语法天花板分级（课标语法项目表，附录3 p133-140）

星级 = 课标分级 = "够得着"的精确刻度。

| 级别 | 代表结构 | 范文用法 |
|---|---|---|
| **必修(\*)** | 限制性定语从句；非谓语（不定式作定语/结果状语，-ing/-ed 作定语/状语/补语）；**省略句**；进行/完成时被动 | ✅ **主力**——范文主体自信用这些 |
| 选择性必修(\*\*) | 非限制性定从；主语/表语从句；将来进行/过去完成/现在完成进行时 | ⚠️ **伸展区**——亮点句可偶触 |
| 选修提高(\*\*\*) | 倒装；**强调句**；**虚拟语气**；同位语从句 | 🚫 **高考之上**——绝不满篇堆 |

**判断题裁定（owner 拍，2026-06-05）**：**范文主体严守水平二（必修\*级语法 + 清晰得体连贯）；仅当任务的交际行为确需时（如对师长的委婉请求 "Would it be possible…?" = 虚拟语气\*\*\*），亮点句可伸向至多 1–2 个 \*\*/\*\*\* 级结构、作为"既得体刚需、又可学"的高分句明确标出；绝不把 \*\*\* 级复杂当装饰满篇撒。**

## 3. 词汇准则

- 以**课标词汇表（附录2 p73+）**为范围；丰富性 = 课标词内的恰当多样，不是生僻炫技。
- 校验期可用 `guokao-vocab-checker` skill 查超纲（带中文注释的超纲词可接受、未注释超纲词需改）。

## 4. 亮点表达（Highlight Expression）甄选准则

- 选 **3–5 个可迁移的框架句**（开头点目的 / 共情 / 委婉请求 / 例证过渡 / 表态感受 / 得体结尾），**不选只适用本题的内容句**。
- 每条 `{text, note}`：`text` 必须在范文中**逐字出现**（强制"从范文里挑"、不许现编）；`note` 用中文讲**功能 + 怎么迁移套用到别的应用文**，让弱一点的学生也能学着用。

## 7. 三源关系（地基判定，2026-06-05）

**课标为纲、外脑为操作手册、评分为尺**，三者经本准则已自洽——外脑（一线老师外脑）≈ 课标"核心素养/真实交际"理念的课堂操作化，**无方向性打架**。两个要知情的接缝：
- 真正的张力是 **外脑 ↔ 评分标准**（评分奖励"复杂高级"、外脑说复杂非关键）；**课标站外脑这边**（复杂=水平三、高考封顶水平二），故"课标为纲"恰是裁判：评分的"复杂高级"读成"必修内的范围与控制"。
- **唯一向应试评分让步、略偏课标/外脑"交际本位"的是 §1⑤「写满 110–120」**——知情接受（学生要分）。
- 外脑"思维深度"主张的**护栏 = §1① "感想从过程长出来、不贴万能升华句"**（机械追深度会反噬成套路升华，2024-i 首测即此病）。
