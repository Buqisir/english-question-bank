# 完形填空：怎么讲（第 3 版）

## 这份讲解是干什么的

老师拿它讲课，学生拿它订正。完形的空不是随便挖的，大多数空落在文章的主线上：人物的关键动作、情感的转折、对一件事的概括、点题的那个词。讲解要让学生看到这一点，做题的过程也就是读懂文章在说什么的过程。

讲解分两层：

- **题组开头**：这篇文章的主题意义和主线。
- **每个空**：脉络说这个空在这里必须是什么意思；找法说原文哪几个词把答案锁定，从词性入手；错项三个都写。
- **题组结尾**：把主线上的空串起来。

## 题组开头

### 主题意义（theme）

一句话：这篇文章最后想让读者明白什么。不超过 40 字。依据是原文点题的地方（常在末段，有时在首段），在 `quote` 里原样抄一处，并让它原样出现在这句话里。只写原文推得出的意思，不写原文没有的道理。

### 主线（lines）

每段一句，写这一段把主线推到哪里：发生了什么，人物的处境或态度怎么变。不超过 30 字。段数和原文一致，按顺序。

### 情感线（emotion）

记叙文写人物情感怎么变，用「→」连，如「失望→不服→释然」，不超过 40 字。说明文、议论文没有明显的情感变化，写空字符串。

## 每个空

### 先分主线空和细节空（role）

- **主线**：把答案换成错项，这一段推进主线的那件事就说不成了。人物的关键动作、情感的转折点、对前后一件事的概括、点题的词，通常是主线空。
- **细节**：换成错项，只是本句说不通，主线照样往下走。
- 拿不准就标细节。不要为了显得每个空都有意义把细节空标成主线。

### 1. 脉络（context）

不看选项也能说出的那句话：这个空在这里必须是什么意思。可以说它是正是负、是哪一类动作、是在概括前面哪件事，还是在引出后面哪件事。不超过 45 字。

- 主线空：说清它在主线的哪一步（转折、低谷、概括、点题等），用这篇文章自己的事和词来说。
- 细节空：只说这一句需要什么意思，不往主题上挂。
- 不写「体现了……精神」「升华了主题」这类话。
- 不写本空的题号，题头已经印了。提到别的空时说「前一空」「后面那一空」，或者直接引原文的词。

### 2. 找法（find）

脉络说「要什么意思」，找法说「原文哪几个词把它锁定」。两行不要说同一句话。

写成「考点名」加「怎么做」。考点名从这八个里挑一个：看搭配、看复现、看话题、看动作顺序、看情感、看走向、看语境义、看逻辑。页面会在前面自动加上词性，印成「名词看复现：……」。「怎么做」写出往哪里找、原文哪几个词（英文原样抄，页面会加粗）、这几个词怎么锁定答案。不超过 55 字。

从词性入手。下面是各词性的常见情况，帮你想到该看哪里，不是每个空都要对上一条：

- 所有词性的基础都是搭配：放进句子里，谁做什么、什么修饰什么，说得通。大多数动词空看搭配就够了，不要为了显得有技巧去找别的考点。
- 动词：主语发不发得出这个动作，宾语受不受得住；后面跟的介词或结构常常直接定下动词（dream of、pair A with B）；前后两个动作夹出中间那个时看动作顺序，只有先后顺序本身决定答案才算；表态度的动词（hate、admire）可以看情感。
- 名词：最常见的是复现，包括原词、同义、反义、上下义，还有概括复现，即用一个抽象名词把前后的具体事说成一个词，线索常是冒号、such、this、that；名词也考话题，文章讲哪个领域，四个里只有一个属于它；名词也有褒贬。
- 形容词：情感正负，前后一致还是翻转（but、yet 翻，and、also 同向）；递进（and even、and often 后面的更重）；它修饰的那个名词。
- 副词：过程的走向（长期下来的结果、常态、突然）；程度。
- 词组：好的空四个放进去语法都对，只能靠意思，看语境义；熟词僻义要点出来；小品词定方向（down、up、to）。固定结构按词组算。
- 连词、逻辑副词、表逻辑的词组（however、instead、otherwise、let alone）：看逻辑，前后是转折、因果、递进还是让步。只有四个选项本身是这类词时才用看逻辑。句子里有 but、although 这类信号词、靠它定下正负的空，仍是看情感；靠它定下动作的，仍是看搭配或看动作顺序。
- 复现不限于名词，任何词性都能用。

主线往往直接告诉你看哪里：情感线定下形容词、副词和表态度的词的正负；主线上的动作链就是动作顺序；主线上一件事说完，后面常用一个名词概括它；段与段之间的转折常落在逻辑词上。用上了就写出原文的词，不要只说「符合情感线」。

### 3. 错项（distractors）

三个错项都写。每项写：这个词放进这句是什么意思，原文哪个词让它不成立。好的空放进去语法都对，错项靠意思排除；只说「原文没有这回事」不算排除，要说出原文写的是什么。有的错项放进这一句也说得通，但会让主线断掉，这时就用主线排除，说出放进去以后前后哪件事对不上。不超过 45 字。

## 题组结尾：串空（thread）

把你标成主线的空，挑能串起全文骨架的，按题号顺序串成一句，让学生看到这些空连起来就是文章在讲的事。每个串进去的空写出它的答案词（原样，英文），可以在后面括注中文。不超过 80 字。`blanks` 写串进去的题号，至少 3 个，只能是主线空。

## 写完做一次搬家检验

把一句脉络或找法原样搬到这篇的另一个空上，还成立的就是套话，重写。「根据上下文，此处应填……」「与语境相符」「符合文意」「体现了作者的情感」都过不了。

## 哪些必须照做，哪些你自己判断

必须照做：

- 输出格式、字段和长度上限。
- 考点名只用上面八个。
- 主题意义、找法、每个错项都至少引一处原文，英文原样抄（大小写、词形都不改），不引空位标记（`__41__` 这种）。引的词必须原样出现在你写的那句话里。
- 答案是给定的，不改，不重新解题。
- 不用「·」做分隔。

你自己判断：

- 每个空是主线还是细节。
- 每个空用哪个考点：选最能让学生下次照着做的那一个。拿不准就用看搭配，写清是哪两个词搭在一起。
- 怎么措辞，不用套固定句式。
- 错项为什么诱人：原文撑得住时可以带半句，不强求。

## 例子（编的，和你要做的卷子无关）

原文：
- 第 1 段：Last spring our school started a garden on the empty roof. Most students thought growing vegetables in the city was a waste of time.
- 第 2 段：Mia joined anyway. She __1__ (A put up　B put off　C put out　D put away) a sign that read "Please don't step on the soil." For weeks nothing grew, and even Mia began to feel __2__ (A hopeful　B discouraged　C proud　D curious).
- 第 3 段：Then one morning she noticed tiny green __3__ (A shoots　B stones　C insects　D papers) pushing through the soil. By June the roof was full of tomatoes. Most students had laughed at the idea. __4__ (A Besides　B However　C Therefore　D Otherwise), twenty of them now asked to join.
- 第 4 段：Mia smiled. Sometimes the best way to change people's minds is to show them, not tell them.

答案：1 A，2 B，3 A，4 B

题组开头：
- 主题意义：要改变别人的看法，做给他们看比说服更有用，即 show them, not tell them。
- 主线：第 1 段 学校开屋顶菜园，多数人觉得白费功夫。第 2 段 Mia 独自坚持，几周没长东西，她也泄气。第 3 段 菜苗冒出，番茄满园，嘲笑的人要求加入。第 4 段 Mia 点出道理。
- 情感线：坚持→泄气→惊喜→欣慰

每个空：
- 1（细节）脉络：她立了一块提醒别踩土的牌子，这里要「竖起、挂出」的意思。找法：词组看语境义：宾语是 a sign，牌子上写着 Please don't step on the soil，是把牌子立起来，put up。错项 B：推迟；推迟一块 a sign 说不通。
- 2（主线）脉络：坚持几周没有结果，这是全文的低谷，要一个负面的情绪。找法：形容词看情感：前面 nothing grew，even 说连坚持的 Mia 也动摇了，四个里负面的只有 discouraged。错项 A：充满希望；前面是 nothing grew，even 表示连她也撑不住了，和 hopeful 反着。
- 3（主线）脉络：低谷后的转机，要一样从土里长出来的东西。找法：名词看话题：讲的是 garden，又是 pushing through the soil，长出来的绿色东西是 shoots。错项 C：昆虫；虫子不会 pushing through the soil 变成后面的 tomatoes。
- 4（主线）脉络：前句说大家笑话这事，后句说他们要加入，态度翻过来了。找法：副词看逻辑：Most students had laughed at the idea 和 twenty of them now asked to join 前后相反，用转折 However。错项 C：因此；laughed at the idea 推不出 asked to join，不是因果。

串空：discouraged（泄气）的低谷之后，土里冒出 shoots（菜苗），However 一转，嘲笑的人都来加入。

## 输出

只输出一个 JSON 对象：

```
{
  "group": {
    "theme": { "text": "要改变别人的看法，做给他们看比说服更有用，即 show them, not tell them。", "quote": "show them, not tell them" },
    "lines": [ { "paragraphId": "<原文段落的 paragraphId>", "text": "学校开屋顶菜园，多数人觉得白费功夫。" } ],
    "emotion": "坚持→泄气→惊喜→欣慰",
    "thread": { "text": "discouraged（泄气）的低谷之后，……", "blanks": [2, 3, 4] }
  },
  "blanks": {
    "<questionId>": {
      "role": "主线",
      "pos": "形容词",
      "context": "坚持几周没有结果，这是全文的低谷，要一个负面的情绪。",
      "find": { "check": "看情感", "text": "前面 nothing grew，even 说连坚持的 Mia 也动摇了，四个里负面的只有 discouraged。", "quotes": ["nothing grew"] },
      "distractors": [ { "label": "A", "text": "充满希望；前面是 nothing grew，even 表示连她也撑不住了，和 hopeful 反着。", "quote": "nothing grew" } ]
    }
  }
}
```

- `role` 只能是：主线、细节。
- `pos` 只能是：动词、名词、形容词、副词、词组、介词、连词、代词。
- `lines` 每段一项，`paragraphId` 和原文一一对应，顺序相同。
- `find.text` 不以考点名开头。`find.quotes` 是你在 `find.text` 里引的原文，每个都原样出现在 `find.text` 里，也原样出现在原文里。
- `distractors` 正好三项，是答案以外的三个选项；`text` 是「意为：」后面那句（不重复选项词）；`quote` 原样出现在 `text` 里，也原样出现在原文里。
- `thread.blanks` 是题号（数字），按顺序，至少 3 个，都标了主线；每个空的答案词原样出现在 `thread.text` 里。
