# Koboyo SVG 风格研究与路线记录 v1

- **研究日期**：2026-08-11
- **用途**：高中课标 3000 词视觉资产
- **结论状态**：代表图研究已完成；原创与母版改编试产均被 Owner 视觉否决。当前正式路线是逐张选择未改 Koboyo 原图，并采用 `direct-sense` / `sentence-scene` 双模式
- **研究范围**：Koboyo 官方图标页、官方授权页，以及仓库内 90 张高中黄金样本、1600 张万唯正式 SVG 和 30 张重复的校准副本

## 1. 结论先行

1. Koboyo 官方目录继续作为**逐张选择的现成资产来源和风格研究样本**，但不应被整体镜像。
2. Koboyo 不是单一视觉风格。官方目录同时包含 `mark`、`object`、`people`、`scene`，并细分为 `solid`、`texture`、`mascot`、`playful`、`concept`、`action`、`profession`、`vignette` 等系列；它们共享“手绘 SVG”与 `currentColor` 等技术特征，但人物比例、轮廓密度、写实程度和构图复杂度明显不同。
3. 直接仿画该风格和以人物母版做 path 改编的两轮试产都没有达到 Owner 的视觉标准；这些产物只保留为失败证据，不进入正式视觉 manifest，也不再作为当前生产路线。
4. “抽象词找不到图”的根因不是图库数量不足，而是拿关系词本身去搜索具体画面。当前路线先找直接教学义图；找不到时，把一条已批准例句转成具体场景查询，再逐张选择未改 Koboyo 原图。
5. 现行检索、图句绑定、界面共现和 QA 合同以 [`visual-binding-policy-v1.md`](./visual-binding-policy-v1.md) 为准；本文第 5–8 节仅保留历史试验的技术与判断依据。

## 2. 官方事实与授权边界

### 2.1 官方目录事实

Koboyo 官方图标页在本次研究时列出 105,035 个图标，并将目录划分为 `face`、`mark`、`object`、`people`、`scene` 等顶层组；其中又有 `solid`、`texture`、`mascot`、`playful`、`concept`、`action`、`profession`、`group`、`vignette` 等差异很大的子组。数量会随官方更新而变化，本文只把它作为 2026-08-11 的目录快照，不把数量写成永久事实。[Koboyo 官方图标目录](https://koboyo.com/icons)

官方分类本身已经证明“手绘”只是一个大伞，不等于单一造型体系：

- 人物动作覆盖运动、工作、问答、情绪和复杂场景。[people / action](https://koboyo.com/icons/set/people/action)
- 职业人物同时有单人头像、持物动作和工作场景。[people / profession](https://koboyo.com/icons/set/people/profession)
- 物体中同时存在抽象概念、吉祥物和 playful 画法。[object / concept](https://koboyo.com/icons/set/object/concept)、[object / mascot](https://koboyo.com/icons/set/object/mascot)
- 场景和实心标记又是另外两类构图密度。[scene / vignette](https://koboyo.com/icons/set/scene/vignette)、[mark / solid](https://koboyo.com/icons/set/mark/solid)

因此，“照着 Koboyo 风格画”不是可执行说明；必须进一步指定采用哪个子风格、排除哪些子风格。

### 2.2 官方授权允许什么

官方授权页当前明确允许：

- 个人和商业用途；
- 用于网站、应用、文档、演示、图表、视频和印刷品；
- 改色、缩放、裁切、动画及其他修改；
- 嵌入销售的更大产品，只要图标不是产品本身；
- 无需署名。

来源：[Koboyo Icons 官方 License](https://koboyo.com/icons/license)

对本项目的直接含义是：把少量 Koboyo 图标嵌入“高中课标 3000 词”这个更大的教学产品，且用户不能把图标当图库挑选、提取和下载，按官方文字**看起来属于允许范围**。

### 2.3 官方授权禁止什么

官方授权页当前明确禁止：

- 把整个图库或其重要部分作为图标集合转售或再分发，不论是否修改；
- 用这些图标建立竞争图标产品，或类似 Koboyo 的画布、白板、制图、演示、绘图应用；
- 把图标打包进“图标本身就是主要功能”的应用，或让用户挑选、提取、下载、再次分享图标；
- 声称自己创作了该图标集合，或基于它注册标识。

来源：[Koboyo Icons 官方 License](https://koboyo.com/icons/license)

对本项目的约束：

- 不再全量或大批量镜像 Koboyo；
- 不提供视觉资产浏览器、原始 SVG 下载、复制 SVG 或导出图标集合的产品功能；
- 若使用现成 Koboyo 图，产品内部可不展示署名，但资产清单仍保存来源 URL、官方名称、抓取日期和哈希，便于追溯；
- 不把 Koboyo 图打包成可复用“EQB 图标库”对外发布；
- 在线授权声明可能变化，正式发布前应重新核对官方页面。

官方同时声明图标库按现状提供、不作保证，并以“在版权存在的范围内授权”的方式表述。本文不是法律意见，也不把任何方案称为绝对零风险。

### 3.2 1690 张规范样本的结构事实

| 指标 | 结果 |
| --- | --- |
| 根级颜色 | 1690/1690 使用 `fill="currentColor"`，没有 `stroke` 画法 |
| SVG 元素类型 | 只出现 `svg`、`g`、`path`；174 张使用一个带 transform 的 `g` |
| 可执行或外来内容 | 0 个 `script`、`foreignObject`、`image` 或外链 `href/src` |
| Path 数 | 1 条：532；2 条：963；3 条：157；4 条及以上：38；中位数 2 |
| ViewBox | 宽中位数 194，高中位数 196，宽高比中位数 1.0 |
| 画幅方向 | 方形 633；竖向 541；横向 516 |
| 文件体积 | P25 约 1.6 KB；中位数约 2.9 KB；P90 约 5.9 KB；最大约 21.8 KB |

这些结果说明可继承的稳定技术外壳是：单色 `currentColor`、纯本地 path、很少的 path 数和近方形画布；它们并不能证明所有画面共享同一人物或物体风格。

### 3.3 “不是单一风格”的本地证据

同一批本地 SVG 至少同时存在以下视觉语言：

- 圆润的年轻人物线稿，例如庆祝、持物和团队动作；
- 更写实、细节更多的老人正面肖像；
- 大面积实心吉祥物，例如黑猫搭积木；
- 白底粗轮廓的自然动物，例如大象；
- 极简符号，例如勾、箭头、感叹号；
- 高密度信息图，例如全年日历；
- 多建筑场景，例如一排运河房屋；
- 文化地标和器物，例如 Big Ben、长城、茶炊、斗兽场。

如果把这些画法都用在同一套词卡里，技术格式虽一致，视觉产品仍会显得像从多个图库随机拼接。内部规范必须做取舍。

## 5. 历史 EQB Hand-drawn Monochrome v1 参数（当前未授权）

### 5.1 SVG 技术外壳

> 2026-08-11 试产修订：第一版把“只用填充 path”误做成了粗硬的几何信息图，Owner
> 明确否决其视觉质量。第二版 Owner QA 之前改用可编辑的 `currentColor` 圆润原生
> stroke 加少量实心发块，先验证人物动作与插画感；若视觉通过、生产合同仍要求
> path-only，再在不改变外观的转换步骤中把 stroke 展开为轮廓。技术格式不得凌驾于
> 视觉风格，未通过视觉 QA 的几何稿不保留为候选。

> 同日第二次修订：Owner 进一步否决“从空白画布模仿人物”的路线，要求直接以库内
> Koboyo 人物 SVG 为母版做语义改编。当时 12 张试产因此分类为 `koboyo-adapted`，
> 允许保留母版 path，但必须逐张记录母版 Entry、官方页面、原始哈希、修改说明与新
> 哈希；不得再标记为独立原创。这是最终否决前的中间记录，不构成当前授权。

> 同日最终决策：Owner 视觉 QA 继续否决 `koboyo-adapted` 试产。独立原创和母版改编
> 两条路线均关闭，不得把下文参数、12 张清单或完成门理解为当前授权。当前只使用
> 未改 Koboyo 原图：能直接对应教学义时采用 `direct-sense`；不能直接对应时，以一条
> 已批准例句为语义锚点采用 `sentence-scene`，并强制图与原句共同出现。

以下参数只记录当时如何验证原创路线，不再构成生产要求。历史原创图默认遵守：

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 256 256" fill="currentColor" aria-hidden="true">
  <path d="..." />
</svg>
```

强制参数：

| 项目 | 规则 |
| --- | --- |
| 画布 | 统一 `viewBox="0 0 256 256"`；不写固定 `width`、`height` |
| 颜色 | 只用 `currentColor` 和透明负形；不写固定颜色、渐变、滤镜、阴影 |
| 元素 | 生产版只允许 `svg`、可选 `g`、`path`；不得有 `script`、`foreignObject`、`image`、字体或外链资源 |
| Path 数 | 目标 1–3 条；确有必要最多 4 条；不能为绕过限制把外部图压成一个超长 path |
| 安全边距 | 四周 20–28 单位，主体常规包围盒约 200–216 单位 |
| 轮廓厚度 | 由于采用填充 path 模拟线稿，主轮廓视觉厚度约 5–7 单位，内部细节约 3–5 单位 |
| 最小细节 | 任何独立黑形或白洞短边不小于 4 单位；64 px 显示时仍能辨认 |
| 文件体积 | 目标 1.5–6 KB；超过 8 KB 必须说明语义必要性并简化 |
| 可访问文本 | SVG 本体不嵌词义文字；中文 `alt` 继续由 manifest 保存 |

### 5.2 通用造型语言

- 单色白底感，黑形既承担外轮廓，也承担发型、瞳孔和强调部分；内部白洞形成脸、衣服和物体结构。
- 主轮廓圆润但不机械等距，允许轻微不对称；不增加随机毛刺，不追求“故意画坏”。
- 一个画面只设一个核心语义锚点。默认一个主体，可有 1–2 个必要配件；除“群体”义外不超过 3 个人物。
- 主要轮廓在 64 px 下先被识别，细节只用于消歧，不用于装饰。
- 不以文字、首字母或完整单词代替图像；数字只在时间、数量等无法避免时使用。
- 抽象词优先用“对照、关系、方向、状态变化”表达，而不是随便套灯泡、握手或问号。
- 一个图优先绑定一个最重要教学义。不同义项不能自然融合时，不把多个象征物硬塞在一张图里；manifest 明确该图服务哪个义项。

### 5.3 人物规范

| 人物类型 | 比例与识别规则 |
| --- | --- |
| 普通成年全身 | 头高约全身 22%–27%；肩略宽于头；四肢为圆润长形，手脚适度放大以保留动作 |
| 普通成年半身 | 头部约占图高 34%–42%；道具与手形成第二识别区，不让衣服细节抢主体 |
| 儿童 | 头高约全身 27%–32%，躯干和四肢更短；不靠婴儿用品以外的刻板符号 |
| 老年人 | 通过发际、轻微姿态和少量面部线表示；不复制高细节肖像式皱纹 |
| 多人 | 共享同一身体骨架和轮廓厚度；通过发型、姿势、身高和一个道具区分，不靠肤色 |
| 动作 | 肩、肘、手和道具形成清晰方向；手部不追求解剖写实，但接触关系必须可信 |

男人和女人使用同一套头身比例、眼鼻口和动作规则。只有词义确实要求性别时，才用少量发型或服装轮廓辅助区分；不得把领带、裙子、王冠、职业或家务道具当成默认性别编码。

面部默认使用点状眼、一个短鼻形和一条短口形；情绪主要由眉、口和姿势表达。单人普通词卡不采用写实肖像、复杂牙齿、密集皱纹或细碎发丝。

### 5.4 物体、动物、场景与抽象概念

| 类型 | 规则 |
| --- | --- |
| 普通物体 | 采用最有辨识度的正视、侧视或轻微三分之四视角；只保留 2–4 个类别特征 |
| 工具与设备 | 略放大功能部件，例如扳手开口、相机镜头、键盘屏幕；按钮和孔洞不能变成噪点 |
| 食物与植物 | 用切面、叶片、孔洞或容器消歧；不靠颜色才能认出 |
| 动物 | 默认自然卡通线稿，不默认变成吉祥物；耳、鼻、尾等类别特征可适度夸张 |
| 建筑与交通 | 轮廓优先，减少窗格、砖缝和机械小零件；不画复杂透视 |
| 小场景 | 主体占画布约 55%–70%，背景只保留一个地点锚点；不要做全景插画 |
| 抽象概念 | 优先使用前后对照、包含关系、连接关系、路径和状态变化；每种隐喻都要能用一句中文解释 |
| 时间与历史 | 用时间线、先后位置、刻度和方向表达，不用某个地区的地标替代整个时期 |

## 6. 历史原创与相似度边界（当前未授权）

### 6.1 创作流程边界

每张原创 SVG 必须从“词条教学义 → 一句话画面命题 → 空白 256 画布”开始：

1. 先写画面命题和唯一主语义，不先打开某一张 Koboyo 图照着改。
2. 可同时查看代表矩阵中 3–5 张不同题材的图，只提取共同的轮廓、留白、比例和复杂度规律。
3. 在空白画布建立自己的构图和几何骨架。
4. 不复制、导入、平移、缩放、镜像、变形或重排任何 Koboyo `path d`。
5. 不描摹单张参考图的独特姿势、视角、道具组合、五官布局或负形洞口。
6. 导出后保存原创说明、目标教学义、参考类别、文件 SHA-256 和 QA 结论。

官方授权允许修改现成图；“不得复制 path”是本项目为了建立清楚原创来源、避免把派生图误称为原创而增加的内部边界，不是假称官方授权要求。

### 6.2 自动相似度门

试产阶段至少执行：

- 新 SVG 与 1690 张规范样本做文件 SHA-256、规范化 XML 和规范化 `path d` 完全相等检查，必须全部不相等；
- 把 path 命令和数值归一化后做长片段匹配，不得出现来自任一参考文件的连续路径片段；
- 统一栅格到 256×256 二值遮罩，与全部参考图做感知哈希和轮廓重叠筛查；高相似候选进入人工复核，不把某个数值阈值误称为法律安全线；
- 人工复核主体姿势、镜头、道具排列、负形结构和整体剪影；只要普通人能立刻指出“就是某张参考图换了点细节”，即退回重画。

### 6.3 不可接受的伪原创

- 下载一张 Koboyo 图后改文件名、颜色或 viewBox；
- 只镜像、旋转、拉伸、裁切或增删一个小道具；
- 把两张 Koboyo 图的 path 拼成一张；
- 让模型“照着这张图画一个几乎一样的”；
- 复刻某张参考图的独特姿势和构图，只重画曲线；
- 将现成 Koboyo 图误标为 `original`。

## 7. 历史 12 张原创 SVG 试产建议（已终止）

这 12 张不是随便挑难词，而是从现有 90 张中选择“当前图只能靠联想、只覆盖了偏义，或文化指向不准确”的条目。试产目标是验证我们的原创语义能力，不是一次解决全量。

| # | 词条 | 当前牵强点 | 原创画面命题 | 首要 QA |
| ---: | --- | --- | --- | --- |
| 1 | `as` | “老师拿书”不能直接表达“作为/如同” | 一个人在普通身份与职业角色之间切换，中间用同一人物轮廓连接，服务“作为” | 不看词能否说出“作为某种身份” |
| 2 | `about` | 警示对话框更像 alert | 中央一个主题物，周围两个人的对话都指向它，服务“关于” | 不能误读成“警告/聊天” |
| 3 | `paragraph` | blockquote 竖线不是段落 | 三组短横线形成正文，其中一组有首行缩进并被括住 | 64 px 下仍能看出“一个段落”而非列表 |
| 4 | `miss` | “到达公交站”不说明已经错过 | 公交车正离站，人物伸手追赶，站牌留在人物身侧，服务“错过” | 动作先后必须一眼明确 |
| 5 | `involve` | 人物摊手解释不表达包含或涉及 | 一个大任务圆环包住人物、文件和齿轮，人物与三者都有连接 | 能否看出“被包含/参与其中” |
| 6 | `account` | 讲故事的人过于泛化 | 三个事件节点按顺序进入一个叙述气泡，服务“叙述、描写” | 不误读成“读书/作者” |
| 7 | `appointment` | 握手更像 agreement | 日历日期与两个人同时到达同一地点，服务“约会、约定” | 不靠文字也能看出预定时间 |
| 8 | `manner` | 扶门只覆盖“礼貌”，不覆盖“方式” | 同一任务出现两条不同操作路径，人物选择其中一种，服务“方式” | 不误读成“选择/路线” |
| 9 | `context` | archived transcript 太像文件归档 | 中央一句话气泡，前后各有一条较淡化的上下文气泡并用括号包围 | 看出“前后语境决定中间含义” |
| 10 | `guideline` | ruler 是“尺子”的文字游戏 | 一条道路两侧有连续引导边界和方向标，人物沿线前进 | 能表达“指导原则”，不是普通路线 |
| 11 | `B.C.` | 斗兽场只代表特定地区，也可能晚于目标联想 | 一条时间线以共同分界点为中心，左侧箭头和较早事件节点突出 | 与 A.D. 成对时先后方向不混乱 |
| 12 | `AD, A.D.` | 城市天际线不能表达“公元” | 与 B.C. 共用时间线语法，突出分界点右侧和向后的年份节点 | 两张独立显示可懂，成对显示可比较 |

其中 `B.C.` 与 `A.D.` 应作为成对设计但输出两个独立 SVG；不得在 SVG 内写完整英文解释。`as`、`about`、`manner` 等多义词仍只让一张图服务一个首要教学义，其他义项由文字内容承担，避免再把多个象征硬拼在一起。

## 8. 历史试产完成门（已终止）

每张图都必须同时满足：

1. **语义**：Owner 不看文件名时，能说出与目标教学义接近的中文；不能只在解释后才成立。
2. **风格**：与核心 28 张放在同一网格中，不出现吉祥物黑块、写实肖像或高密度信息图的突变。
3. **小尺寸**：256、128、64 px 栅格均无断裂、糊块、细节消失或主体贴边。
4. **技术**：`currentColor`、纯本地 path、数字 viewBox、无脚本/外链/位图/字体，SVG 可解析。
5. **原创**：哈希、规范化 path 和感知相似度筛查通过，人工没有识别出单张参考图的独特复制痕迹。
6. **资产绑定**：每张具有独立 `visualKey`、中文 alt、SHA-256、版本和原创 provenance；不覆盖现有正式资产，直到 Owner QA 明确通过。
7. **产品表现**：真实词卡中前景色继承正确，桌面与 390 px 移动端均检查；不可只看独立 SVG 文件。

## 9. 当前执行路线

1. 以本文代表矩阵了解 Koboyo 各子风格，逐词检索官方目录；不把代表板扩大成批量
   抓库任务。

4. `sentence-scene` 只在显示其完整绑定原句和目标词高亮的界面出现；不得拿一张 A
   场景图解释 B/C，也不得在只显示单词的判断正面单独展示。
5. 两种模式都找不到合格原图时记录真实缺口并提交 Owner；不恢复独立原创、
   `koboyo-adapted` 或牵强配图。完整执行合同见
   [`visual-binding-policy-v1.md`](./visual-binding-policy-v1.md)。
