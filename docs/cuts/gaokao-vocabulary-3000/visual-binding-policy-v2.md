# 词汇视觉绑定策略 v2：最终每词必有图

- **状态**：Owner 决策已锁定（2026-08-12）
- **适用范围**：万唯初中 1600 词与高中课标 3000 词的视觉生产、QA 和正式接入
- **替代关系**：覆盖 `visual-binding-policy-v1.md` 中允许最终保留 `visual-gap`、禁止组合
  原始图库元素的条款；v1 保留为历史决策证据

## 1. 最终覆盖率

最终冻结 Set 必须做到每个 Vocabulary Entry 都有视觉资产。`visual-gap` 只允许作为生产
过程中的临时状态，不得进入最终 Owner QA 完成态、课程导入或公开产品。

这条覆盖率要求不授权把已经判定牵强的旧图原样塞回，也不降低图义 QA 标准。

## 2. 固定补图顺序

1. **直接词义原图**：优先使用一张未改 Koboyo 原始 SVG 直接表达冻结教学义。
2. **单图句景**：没有直接图时，从三条批准例句选择最适合可视化的一条，使用一张
   Koboyo 原始 SVG 表达完整可见场景，并绑定句 ID、版本和英文 SHA-256。
3. **旧图覆盖兜底**：仍找不到更准确新图时保留现有 Koboyo 原图，标记为
   `coverage-fallback` 和 `known_semantic_risk`，并强制与最贴近的批准例句共同显示；
   它满足“页面不可缺图”，但不获得语义合格结论，继续进入 Owner QA 和后续换图队列。
4. **人工组合句景**：只有逐张人工设计并通过小样 QA 后，才允许把 2–3 个逐张选择的
   Koboyo 原始 SVG 作为未改动组件排列成场景。自动批量组合不进入候选。

前三个层级保证任何阶段页面都有图；最终语义冻结仍应继续更换批准例句、扩大图库检索
或经 QA 的人工组合，逐步清除 `known_semantic_risk`，不能把覆盖兜底当成最终合格。

## 3. 组合句景边界

2026-08-12 自动组合试产抽样失败：`deep` 被组合成“炸锅 + 浴鸭”，形式上有图但比旧
潜水艇更牵强。因此自动批量组合路线关闭；下列边界只适用于以后逐张人工设计的小样。

- 只允许移动、缩放、裁切、统一颜色和排列已保存来源 receipt 的 Koboyo 原始组件；
- 不重画人物路径，不仿画 Koboyo，不凭空添加人物动作或句中不存在的事实；
- SVG 内不得写入目标英文词、中文释义或答案；文字和目标词高亮仍由界面提供；
- 每个组件都记录 slug、官方页面、官方 SVG、原始哈希和在组合中的语义角色；
- 组合资产另存到新版本目录，不覆盖任何 v1/v2 原始资产；
- 组合后的 QA 单位仍是“完整图片 + 精确绑定原句 + 目标词高亮”，不能裸图审核。

Koboyo 当前授权允许在网站、应用和教学材料中使用、缩放、裁切、重新着色及修改图标；
本项目仍保留逐组件来源 receipt，不批量镜像或把图库重新分发为独立图标产品。

## 4. 数据模式

最终绑定只允许：

- `direct-sense`
- `sentence-scene`

`sentence-scene` 的资产可为：

- `single-original`
- `composed-originals`

`composed-originals` 必须额外保存：

```json
{
  "composition": {
    "layout": "sequence",
    "components": [
      {
        "slug": "...",
        "role": "句中可见事实",
        "sourceSha256": "...",
        "officialSvgUrl": "https://koboyo.com/icons/svg/....svg"
      }
    ]
  }
}
```

## 5. 接入边界

- `direct-sense` 可以出现在无例句界面；
- 所有 `sentence-scene`，包括组合句景，只能与它绑定的完整批准例句和目标词高亮共同
  出现；句 ID、版本或哈希不一致时隐藏图片；
- 当前公开听写页没有同句显示能力，因此正式接入时不能裸放 `sentence-scene`；
- Owner QA 通过前，所有新绑定均保持候选状态且 `integratedIntoProduct=false`。

## 6. 完成门

1. Entry 数量完整，最终 `visual-gap=0`，每条均有本地 SVG 和可验证哈希；
2. 单图保存一份来源 receipt；组合图保存每个组件 receipt 与最终组合哈希；
3. 所有句义图能解析到原样批准例句，英文 SHA-256 一致；
4. 旧版资产字节保持不变；
5. QA 页默认展示旧图/新图、模式、绑定原句和理由，并支持逐词 Owner QA；
6. 1600 或 3000 条全部得到 Owner 结论前不得集成。
