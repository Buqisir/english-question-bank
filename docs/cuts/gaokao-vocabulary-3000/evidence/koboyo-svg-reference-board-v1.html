EQBank visual study · v1

48 张代表图，提取一个可持续的原创 SVG 子风格

这些样本覆盖人物、物体、场景、动作和抽象关系。它们用于学习高层视觉语法，不用于复制、描摹或机械变换任何 Koboyo 路径。Koboyo 本身包含多种表现形态；下方规则是题库自己的统一收敛。

Canvas256 × 256；20–28px 安全区；64px 仍可读
RenderingcurrentColor 填充 path；负形留白；不使用 stroke
Composition一个教学义、一个视觉动词、最多三个辅助组
Originality不复制、不描摹、不变形参考 path，只学构图与表达语法
