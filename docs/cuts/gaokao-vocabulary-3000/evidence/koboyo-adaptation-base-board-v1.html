12 张 Koboyo 人物母版

每张改编图从一个已验收的人物动作 SVG 出发，保留人物造型与线条，再修改语义道具或场景。成品标记为 Koboyo adapted，不标记为独立原创。

however ← either

人物置于两个相反选项之间。

beyond ← along

人物沿路线前进，可增加明确边界。

although ← hurry

保留赶路人物，增加雨云和晴朗目标。

throughout ← follow

把路径改为从头到尾的连续节点。

unless ← allow

把一般开门改为钥匙条件触发。

otherwise ← choose

把衡量两个选项改为替代分支。

despite ← difficult

保留阻力与继续行动。

indeed ← really

保留确认信息的动作。

somehow ← lost

把迷路改为曲折之后找到出口。

merely ← few

把少量任务收敛为仅有一项。

regardless ← come

增加两侧干扰，人物保持方向。

nevertheless ← climb

翻过障碍后继续朝目标前进。
