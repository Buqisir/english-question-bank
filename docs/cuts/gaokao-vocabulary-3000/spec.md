保留现有“中考词汇一轮1600词”，新增完整高中3000词课程。一个“过生词”
入口在开始页切换课程；同一学生在两套课程中拥有独立的进度、未结束轮次和
生词组。高中课程在3000词数据、图片、三例句及美英音频全部通过前保持隐藏。

高中课程必须复用现有冻结 Set、下载、二维码、公开播放器、自动听写和趣味
练习闭环；不得建立跨课程 Set，不得把中考判断迁移为高中掌握记录。

## 3. 内容与资产

- 完整保留源书义项，每词确定1–3个高考常见核心义。
- 每词保存三条已批准例句；优先覆盖不同核心义，核心义不足三个时才围绕同义
  更换场景。提示卡固定候选A，冻结 Set 稳定选择A/B/C。
- 先完成高/中/低频各30词的90词黄金样本，再自动推进全量。
- 中考与高中重合词只有在词形、词性、目标读音和教学义一致时才能复用已验收
  内容或资产；每次复用必须记录来源 Entry、版本和哈希。
- 每个高中 Entry 保持一个独立视觉绑定，模式只能是直接表达冻结教学义的
  `direct-sense`，或准确描绘一条已批准例句的 `sentence-scene`。Koboyo 只逐张选择
  未改动的原始 SVG，不批量镜像；每张保存官方页面、SVG 地址、版本、授权页、检查
  时间、哈希和中文 alt。句义图必须保存稳定的 `visualSentenceId` 与原句文本哈希，
  并且只与该条完整原句及目标词高亮共同出现；原句变化必须使绑定失败关闭并重新
  QA。没有合格直接图或句义图时保留视觉缺口并交给
  Owner 决策，不得以牵强图、`koboyo-adapted` 或未批准的原创图填数。完整检索、
  图句绑定和 QA 合同见 [`visual-binding-policy-v1.md`](./visual-binding-policy-v1.md)。
- 每词提供美音和英音。新冻结快照显式保存
  `audioVariants.american` 与 `audioVariants.british`；旧快照只读兼容。
- 新增或读音不同的美英音频必须由 Owner 逐词试听；精确复用项继承既有QA。
- 多词形条目朗读第一个规范词形，词组完整朗读。

## 4. 产品行为

- 一个入口页内切换课程，URL携带 `programId` 并记住上次选择。
- 过词进行中必须先暂停返回才能切换；每位学生每套课程可各保留一轮。
- 最近生词组和直接输入仅作用于当前课程。
- 高中默认从第1词开始，可用“查看 / 调整进度”点选任意Entry作为下一词。
- 判断正面仍只显示单词；提示卡和进度浏览器显示频率阶段、频序、课标标签和
  核心义。
- `direct-sense` 可以在只显示单词的界面单独出现；`sentence-scene` 不得脱离其
  `visualSentenceId` 对应的完整例句出现。提示卡当前固定候选 A，因此正式句义图
  原则上在冻结前选择并绑定 A；显示 B/C 的练习不得继续沿用 A 的句义图。
- 老进度、老Set、老二维码和公开接口不得失效或漂移。
