# 初中 1600 词图片全量复检与重选 v2

- **状态**：1600 条候选已生成并通过结构/哈希校验；全部等待 Owner 逐词语义 QA
- **适用课程**：`wanwei-round-one-v1`（初中一轮 1600 词）
- **语义政策**：初轮沿用 [`visual-binding-policy-v1.md`](./visual-binding-policy-v1.md)；
  最终覆盖率按 [`visual-binding-policy-v2.md`](./visual-binding-policy-v2.md) 执行，
  `visual-gap` 只作为待补生产状态
- **资产来源**：只使用逐张选择的 Koboyo 原始 SVG；不改画、不仿画、不批量镜像图库

## 为什么重做

旧版 `wanwei-visual-manifest-v1.json` 只记录图片路径、slug、alt 和哈希，没有记录图片
表达的是词义还是例句意，也没有稳定例句 ID 与原句哈希。因此：

- `hurt` 绑定的 `sling` 实际只是一个空吊带，alt 却写成图中不存在的“受伤手臂”；
- 连词、介词、代词等关系词即使找到合适句景，也可能在无例句界面裸放；
- 例句改变后，旧图片不会自动失效；
- 颜色词的 SVG 全部使用 `currentColor`，旧页面统一染成绿色，图片并未呈现目标颜色。

## 本轮做法

1. 对 1600 张现有图片逐条保存 Koboyo 官方标题、官方画面描述、官方 SVG 哈希与本地哈希；
2. 用冻结教学义和三条已批准例句全量判断当前图 `PASS` / `FAIL`；
3. `PASS` 原图保留；颜色词保留准确物体图，但把实际颜色作为强制渲染提示；
4. `FAIL` 先找准确 `direct-sense`，否则绑定一条完整批准例句成为 `sentence-scene`；
5. 两种模式都找不到准确原图时标记 `visual-gap`，不再为了凑齐 1600 张使用牵强图；
6. 新候选写入独立 v2 manifest、bindings 和资产目录，不覆盖冻结 v1 文件；
7. Owner QA 完成前不接入课程、数据库或公开听写页。

## `hurt` 的锁定修复

`hurt` 由三路独立质检共同判为失败：现图是孤立吊带，不能直接呈现“弄伤；受伤”，也
不对应 “She hurt her knee while running.” 的跑步伤膝盖场景。

本轮把它锁定为 `direct-sense`，候选原图为 Koboyo `person-cast-arm`：一名手臂打着
石膏的人。它不冒充跑步例句，但脱离句子仍能稳定表达“受伤”。该人工锁定不能被后续
模型改回 `sling` 或改成只覆盖半条例句的场景。

## 产品接入边界

正式接入前必须完成数据和消费合同：

- `direct-sense` 可在仅显示单词的界面出现；
- `sentence-scene` 只有当前例句的 candidate ID、version、英文哈希全部匹配时才显示，
  并与完整例句及目标词高亮构成同一可见单元；
- 公开听写当前不提供例句，所以必须隐藏 `sentence-scene`；
- v3 不再有 `visual-gap`；`coverage-fallback` 必须和绑定例句、风险标记共同显示；
- 生词集快照必须原子冻结视觉绑定；旧快照继续引用旧路径，不被新图静默替换。

本轮先生产可审候选，不提前修改数据库或公开产品。Owner QA 通过后，再以独立接入步骤
修改 schema、store、API 投影和真实 Screen/Print 消费路径。
