## 总纲：共创分工

算法、机审、批量工具归小川；**「味」的标准归 owner**。形式=**判例裁决制**：
小川只把拿不准的边界样本递给 owner 裁（一次十来条量级），owner 的判决
沉淀成判例集写进导题标准，校准未来管线。owner 不做逐条审卷员。

## 四轨顺位（R1 → R4）

### R1 体裁补真值（先行）

- **实测病灶**：`passages.discourse_type` 表面 100% 覆盖，实际存的是
  **题型名**（reading/cloze/sevenChoices/grammarFill/writing），与
  `group_type` 冗余。后果：相似题引擎两处配方空转——完形次序「同体裁」
  对硬池候选恒真；阅读「篇位 proxy」40% 权重的体裁匹配恒真。
- 词表五类：**记叙 / 说明 / 议论 / 应用 / 新闻**（owner 拍板：四大类+新闻，
  再细就标不准）。
- 存法：覆写 `discourse_type`（一次迁移，引擎读同一列，零 schema 新增）。
- 生产：AI 跑批 273 篇 + owner 判例抽检 gate。
- 落库后立即接线：修引擎两处假匹配（见目标配方表）。

### R2 干扰项（机审 → 判例 → 返修 → 才索引）

- **抽检基线**（2026-07-10，21 条分层盲审，小川代审 owner 认可）：
  约 14 对味 / 2 明确贴错 / 5 边界存疑。实锤两类病：①标签-解释自相矛盾
  （样本 #18：判「无中生有」但解释自己引了原文词钩）；②规范外野类型
  `timeOrderReversal` 1 例（schema gate 漏网）。「无中生有」占全库 40.6%
  （566/1395），是懒人桶重灾区。
- 机审刀（确定性全扫 1395 条）：野类型 / 各类子结构完整性（五类 trap
  各有子 schema，sourceLexicalTrap 用 sourceText/relationNote 而非
  sourceQuote/explanation——扫描器必须按类适配）/ 标签-解释自相矛盾 /
  懒人桶引证泄漏 → 产出返修清单。
- owner 裁边界判例 → 返修 → **返修完才立索引刀**接相似题
  （不可信的建议比没有建议更伤，绝不带病上 UI）。
- `timeOrderReversal` 要不要转正进受控词表：机审后看真实量再议
  （动词表=schema 变更，慎重）。
- 抽检器物：trap-audit 审卷页 + 分层样本入档本目录。

### R3 写作双 facet

- 定义（owner 拍板）：**应用文 → 功能型**（建议信/邀请信/申请信/通知/
  演讲稿…）；**读后续写 → 情节型**（困境成长/救援互助/比赛挫折/亲情
  和解…）。词表小川拟草案、owner 裁判例。
- 附带：48 组写作的**小类标注**（应用文 vs 续写，可从指导语/分值确定性
  推导）——相似题硬池按小类分，应用文与续写不互配。
- 完成后 similar-questions Q5 门槛解除，写作进相似题。

### R4 难度（压轴，不立项）

等 reading signals join 有真信号再议。**绝不再上一个撒谎的 medium**
（ADR-0008/0015 前车之鉴）。目标配方表中仅虚线预留「份量相当」加分轴。

## 话题体系（三台阶阶梯）

- **数据底**：492 标注 / 273 组（平均 1.8 标/组，多标签是设计且在用）；
  受控词表 90 原子（api.mjs `TOPIC_LABEL_TAXONOMY`），库里在用 67，
  零野标签；36 条课标条目→原子映射**已在代码**（`TOPIC_SUBTOPIC_ALIASES`，
  倒读即原子→条目，阶梯零人工梳理）。拆分经与课标原表逐条核对忠实。
- **阶梯**：同原子=满分（「同话题：××」）→ 同课标子主题条目=高分
  （「同课标子主题：××」）→ 同主题群=低分（「同域：××」；
  「生活与学习」158/492 一家独大，此档再打折）→ 一级（3 主题）不看。
- 阅读「话题不同」反向加分收紧为**跨主题群**才算拓展语境。
- **双胞胎裁定**（owner 直觉胜出）：近义原子对（乐于/善于学习等）标注
  实测二选一、几乎零共现（乐于/善于 13 组 0 共现），抖动真实存在，但
  条目台阶已兜住重逢——白名单合并提议**撤回**（不为微调养机制）。
  标注标准补一句：双胞胎任选其一即可。
- 数据小修：「生态环境」一女二嫁（词表同时挂自然生态+环境保护），
  收敛归**自然生态**（贴语义+与现有 2 条标注一致，映射表改一行）。
- **选材缺口**：宇宙探索主题群全库零篇——入生产线选题方向账。
