## Premise（票 03 / 06）

学生面本 spec 不实现，但要写进 spec 的红线。留下的场景只有：错题陪练、
续写/应用文教练、词汇陪练、讲评课后二次消化。IM Partner 与掌握路径已
出图。

已定、不必再问：

- 答案/讲评：EQB 工具层按 caller role 剥掉，不另建学生柜。
- 学生隐私不得进入可复用记忆；记忆 v1 是空位；学情报告后置。
- `member` 是普通老师，不是学生。生产 enforced 登录、0 个 member。
- 已有学生面先例：生词集分享 = 可撤销、不可猜的公开能力链接，只读，
  无学生账号。草稿卷 `studentLabel` 是自由文本，没有学生实体。

## Question

学生面四场景开放前必须定（写进 spec，本图不实现）：

1. **访问形态**：正式学生账号，还是类生词集分享的免账号能力链接？
   扫码进「套题专属辅导页」属于哪一种？
2. **确认边界**：现行「AI 服务于具名教师任务并经人工确认」；学生直面
   辅导是第一次突破。哪些输出免确认（对话本身），哪些仍须教师确认
   （进库的任何内容）？
3. **额度**：学生面若走 server key，会不会打满老师备课的全局日限额
   （默认 500）？本 spec 先写什么隔离？

## Resolution 记录

2026-08-13 grilling，owner 确认（按推荐）：

- **访问**：类生词集分享的能力链接；扫码进套题专属辅导页也是这种门。
  无学生账号。本 spec 不引入学生角色。
- **确认**：对话当时说的话免确认（关页即丢）；任何要进题库 / Analysis /
  给学生看的练习题，仍须老师确认。
- **额度**：学生面不得与教师备课共用这一条无隔离全局日限额；学生配额
  另定。第一期无学生面，本 spec 只锁这句话。
- **隐私（由访问形态推出）**：能力链接没有学生身份，故无 per-student
  记忆。学生话语不得进入可复用记忆。
