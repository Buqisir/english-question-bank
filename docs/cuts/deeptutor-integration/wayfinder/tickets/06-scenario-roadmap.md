### 变式题工坊（2026-08-13 grilling，owner 确认）

原票设想「生成变式、走后端导入确认」作废。变式拆成两步，DeepTutor Quiz
不进生产：

- **找** = 现有配相似（同题型硬池 + 考点密度，零 AI，勾选进草稿卷）。
  考点不同的真题不拿来充数。不换 DeepTutor RAG，不推翻配相似。
- **造**（找不到才造）= EQB 自己按语法填空 schema 调 LLM。提示词带种子
  题干 + 考点，输出锁死空/答案格式，不合法再修一次。不挂题库检索、
  不从阅读里捞语料、不搬 DeepTutor Python、不跑 DeepTutor 进程。
- **造的产物** = 教师个人练习题（`user-data`，非 Canonical），可进同一份
  草稿卷，必须标明「练习题 / 非题库」。不进官方库、不走导入。老师先用。
- **DeepTutor 出题**没有相似度算法，mimic 只是原题进提示词 +「仿写、别
  另起炉灶」。像不像不取决于搬不搬它的管线。它的产品独特处在 agent 循环
  / 学习 OS，不在出相似题。
- **后置**：跨题型找（阅读当冠词练习）、学生看见 AI 练习题、把 DeepTutor
  当造题服务。
