# EQB 小导师（DeepTutor 对照接入）

Status: accepted
Accepted: 2026-08-16 by owner
Wayfinder: `docs/cuts/deeptutor-integration/wayfinder/map.md`
Date: 2026-08-16

## Problem

港大 DeepTutor 看起来像「懂题库的导师」，但试装后不适合当生产引擎：建库
吃内存、检索是切段向量、Quiz 没有配相似、人设是通用 STEM 教练。EQB 要的
是对着**屏幕上这道题**备课追问，语境必须是 Canonical 对象，不能另养一套
知识库和进程。

## User outcome

老师在整卷浏览讲评栏里打开「小导师」，当前题已经在场，可以追问怎么讲、
这个空为什么填；要类似练习时先看到配相似卡片，勾选后那些题才进入对话。
港大进程不进生产。学生面本 cut 不实现，红线先写死。

## User stories

1. As 老师，我要对着当前题组问讲评思路，以便不用离开卷面另开聊天窗口。
2. As 老师，我要配相似的结果先以卡片出现、勾选后才被导师当事实，以便
   「为什么相似」仍由我决定。
3. As 老师，我要点回答里的题号回到卷面并点亮那一空，以便对话和卷面是
   同一道题。
4. As owner，我要生产零依赖港大 DeepTutor，以便 2C2G 的 `eqb-hk-1` 只跑
   EQB 自己的薄循环。

## Accepted decisions

### 形态

- eqbank.cc **自养小导师**。协议模仿港大循环（工具、澄清、引用对象），
  语境全是 EQB 对象。模仿验收 = 协议像，不是 UI 像。
- 屋子在架构里可挂：记忆、柜子、掌握。第一期只开门厅。
- 柜子 = Canonical Paper / Question Group / Analysis / 配相似结果的对象
  API。不做切段向量知识中心，不导出 Markdown 建库，不给港大进程做 MCP。
- 记忆 = 教师口吻；v1 不写。口吻后置为 EQB Skill。v1 用短备课系统提示，
  不模仿港大 STEM 教练人设。学生话语不得进入可复用记忆。
- 掌握 = 考点；v1 沿用配相似 / 错题再练，不另造知识点树。
- 港大 DeepTutor（Mac 1.5.12）只作对照机。动手前只对照：agentic 聊天循环、
  `prompt_blocks`、掌握路径状态机。Quiz 与前端不对照。不搬 Python 管线。
  生产不跑该进程、不代理其 HTTP/WS。

### 第一期门厅

- 落点：整卷浏览讲评栏里的「小导师」页签。打开默认停在小导师；「讲评」
  仍在同一栏。不新开列，不贴在题组底下，不做独立页。
- 首状态：当前题组、当前空、Analysis 已在场。缺 sidecar 则标明「解析未
  发布」，不编。
- 工具：当前题组（自动在场）+ `读题组` + `配相似`。
- 教师 `读题组`：篇章 + 题干 + 答案 + Analysis。
- `配相似`：模型可调；结果以现有配相似抽屉手感出卡片；老师勾选后才进入
  上下文。模型不得把命中直接当已读事实。写作题组 / 已下线的小题相似沿用
  现有引擎限制。
- 个人练习题不在 v1 柜（变式工坊的柜）。
- 引用：点引用回到卷面并点亮对象。
- 无「带走」成讲评候选。讲评草稿是教师第二期。
- 会话：关侧栏 / 关页即丢，不写 `user-data`。
- 流式：v1 整段返回。
- 降级：明确错误（含日限额 429），已在场题组还在；不改成无工具闲聊。
- 教师备课走现有全局日限额（默认 500、只计 server key、非 per-user）。
- 浏览器只见 eqbank.cc；凭据留 server，走现有 `completionRunner` 出站单点。
- 实现先本机；转正跑 EQB server。上生产另需 owner 授权。
- UI 证据：`design/deeptutor-prep-hall-prototype/index.html`（变体 A）。

### 场景阶段

- **第一期（本 spec 执行范围）**：教师备课对话面板。
- **教师第二期**（另开 cut）：讲评草稿助手（AI 起草 Analysis，人工确认后
  才进库）。
- **变式题工坊**（形态已定，不进第一期，不挡讲评草稿）：
  - 找 = 现有配相似（同题型硬池 + 考点，零 AI）。考点不同的真题不充数。
  - 造（找不到才造）= EQB 按语法填空 schema 调 LLM；种子题干 + 考点；不
    合法再修一次。不挂库、不从阅读捞语料、不搬 DeepTutor、不跑其进程。
  - 产物 = 教师个人练习题（`user-data`，非 Canonical），可进同一份草稿卷，
    必须标明「练习题 / 非题库」。不进官方库、不走导入。老师先用。
  - 后置：跨题型找、学生看见 AI 练习题、把 DeepTutor 当造题服务。
- **自然语言检索台**：不另做；沿用 steward。
- **学情报告**：后置，等记忆房间。
- **学生面留下、本 spec 不实现**：错题陪练、续写/应用文教练、词汇陪练、
  讲评课后二次消化。
- **出图**：IM 答疑 Partner、个性化练习路径（Mastery Path）。架构可挂，
  产品不做。

### 学生面红线（先写死，第一期不实现）

- 访问：类生词集分享的能力链接；扫码进套题专属辅导页也是这种门。不引入
  学生账号 / 学生角色。`member` 仍是普通老师。
- 答案/讲评：工具层按 caller role 剥掉。不另建学生柜、不分库。
- 确认：对话当时说的话免确认（关页即丢）；任何要进题库 / Analysis / 给
  学生看的练习题，仍须老师确认。
- 额度：学生面不得与教师备课共用这一条无隔离全局日限额；学生配额另定。
- 隐私：能力链接没有学生身份，无 per-student 记忆。学生话语不得进入可
  复用记忆。

## Test seams

- 门厅循环的对象边界：教师 `读题组` 含答案 + Analysis；学生 caller 被剥
  答案/讲评（第一期可只测教师路径 + 角色过滤函数）。
- `配相似` 勾选前不得进入模型上下文。
- 会话不写 `user-data`；关页后无续聊。
- 日限额 429 明示，不降级闲聊。
- 生产路径不得出现港大 DeepTutor HTTP/WS 代理或 KB ingest。

## Out of scope

- 各场景的具体实现与上线，除第一期门厅外均另开 cut。
- 恢复网站导入 UI；改 Canonical Paper / PaperSurface / 打印 / PDF。
- 港大 DeepTutor 当生产引擎或其 Web UI 当产品面。
- DeepTutor Quiz / mimic 作出题或变式生产路径。
- 第一期流式输出、持久会话、记忆房间、掌握路径产品、学生面实现。

## QA

第一期实现后：本机整卷浏览讲评栏打开小导师；当前题已在场；走一遍追问与
配相似勾选；点引用回卷面。按 `docs/agents/owner-qa-handoff-template.md`
交精确页。上生产另需当次授权。

## Open questions

无。口吻细节归后续 Skill，不挡第一期。
