# owner DP-3 对照单 — D1/E5/E6 归并实点（部署前本地 / 部署后生产复点）

前台真鼠标实点（面板 CDP 合成点击有盲区，判例在案）：

1. **详情页**：点开一篇阅读的详情 → 动作行有「相似篇章」→ 点它在
   hero 下方原地展开候选（卡带 chips：同为B篇/同话题·X/真题 + 池子
   诚实条）→ 点「＋ 加入草稿卷」→ 草稿卷计数 +1 + toast。
2. **搜索卡**：找题命中列表里任一卡点「相似篇章」→ 卡下方原地展开；
   再点另一张卡的 → 前一张自动收起。
3. **讲评态·完形**：整卷页讲评态选一道完形题 → 解析下方按钮文案是
   「相似篇章」→ 点击 rail 显示**篇章**候选（不再是报错+重试死循环）；
   种子行只有篇名不带"第N题"。
4. **讲评态·语法填空**：点「配相似」→ 小题相似照常（考点 chips 按 D1
   新词表：谓语·时态/非谓语作状语/名词的数 等粒度）。
5. **诚实空态**：找一篇无话题标签的组（库中有 7 组）点相似篇章 →
   明示"暂无话题标签"文案，不假装有候选。

全过 → 部署同批解门（deploy-remote.sh；D1 数据文件随 git 同步，无需
停服 apply）。
