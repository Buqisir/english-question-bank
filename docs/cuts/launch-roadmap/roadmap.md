# 上线路线图 v1（L 级，owner grill 拍板 2026-07-03）

八个主干决策由 owner 在 grill 中逐条拍板（PM 推荐全部被采纳），本文档是
唯一权威版本。改任何一条要重新过 owner。

## 决策记录

| # | 决策点 | 拍板 |
|---|--------|------|
| 1 | V1 用户层 | **熟人小圈，个位数**（owner + 信得过的同事/同行，可挨个打招呼） |
| 2 | 数据归属 | **共享馆**：题库读共享、写权限只有 owner；草稿卷/个人空间按用户私有 |
| 3 | 部署形态 | **境外（香港）轻量云单机**，Node + SQLite 原样上，**不换数据库**，免备案；配异地备份 |
| 4 | Auth | **邀请制**：owner 手工建账号/发邀请，密码（argon2）+ 签名 cookie session；无自助注册、无找回流 |
| 5 | AI 费用 | **统一 server key（owner 的 DeepSeek）+ 全局日限额**，触顶自动降级本地搜索；不做 per-user 配额 |
| 6 | 产品边界 | **一体化 AI 模式，对所有人（含 owner）是唯一界面**；经典模式走向整体退役，不再保留为 owner 策展后台（owner 2026-07-03 修订：原「member 只见 AI 模式、经典 owner-only」作废）。退役前提：经典模式独有的策展/管理功能先在一体化界面或独立入口接住。「key UI 迁移」工单**消亡**；topbar 按钮墙并入权限裁剪刀 |
| 7 | 数据流 | **两库分离**：`question-bank.sqlite`（共享馆，本地策展、整文件推上服务器）+ `user-data.sqlite`（服务器独有，部署永不碰） |
| 8 | 节奏 | **M0 → M1（owner 独用两周）→ M2（邀 2–3 同事）**；半公开门封存 |

关键排除项（都是"删掉一个工单比完成一个工单更好"）：
- 不换 Postgres/不上托管 DB——个位数用户，SQLite 单机绰绰有余；
- 不做微信/手机号登录——个人主体拿不到资质，V1 用不上；
- 不做导入管线产品化——同事不自建馆（决策 2 的推论）；
- 不做 per-user 配额/防滥用——熟人圈 + 日限额兜底足够。

## 里程碑

### M0 多用户地基（纯代码，本地可验证，不碰云）

按 cut 逐个做，每刀独立可验（两个浏览器 profile 当两个用户测）：

1. **两库分离手术**：`draft_papers` / `draft_paper_items` /
   `my_space_artifacts` / `my_space_folders` 四张用户表挪进
   `user-data.sqlite`，连接层双库（跨库引用走 ID + 应用层拼装，现状
   草稿卷本就按 ID 引题组）。一次性 schema 手术，当正经 cut 做，
   建议配 ADR。
2. **邀请制登录**：users 表（在 user-data 库）+ argon2 哈希 + 签名
   cookie session + 登录页。无邮件依赖。
3. **权限两档（owner/member）**：写共享馆的路由全挂 owner 闸；
   经典模式路由与入口 owner-only；member 只见 AI 模式。
   topbar 按钮墙收敛并入本刀（member 视角本来就该少见大半按钮）。
4. **用户数据隔离**：草稿卷/个人空间表加 user_id、查询圈范围。
   （前端 localStorage 工作篮是浏览器本地缓存，天然按人，不动。）
5. **AI 全局日限额**：计数器 + 触顶降级本地搜索 + 通知条人话说明。

### M1 上机（owner 独用）

- 香港轻量云服务器（¥30–60/月档）+ HTTPS + 域名（免备案解析）；
- 部署脚本：build + 进程管理 + **馆文件推送流程**（本地策展 →
  scp/rsync 替换 question-bank.sqlite + paper-assets，重启刷缓存）；
- **备份 cron**：两个 DB + paper-assets 每日推异地（对象存储或另一台
  机器）——单机 = 单点，题库是几年心血，此项不可省；
- 最小可观测：错误日志落盘 + uptime 探活。
- **验收闸：owner 两周日常备课全用远程版**，本地只留策展。

### M2 邀请同事

- 手工建 2–3 个账号 + 一页使用说明；
- **验收闸：至少一位同事无求助走完「找题→组卷→导出打印」**；
- 反馈清单决定 V1.1 范围。

### G 半公开门（封存，M2 反馈证明值得之前不开）

自助注册、per-user 配额、**内容授权分级**（真题无碍；机构模拟卷版权
属出卷方，熟人圈等同老师间传卷惯例，半公开前必须解决）、境内云 +
备案评估、防滥用。

## 与既有挂账的关系

  不算碎片化上云——它就是路线图第一步。
