# Option B 两条保护（v24，2026-11-22）

Owner 定的标准从「挑不出毛病」改成「不错、对读者有帮助」后，按第六轮两位评审都挑刺的 5 题加两条保护，写进 `resolveReadingLocate`（传了选项文字才检查），提示词各加一句。

## 两条保护

- **图表答案**：正确项里有原文没写的数字，answerText 里也没有自己的数字（题干外的数字，或 half、third、twice、percent 一类数词），就不给定位句，改按选项。防的是答案在图表里或要自己算时，定位句指错地方。
- **桥接偏向干扰项**：bridgeZh 里的英文实词只出现在错项里，不在正确项和题干里，就要求重写。防的是桥接把学生引向错项。
