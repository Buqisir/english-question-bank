# 第八轮预登记：看懂答案为主，兼顾示范找法（2026-11-22，跑之前写）

Owner 把目的定为两件事一起做：先帮读者看懂答案，再让他从这道题上看到怎么回原文找。第七轮只问了前一半，而且给评审看的是我拼的文字版，把定位句和答案又单独列了一遍，比真实页面重复得多（真实页面上，答案就在定位句的题只有一行「定位 X 原词 第 N 段」，定位句并进原文依据）。

这一轮用同样的 80 题（v24 加保护后的版本），给评审看页面上这道题的全部真实文字（加粗的定位词用 «» 标，答案底色用 【】 标），每题答两个是非、判一档：

- 看懂：这一行定位（连同它带出的加粗和底色）有没有让读者更清楚答案出自哪里、题干和正确项怎样对上原文。
- 找法：读者能不能从这一行看到这道题具体怎么回原文找（落到具体的词和段落，不是一句方法名），下次照着做。
- 档：误导（引向错项或讲错）、没帮上（看懂和找法都没有）、帮上了（至少一样有）、没有定位行（页面上这题没有定位这一行）。

取两位评审更差的一档；「没有定位行」单独计，不算没帮上。

## 线

- 误导不超过 1 题。
- 没帮上暂定不超过 16 题（20%），没有依据，是暂定的。

## 事先的预测

- 按选项回原文的 8 题多半还是没帮上：只有方法名，没落到具体段落。
- 答案就在定位句、题干原词的 18 题，大部分会因「找法」翻成帮上了：它示范了「拿题干原词去原文扫到第几段」。
- 看全文的题在页面上大多没有定位行，计入「没有定位行」。
- 有说明、或题干词换了说法的题，和第七轮一样大多帮上了。
