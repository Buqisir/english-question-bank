# 第十三轮预登记：定位讲出「这道题怎么做好」（2026-11-22，看结果之前写）

## 为什么做

Owner 看完第十二轮盲看页后提出：主旨这类题的定位不该只说「看全文」「看首段加末段」，要讲出这道题具体怎么做，把能看的地方引出来；而且「每道题的定位都要体现，怎么能把这道题做好」。惯常写法不定死一句，只要求不泛、不套话。

## 改了什么

- 提示词（草稿 prompt-W，在第十二轮胜出的 prompt-N 上只改 findZh 一节）：
  - 通用检验：这一行原样搬到别的题、别的文章还说得通，就是套话，重写。
  - 看全文的题：说清这篇（或这一段）怎么写的、答案从哪里来，用 [[段落]] 标出每一处，抄两到四个能看到这一步的原文词，再用几个字说答案要盖住什么。不印结构类名。
  - 核对选项的题：说清每项带什么回原文、这篇里什么定胜负。
  - 从题干定位的题：规则不变。
- 校验（已提交 1b315094c）：findZh 长度按 locateBy 分开，题干 16 字 2 个英文词不变；核对选项 24 字 3 个英文词；看全文 48 字 8 个英文词。

## 怎么比

- 卷子同第十轮：2022 全国甲、2023 新课标Ⅱ、2024 全国甲、2026 新课标Ⅰ。
- 新版每套卷子一个写作者（Opus 5.5 medium），只读 prompt-W、本卷请求、任务说明，校验 PASS 才算。
- 对照用第十二轮 N 版已有的输出，不重新生成。
- 比的范围：两版里任一版 locateBy 为 options 或 passage 的题（第十二轮 N 版是 11 题）。从题干定位的题规则没改，只查新版有没有变坏：新版和 N 版 locateBy 不同或 findZh 变了的题题干题，列出来给 Owner 看。

## 判定（事先定）

Owner 盲看（两版并排，A、B 随机，不标哪版），每题选更好的一版或差不多，可写一句理由。
- 新版更好的题多于 N 版更好的题，且 N 版更好的不超过 2 题：采用新版写法，进心法和提示词。
- 否则不采用，逐题看 N 版更好的原因再改。
- 另查一条客观项（我来做，不靠评审）：新版每条看全文、核对选项的 findZh 里的英文词都能在本题原文或选项里找到；[[段落]] 指到的段里确有它说的内容。有一条对不上就记「误导」，误导超过 1 条不采用。

不另派评审：这一轮问的就是 Owner 的口味，前几轮评审和 Owner 已有冲突时以 Owner 为准。
