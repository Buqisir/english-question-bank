- Forbidden: new Q33-specific branches or verifiers, changed candidate bytes,

- [ ] The generic Job replays Q33 without invoking a Q33-specific materializer or selecting behavior from its paperId.

- [ ] Screen, Student Print, Teacher Print, and PDF consume the same four confirmed images and source layout intent without consumer-side recrop, stretch, or paper-specific offsets.

- [ ] Identical replay is idempotent and exact-source or confirmation mutation fails closed through the generic Job seam.
- [ ] The legacy Q33-only materialization path is removed only after parity passes, leaving one supported route and no lost capability.
- [ ] Narrow Q33 parity, generic Job, shared consumer, rendered-canary, and `git diff --check` checks pass. No per-paper authority bump, full suite, or separate review is added.
