# home-blank · owner DP-3 对照单

生产部署后在 eqbank.cc 前台过一遍（约 3 分钟）。

1. **开门定**：主页 = 居中词标 + 大搜索框 + 一行小字。无 feed、无筛选、
   无思考开关。感受这个「定」是不是你拍原型 D 时要的。
2. **提交拍**：随便打字——页面应纹丝不动；回车那一刻整体上移、出结果。
   观感项（CR SW-3）：上移顺不顺、命令行那一瞬变宽刺不刺眼——我截图
   判了可收，你有否决权。
3. **回落**：×/esc 清空 → 回纯空白；点居中词标 → 任何状态一键回空白。
4. **浏览态**：点小字「N 套卷 · M 篇章」→ 今天的 feed（年份分组 + 筛选
   chips）原样在这；Back → 回空白；带筛选的 URL 刷新不丢态；详情中键
   照旧。
5. **诚实空态**：搜「量子力学」→「没找到匹配」+ 引导，不硬凑。

顺带拍板一条：思考模式开关按原型基准藏进了列表面（空白态不显示）——
若想空白态也常驻，说一声即回。
