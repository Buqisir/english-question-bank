# similar-questions — 相似题（主打功能 program）

Owner 定位：**网站主打功能**。方向经 grilling 逐裁点拍板（2026-07-09/10，
七问全落锤，Q6 形态待原型裁）。本文件是 program 级决策记录；每把刀另立
`docs/cuts/<CUT>/plan.md`。

## 已拍板的决策

- **Q1 本命场景 = 错题再练闭环**：学生错某题 → 从该题一键配同款 →
  勾选入草稿卷 → 再练再检验。入口贴讲评/解析。其他场景（组卷加购、
  浏览探索）是同一引擎的出口，不另立形态；出题查重是另一个功能，不混。
- **Q2/Q4 配方表（整表通过）**——"相似"按题型各一张配方，共同骨架
  =硬池(同题型)→主序→次序→加分：

  | 题型 | 主序 | 次序 | 加分 |
  |---|---|---|---|
  | 语法填空 | 考点 facetKey **按密度** | 有/无提示词 | — |
  | 完形 | 话题 | 体裁 discourse_type | 错题词性 |
  | 七选五 | 功能句 roleFacet+位置 **按密度** | 衔接机制 mechanismFacet | 话题 |
  | 阅读 | 小题题型 skill **按密度** | 篇位 proxy（词数+体裁） | 话题 |

  共同底线：排除同篇/同卷/种子所在组；每条结果带"为什么相似"注解；
  **纯确定性零 AI**（不吃日限额、可解释、可复现）；引擎复用 i16a
  `/api/teaching-facets` 检索层（已建成、至今无 UI 消费者）。
  难度字段是死的（全库 medium）不参与；话题标签覆盖 96.7%。
- **Q3 学生维度三级走**：v1 老师记忆 + **同刀种"草稿卷归属学生"可选
  字段**（成本极小，闭环种子）；v1.5 草稿卷史排重（配题时排除该学生
  历史草稿卷已出现的题）；学生档案=ADR 级域模型扩展，roadmap 后置
  （M2 后议）。
- **Q5 v1 题型范围 = 四类非写作**（语法填空/阅读/七选五/完形，数据
  满配）。写作不出 v1：零 facet、闭环是批改不是错题；等后台解析管线
  长出"情节走向"facet 再以完整体上线。
- **Q6 入口与形态：原型通过，整套落锤**（owner 2026-07-10"看起来还是
  帅的，可以的"；原型快照 `prototype.html` 入档）：讲评/解析面板每题
  「配相似」→ 右栏原地切换结果列表（不跳页）→ 每条带"为什么相似"
  chips（含 N 题·考点 / 篇位相当 / 话题不同✓）→ 勾选墨绿亮边+底栏计数
  → 加入草稿卷 toast → 返回解析。池子诚实尾注（"库内同考点还剩 N 组"）。
  详情页次入口、concierge 旧文本"找类似"换新引擎、命令行考点直搜挂 v2。

## 盲区处置清单（grilling 产出）

1. 池子天花板：单池 33-126 组；池子见底要诚实显示（"库内同考点仅剩
   N 组"），不硬凑。生产线（后台出题 skills）按考点缺口补题——相似题
   使用数据反哺选题方向。
2. 配方同质化：高考卷考点分布趋同 → 排序必须按**密度**不按命中与否。
3. 难度补标：挂账给解析管线（数据生产任务），补活后接入"份量相当"。
4. 导入门禁：**"入库必带解析/facet"写进导入 runbook 硬门禁**，否则
   相似题对新卷静默失明（i16a coverage=analyzed-only）。
5. 错题簇预留：v1 单题入口，**API 收种子题数组**，v2 多题合并画像。
6. 老师否决权：结果永远是带理由的建议+手动勾选，绝不自动进卷
   （Super Teacher Boundary）。
7. 非谓语粒度：registry 17 类中"非谓语动词"未分 doing/done/to do
   功能位，v1 够用，细分挂账解析管线。

## 配方 v2（2026-07-15 起，逐题型重谈；本节按拍板顺序累积）

背景：07-14 机审实锤 v1 配方三类病（种类密度非空数/题数密度、恒真维度
四处、阅读词数 proxy 残余），owner 定调 v2 原则=**实用、不困难、贴合
实际**，逐题型单独谈，不套统一大表。

### 阅读理解（2026-07-15 拍板 ✅）

概念拆分：**篇章相似**与**小题相似**是两个功能、两套入口，不再混在
一个"配相似"里。

- **篇章相似** = 同话题（**硬门槛**：话题不同的直接不进池，不是降权
  ——owner："拓宽语境是个假说法，拓宽语境不如去搜一个你想要的题目"，
  v1 的阅读「话题不同+20」加分废止）→ 池内按篇位排（同篇位 > 相邻
  篇位）。词数细排随 v1 废止（proxy 残余）。
- **小题相似** = 小题题型（skill），维持密度方向，密度语义待完形/
  语法填空轮次一并定（种类 vs 题数）。
- **入口拍板（原型 prototype-passage-entry.html 三场景，owner 全过）**：
  篇章入口贴"篇"的单位出现，共三处——①详情页组头（原 E3「配相似」
  改名升级「相似篇章」）②工作台贴纸操作条新增 ⇄（右栏目录原地切
  候选抽屉，可「替换这篇/加入」，替换可撤销）③搜索结果卡（原
  「配相似」钮原位改名，不加新钮）。小题入口只一处=讲评/解析每题旁
  （现 E2 rail）。
- 池子诚实条款照旧：「库内同话题 B 篇仅剩 N 组」。

### 完形填空（2026-07-15 拍板 ✅）

- **相似 = 同话题，组级，没了**——单维度配方。机审互证：完形除话题外
  全是恒真维度（体裁 91% 记叙、词性每组 4-6 种全含），v1 的体裁次序、
  词性加分随 v1 废止；「词性↔话题对调」裁决点就地消解（词性不进配方）。
- **小题相似不做**（owner："有点冒进"；补充定性：完形错空≠词性弱，
  多为语境线索/词汇量问题，按词性配无教学含义——与语法填空不同）。
- **入口**：卡/详情/工作台三处同阅读（篇章语义）；讲评态解析面板的
  「配相似」**保留、改指篇章相似**（老师讲评现场"再来一篇同话题的"
  就地可点，不摘钮）。

### 语法填空（2026-07-15 拍板 ✅）

- **篇章相似 = 同话题**（owner 改判小川"话题不进语法填空配方"的提案：
  全站篇章入口必须一个含义，统一性 > 单题型洁癖）。
- **小题相似 = 同考点命中即入池 → 同话题加分 → 年份新旧**。
  **密度概念废止**（owner："空数密度是虚的，没用"；数据实证：同一考点
  在一篇内 80% 仅 1 空、15% 2 空——高考挖空配方本身要求考点铺开，
  密度分子恒 1-2 无区分力；动词细分落地后更平。v1 盲区2"考点趋同→
  必须按密度"就地反杀：恰因每篇均匀谱，按命中才诚实）。
- **考点粒度尺子（普适）：考点粒度 = 老师讲评时嘴里说的那个词。**
  现 17 类词表大半达标（定从/介词/冠词/词形转换含转换方向）；唯谓语/
  非谓语两桶（114 空，占全库 1/3）未细分——谓语→时态/语态/主谓一致、
  非谓语→doing/done/to do——**挂账数据线**（r1-genre-truth 同款：机审
  预标+owner 盲审判例，仅 114 空）。细分落地引擎零改动自动变准。
- 提示词信息已编在考点 key 内（given/no-hint），随考点匹配，v1 恒真的
  独立「提示词」次序废止不丢信息。

### 七选五（2026-07-15 拍板 ✅）

- **篇章相似 = 同话题，组级；小题相似不做**。数据双证：单维度组间

  组合裂成两半——学生最常错的空型（段中衔接/段首主旨 28-33/33）恰好
  恒真，仅段尾总结（14/33）等少数空型有区分力——"有时灵有时不灵"

### 篇章相似排序（2026-07-15 拍板 ✅，四题型统一）

owner 三句语义（同话题同篇位有意义/同话题有意义/单纯同篇位意义不大）
⇒ **分层制，非加分制**（加分制会让"篇位+真题+年份"凑分越过话题，
结构上防不住；分层制下层满分翻不过上层一格——v1 打分骨架
primary×10000+secondary×100+bonus 直接复用，换格子内容）：

1. **同话题 = 门槛**（不同话题不进池，维持阅读轮拍板）
2. **篇位**（仅阅读）：同篇位 > 相邻 > 其他
3. **真题 > 模拟题**（sourceType 库里现成，卡上给「真题」chip）
4. **年份新旧**收尾

远期杠杆（v3 不动，数据结构别堵死）：话题匹配粒度台阶（原子标签→
课标条目→主题群），池子太小自动上台阶放宽、卡上如实标"同主题群"。
