# 1 对 1 单词听写与错词复习扩展规范

## 范围

本扩展在既有 `学生 → 过词轮次 → 冻结 Vocabulary Set` 之外增加教师复习闭环：

`冻结生词组 → 词义抽查 → 待认义 → 复习任务 → 学习卡 / 复听写 → 教师批改 → 跨日复查`

首版只接受 `wanwei-round-one-v1` 的词条，但所有新增对象持久化 `programId`。既有 Vocabulary Set、单组打印、旧二维码和过词快捷键不改语义。

## 领域不变量

- Vocabulary Set 继续是冻结、不可变的交付物；错词状态和听写历史属于学生，不写回 Set。
- Vocabulary Meaning Recall Record 是冻结、有序、1–60 词的教师现场抽查；只展示英文词形，由老师记录 `correct / wrong / untested`，不复用 Review Run。
- Meaning Recall Record 保留来源 Set、逐词全部来源与冻结快照，并拥有 `draft / completed / void` 生命周期；生成的听写任务通过独立关联表连接，之后不得随抽查记录修改或作废而漂移。
- Vocabulary Dictation Task 是冻结、有序、1–60 词的快照，可保留多个来源 Set 和冻结口音。
- 同一个任务可以产生多条独立 Vocabulary Dictation Record；纸笔补录先创建不公开任务。
- Record 的词结果只允许 `correct / wrong / untested`。草稿、作废记录和 `untested` 不参与复习统计。
- 写错一次进入待复听写；其后连续两次有效听写正确才进入已改善。
- 看词说义答错一次进入待认义；两个不同日期明确答错且仍未恢复时进入反复忘记。
- 看词说义答对与完整听写答对都贡献认义正确证据；最近一次词义错误后连续两个不同日期正确，才转为认义已恢复。
- 完整听写答错只影响待复听写，不制造词义错误；草稿、作废和未测不参与任一推导。同日记录全部保留，但每个能力状态最多贡献一个日期证据。
- 单词可同时处于待认义和待复听写；不计算权重、综合分或错误子类型。
- 至少两个不同日期写错且仍待复听写，才进入顽固错词。同日重复错误不伪造顽固日期数。
- 排行依次比较：当前连续错误次数、最近五次错误率、累计错误次数、最近错误日期。
- `pinned` 只提升推荐顺序；`paused` 只从当前待办和推荐中隐藏；两者都不改历史。
- 新任务按“所选生词组顺序 → 组内顺序”去重；首次快照为任务快照，但保留全部来源 Set。冻结前可打乱，冻结后不可变。
- 新旧公开分享 ID 在同一命名空间内防碰撞；公开投影不返回教师、学生、来源组、记录、错词或排行。

## 持久化

`user-data.sqlite` 使用幂等 schema 创建以下职责表：

- `vocabulary_dictation_tasks` 与 task source / entry / entry source 子表：冻结任务和来源关系。
- `vocabulary_dictation_task_shares`：独立分享、撤销和重新分享。
- `vocabulary_dictation_records` 与 result 子表：草稿、完成、作废及逐词结果。
- `vocabulary_student_word_flags`：稀疏存储 `pinned / paused`；普通状态无记录。
- `vocabulary_meaning_recall_records` 与 source / entry / entry source 子表：冻结词义抽查、来源关系、逐词结果与生命周期。
- `vocabulary_meaning_recall_dictation_tasks`：只记录抽查与后续冻结任务的来源关系，不反向改写任务。

升级不重写旧 Set、旧 share、Review Run 或学生进度，也不虚构历史成绩。

## 教师操作面

认证工作区对外固定叫“单词复习”，包含：生词组、词义抽查、听写任务、待复习、检测记录。

- 生词组库分页加载，支持标题/单词搜索与日期筛选；卡片显示最近错词数、累计听写次数和当前待复听写数。
- 生词组卡片同时显示最近词义抽查日期、当前待认义数和反复忘记数；冻结生词组可直接进入“看词说义”。
- 词义抽查支持单组、多组、默认随机和原顺序；舞台先只显示英文词形，`Enter` 答对、`Shift` 答错、`Delete` 撤销。答错后展示冻结教学义、音标和读音，老师确认后继续。
- 结果页固定显示仍记得、已忘记和未测，只提供“为本轮错词生成复听写”；任务与公开分享在同一事务中原子创建，分享失败时整份任务回滚，复听写纸必须带“扫码自动听写”二维码。
- 认义建议默认 20 词、可调 1–60；优先重点关注、认义和听写双项未解决、反复忘记及较久未检查词，已恢复抽查不超过目标的 20%，暂停词不进入待办或推荐。
- 检测记录按日期统一展示词义抽查与完整听写，二者都支持草稿、编辑、作废和恢复。
- 多选显示原始词数与去重词数。合并打印可选去重或按组装订；按组装订保留重复并从新页开始。
- 词组多选工具直接提供“错词资料”，由服务端按当前有效认词与听写记录重新计算未解决错词，排除已改善和暂停词；错词按所选组顺序、组内顺序全局去重。错词资料的“按组装订”与普通词组打印不同：重复词只归入最先选择的来源组，各非空组另起页，整份分片共用一个二维码，纸面题序必须与播放顺序一致。
- 错词资料下载会原子冻结带分享的复听写任务；每份最多 60 词，超过时按顺序拆分。单份单类型直接返回 PDF，多份或“下载全套”返回包含单词卡、复听写纸和教师答案独立 PDF 的 ZIP；下载失败不得删除已冻结任务，老师可从听写列表重试。
- 二维码听写始终去重，超过 60 词按冻结顺序拆分成独立任务和分享。
- 听写任务持久化独立任务日期并按任务日期分组，支持逐项多选和全选当天；所选任务按日期分别合并去重，并直接复用来源任务的冻结快照，不能依赖它仍有来源生词组。原子创建任务与公开分享后导出带二维码复听写纸，单日超过 60 词时自动拆分；新任务继承所选任务日期，不随实际导出时间漂移。
- 批改默认整组全对，老师只标错词；抽听先标实际题号，其余为未考。
- 支持点击题号、`2,5,8-10`、方向键、空格标错和 `Cmd/Ctrl+Enter` 完成。草稿自动保存；完成前明确确认未考词。
- 已完成记录可重开编辑并重新计算；可作废与恢复，不直接删除。
- 待复听写和顽固错词先冻结为复听写任务，再从同一任务下载单词卡（首页右下角“扫码听音频”二维码）、复听写纸（首页右上角“扫码自动听写”二维码）或教师答案；也可复制清单。
- 下次建议默认 20 词并记住教师上次选择；先取重点关注和未解决错词，再按排行补足，已改善抽查不超过目标的 20%。

## 打印与公开边界

- 合并打印通过短时、认证绑定的内存 print job 把已授权快照注入既有打印渲染器；渲染结束即删除，不创建临时 Vocabulary Set 或永久打印记录。
- 同一复听写任务可以复用同一个匿名 share ID，但必须按资料语义进入不同公开消费者：单词卡、记忆卡和单词纸右下角固定进入带图片、词形、词义与音频的听音页，标签统一为“扫码听音频”；复听写纸右上角固定进入隐藏答案的自动听写页，标签为“扫码自动听写”。两者不得共用自动听写 URL。教师答案不放二维码，也不公开学生、来源组或错词历史。
- 新任务分享公开页锁定任务口音。旧 Set 分享仍接受 URL 口音参数，保持兼容。
- 真机未执行必须明确报告 `SKIP`，不能把桌面浏览器模拟当真机证据。
