## 2. 已锁定的 Owner 决策

### 2.1 例句

- 例句由离线模型生成，独立模型复核，再经过确定性规则检查。
- 必须命中当前 `teachingSense`，自然、简短、适合初中生理解。
- 疑难项由 Goal 内持续返工直到通过，不逐条打断 Owner。
- Owner 只在最终 QA 按 Day 抽验，抽验不是全量生产的中途审批。
- 例句与译文进入提示卡和打印卡；首版扫码播放器首屏不展示例句，也不朗读例句。
- 每词保存三个已批准候选；现有例句逐字保留为候选 A，新增 B、C 只更换具体场景，三句必须对应同一 `teachingSense`。
- 原候选 A 若被儿童价值观安全复核判定为阻断，必须列明原句、原因并取得 Owner 明确批准后才能替换。2026-08-10 Owner 已批准将 `even`（sourceOrder 123）的贬低式比较句替换为中性场景句。
- 提示卡固定显示候选 A。创建新 Set 时，以例句版本、Set ID 和 Entry ID 稳定选择一个候选并写入冻结快照；重命名、重印和重新分享不得重新选句。

### 2.2 读音与音节

- 只做音节拆分，不做音素拆分。
- `syllables` 保存为有序数组；页面紧凑并排显示，整词 IPA 单独保留。
- `a / an` 等多形式条目使用 `forms`，不伪造音节。
- 音节片段重新拼接后必须与规范化 headword 一致。

### 2.3 正式语音

- 扫码播放器提供美音、英音两套固定资产；默认美音，教师和学生可切换，不在运行时合成。
- 美音继续使用已完成质检的历史内部版本 `eqb-british-teacher-v1`；这个内部 ID 不再改名，产品界面只显示“美音”。
- 英音固定为 `eqb-british-cori-high-v1`：Qwen3-TTS Base 使用冻结的 Piper Cori High 官方样音作为合成参考，不对应任何真人。
- 本机运行时固定为 `mlx-audio==0.4.7`；VoiceDesign 6bit revision 为 `ffc6545dc9cb086950aa46c6cd3db490e6ece3e1`，Base 6bit revision 为 `34ff5318365b59cba9c03ff729f2eee0814caf72`。
- 冻结证据至少保存：声音设计描述、参考文本、参考 WAV、上述版本与 revision、生成参数、参考 WAV SHA-256、Owner 听感批准和每份正式资产 SHA-256。
- 输出固定为 24 kHz、48 kbit/s、单声道 MP3，使用正常语速和音高。
- 每个词预生成一个版本化音频文件；运行时不得调用 TTS 或 `speechSynthesis`。
- 正式管线完全离线运行，不读取云密钥、不调用第三方 TTS 接口，也不得使用真人、学生、未成年人或名人参考音频。
- 批量生成前必须先通过孤立词黄金集：超短词、同形异音词、英式元音词、复数变体和缩写均检查起音、尾音、重音、英式元音与目标词义读音。少数歧义词允许使用版本化文本覆写，但不得在网页运行时猜测读音。
- 每套口音均要求 1600 份正式 MP3。英音由 Owner 逐词听完，并以 `1525 原版 + 69 + 4 + 2 修复版` 完成四层选择闭环；试听参考句不能代替单词资产。

## 3. 数据与领域合同

### 3.1 共享数据

`question-bank.sqlite` 保存所有用户共同消费的版本化 Vocabulary Program、Group、Entry、教学内容与资产引用。

稳定 Entry ID 根据 Program、阶段和源书位置生成，不假设 headword 全书唯一。每个 `VocabularyEntry` 至少包含：

```ts
type VocabularyEntry = {
  id: string
  headword: string
  phonetic: string
  partOfSpeech: string
  sourceMeanings: string[]
  teachingSense: string
  syllables: string[]
  pronunciationMode: 'syllables' | 'forms'
  example: {
    english: string
    chinese: string
    highlight: string
    reviewStatus: 'approved'
  }
  visual: {
    key: string
    version: string
    path: string
    alt: string
  }
  audio: {
    key: string
    version: string
    path: string
    voice: 'eqb-british-teacher-v1'
  }
  source: {
    title: string
    edition: string
    stage: 'core' | 'basic' | 'recognition'
    day: number
    sourceOrder: number
    printedPage: number
    verification: 'page-checked'
  }
}
```

OCR 只用于发现文字；词形、音标、词性、释义、阶段、顺序和来源页必须回到扫描页核对。无法确认的条目不得用猜测补齐。

### 3.2 用户数据

`user-data.sqlite` 保存：

- 教师管理的学生档案；学生不创建账号，也不进入教师后台
- 每用户、每学生、每 Program 的主进度和上次目标数
- Vocabulary Review Run 与 Review Decision
- Vocabulary Set 与 Vocabulary Set Entry Snapshot
- Vocabulary Share

教师首次进入时自动获得“默认学生”。本功能上线前已经存在的进度、Run、Set
和 Share 必须原样迁入该默认档案；迁移不得丢失冻结顺序或使旧二维码失效。
教师可以新建和切换学生，同一教师下不同学生的进度、Run 和 Set 必须严格隔离。
首版不提供永久删除学生档案，避免误删长期学习记录。

`VocabularySet` 是冻结、有序的结果。Set Entry 必须保存生成时的 headword、IPA、1–3 组来源核心义、教学常见义、音节、已选例句及其候选 ID/版本、图片版本和音频版本快照，后续词库更新不得让旧单词纸或二维码内容漂移。旧快照没有 `sourceMeanings` 时回退到 `teachingSense`，没有例句选择元数据时继续使用原冻结例句，不能因此失效。

`shareId` 使用加密安全的 URL-safe 随机值，不包含用户或 Set 的顺序信息；长期有效，直到教师撤销。
撤销后的旧 `shareId` 永不复活；同一 Set 再次分享时生成新的随机 ID。

## 4. 服务接口与权限

认证接口提供：

- 获取和创建当前教师的学生档案。
- 获取 Program 与主进度。
- 按当前 Program 词条调整指定学生唯一主进度的下一词；若存在未结束 Run，必须由教师显式确认放弃该轮。
- 创建、恢复和更新 Review Run。
- 达到目标后冻结 Vocabulary Set。
- 获取最近 Sets 和 Set 详情。
- 修改 Set 名称；该名称同时用于最近生词组、单词纸标题和下载文件名。
- 创建、复制或撤销 Set 分享。

公开接口固定为：

```text
GET /api/public/vocabulary/listen/:shareId
GET /api/public/vocabulary/dictation/:shareId
```

普通播放器接口只返回词卡所需的冻结词条、顺序、图片和音频；自动听写接口只返回题序、测试词形、词性、来源核心义和音频，以便完成后在本页核对。两者均不得返回教师身份、学生姓名、学生 ID、内部用户 ID、Review Run 或其他 Sets。

公开页面固定为：

```text
/vocabulary/listen/:shareId
/vocabulary/dictation/:shareId?accent=american|british
```

该路由在 `AuthGate` 之前分流；其他页面继续使用现有认证边界。未知分享与已撤销分享使用克制的公开失效状态，不泄露所属用户。

## 5. 教师过词与生词集

- 教师先选择当前学生；切换后只读取该学生的主进度、未结束 Run 和最近 Sets。
- 教师可在同一页紧凑地新建学生档案；创建后自动切换到该学生的全新进度。
- 每次 Review Run 和直接输入生成的 Set 都必须绑定当前学生，不能只依赖浏览器本地状态判断归属。
- 每轮开始输入目标生词数 `1–60`；首次默认 15，以后默认上一次选择。
- 每个学生只有一条 Program 主进度；默认从服务器记录的未结束 Run 或主游标继续。开始页提供一个次级“查看 / 调整进度”入口，按 Week、Day 展示实际词目；教师点选某词并确认后，该词成为唯一主进度的下一词，用于迁移实体书已有进度，不建立并行进度，也不为此前词目伪造认识记录。
- 过词页左栏只读展示当前 Week、阶段和 Day 位置，不承担跳转。若调整进度时仍有未结束 Run，界面必须明确说明并由教师确认放弃该轮及其未冻结判断；已经冻结的生词组、下载和分享均不受影响。教师可“暂停并返回”，再次进入时必须恢复同一 Run、游标、判断和已收生词。
- 新词出现时自动播放一次；空格重播，Enter 表示认识，Shift 表示不认识，Delete / Backspace 撤销，右方向键查看提示。按住按键不得连续跳词，输入框聚焦时快捷键不得触发。
- 开始过词处提供克制的“美音 / 英音”选择，并在当前浏览器记住上次选择；自动播放、手动重播、提示卡音标和音节拆分必须跟随该选择。
- 每次判断后把进度持久化到服务器；本地缓存不能成为唯一权威。
- 达到目标时不自动生成，教师点击后才冻结 Vocabulary Set。
- 同一“过生词”入口允许教师粘贴已有单词，直接生成 `1–60` 词的固定 Vocabulary Set；输入界面以中文逗号分隔为主。
- 直接输入只做当前 1600 词库的确定性匹配：按首次有效输入保留顺序，按 Entry 去重，明确列出未收录项，不用模糊匹配猜测错词。
- 直接输入生成的 Set 不创建 Review Run 或 Review Decision，不改变主过词进度，并与过词生成的 Set 共用打印、二维码、公开听写、重印和撤销分享流程。
- 最近生词集直接展示其中词目，支持打开、改名、下载 PDF、复制公开链接和撤销分享。
- 30 词校准样本是 Canary，但所有合同从第一天支持完整 Program 和 1–60 词 Set；Canary 通过后 Goal 自动继续全量工作，不等待新的 Owner 决策。

## 6. 打印单词纸

- 固定 A4、两栏三行，每页六张卡，按从左到右、从上到下排列。
- 最后一页不足六词时保留空位，不拉伸或重新分配。
- 单词字号采用已确认的较大一级版本。
- 每张卡包含正式图片、单词、紧凑音节、整词 IPA、词性、1–3 组来源核心义、例句和译文；例句仍对应 `teachingSense`。
- 图片使用 `object-fit: contain`，不裁切、不变形，不以低分辨率截图替代 SVG。
- 第一页右下角预留 22 mm 二维码区域，不覆盖卡片；后续页不重复二维码。
- 单词纸、单词卡和记忆卡右下角二维码的唯一语义是打开带图片的听音页；纸面、按钮、`title` 与无障碍标签统一写“扫码听音频”，不得写“扫码听写”或“扫码自动听写”。
- QR 在本地生成并直接编码稳定公开 URL，不调用远程二维码服务。
- Screen 提示卡、打印和播放器消费同一份 Entry/Set 资产版本，不分别重建词义和顺序。

## 7. 公开扫码播放器

参考页只提供“当前词卡 → 播放控制 → 完整词表”的行为骨架。本站保持纸张感、黑灰文字和单一克制强调色，不复制紫色通用卡片外观。

首屏当前词卡包含正式图片、headword、紧凑音节、整词 IPA、词性和 `teachingSense`。

播放器固定行为：

- 第一次用户点击后才播放。
- 重复次数支持 1、2、3，默认 2。
- 同词两次发音间隔 0.8 秒，不同词之间间隔 2 秒。
- 支持上一词、播放/暂停、下一词、音量、整组进度、当前序号和完整词表。
- 播放中手动切词立即取消旧音频和所有计时，从新词继续播放。
- 暂停或未播放时切词只改变选中词，不擅自发声。
- 暂停立即取消当前播放和全部等待任务，不允许后台继续推进。
- 播完末词停留在末词，显示“本组听完 / 从头播放”。
- 当前卡、进度和列表高亮始终同步，并把当前行带入可视区。
- 音频失败时暂停并显示重试，不静默跳词。
- 使用一个复用的 `<audio>` 和显式状态机。
- 所有操作使用真实 `button`、`range`、可见焦点和准确中文 `aria-label`。

手机端使用正常页面滚动；完整词表不设置固定高度嵌套滚动。主控制离开视口后显示紧凑粘性播放栏，但不得产生两套播放状态。

### 7.1 听写纸与自动听写

- 固定 Set 的下载入口提供“单词纸 / 听写纸 / 教师答案”三种 PDF；听写纸和答案均为 A4 单栏表格，每页最多 15 题，列为序号、英文单词、词性、中文意思。
- 学生听写纸只保留空格；教师答案逐题给出测试词形、词性和全部已复核来源核心义。`forms` 条目只考第一个词形，词组必须完整读写。
- 听写纸首页包含直接进入自动听写页的二维码，纸面不显示口音；生成时选择美音或英音并写入二维码，消费端不提供切换。
- 只有听写纸二维码使用“扫码自动听写”语义；它不得与单词纸、单词卡或记忆卡的“扫码听音频”二维码混用。
- 如果 Set 尚未公开分享，下载听写纸前必须明确说明将创建匿名公开链接；答案 PDF 不要求公开分享。分享撤销后普通播放器与自动听写页同时失效。
- 自动听写页在完成前不显示英文、词性或中文义。首次点击后先倒数 3 秒，每词前给出克制提示音；重复支持 1/2/3 遍（默认 2），同词间隔 0.8 秒，词间书写时间支持 3/5/8 秒和 3–15 秒自定义（默认 5），设置记在当前浏览器。
- 页面提供上一题、开始/暂停/继续、下一题、重播本题和音量；隐藏或锁屏时立即暂停。刷新后可从当前题继续或从头开始；支持时申请 Screen Wake Lock。
- 音频失败停在当前题并提供重试，不静默跳过。最后一题播放完仍等待完整书写时间才完成；完成后可从头再听，或二次确认后查看本组答案。
- 首版不生成连续 MP3，不接受学生端自动评分；教师确认后可按独立听写任务保存真实听写结果，但不得写回冻结生词组或改变学生过词进度。首版不接收 1600 词库以外的内容；听写任务可在冻结前由教师选择打乱，冻结后顺序不再变化。

### 7.2 词义抽查与复习闭环

- 教师可从一个或多个冻结 Vocabulary Set 发起 1–60 词的“看词说义”；默认随机，也可保留来源顺序。它使用独立 Vocabulary Meaning Recall Record，不复用 Review Run，也不推进首次过词游标。
- 舞台先只显示英文词形：`Enter` 答对、`Shift` 答错、`Delete` 撤销。答错后才显示冻结教学义、音标和当前口音读音。
- 每词仍只记录 `correct / wrong / untested`，并支持草稿自动保存、完成、编辑、作废和恢复。词义抽查与完整听写在“检测记录”中按日期统一展示。
- 明确词义错误一次进入待认义，两个不同日期错误且未恢复时进入反复忘记；最近一次词义错误后，来自词义抽查或完整听写的两个不同日期正确证据使其恢复。完整听写错误不得虚构词义错误。
- 单词可同时待认义和待复听写；不使用权重、综合分或错误子类型。`pinned` 只提升推荐，`paused` 从待办和推荐隐藏，二者不改历史。
- 抽查结果只允许从本轮错词生成冻结 Vocabulary Dictation Task；任务与公开分享必须在同一事务中原子创建，分享失败则任务回滚，对应复听写纸必须带自动听写二维码。关联只记录来源，之后修改或作废抽查不得改写已冻结任务。
- 听写任务持久化独立任务日期并按任务日期分组，支持逐项多选和全选当天。合并导出时按日期分别去重并直接复用所选任务的冻结快照，不得要求仍有来源生词组；之后原子创建冻结任务与公开分享并生成带二维码复听写纸。新任务继承所选任务日期，单日超过 60 词自动拆成多份独立任务。
- 教师从一个或多个冻结 Set 下载错词资料时，服务端必须以当前有效记录重新计算认词与听写任一通道尚未解决的词，排除已改善和暂停词，并按“所选组顺序 → 组内顺序”全局去重。错词资料可合并去重或按组装订；按组装订时重复词只归入最先选择的来源组，各非空组另起页，但每个不超过 60 词的任务分片只使用一个共享二维码，纸面题序与播放顺序必须一致。普通生词组打印的按组重复规则不受影响。
- 错词资料任务及分享按整批事务冻结，超过 60 词依序拆分；单份单类型返回 PDF，多分片或全套资料返回 ZIP。单词卡二维码进入听音页，复听写纸二维码进入自动听写页，教师答案无二维码；渲染失败保留已冻结任务供老师重试，不产生听写成绩。
