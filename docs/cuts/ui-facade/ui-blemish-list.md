# UI 烂点清单（本刀 QA 顺手记，给 owner 圈下一轮范围）

本刀（UI 门面刀）已修的不再列。下面是看到但**没**动的，按碍眼程度排序，
owner 圈了哪条再立刀：

1. **窄窗口下 topbar 按钮墙竖着叠**：浏览器窗口 <900px 时，owner 视角的
   7 个 topbar 按钮换行成两三层，字都竖排了。member 视角只有 2 个按钮无此
   问题。经典模式退役+权限裁剪后按钮会变少，可能自然消解——建议挂到
   经典模式退役刀后再看。
2. **feed 卡标题截断**（如「2026年1月浙…」）：hover 有完整 tooltip（早已
   有），但视觉上标题列宽偏窄、右侧留白大，标题可以多给一点宽度。
3. **搜索 loading 期间整页只有一行字**：「正在连接本地题库，稍候即可搜索」
   期间 chips/feed 都不渲染，首屏有一两秒的空白闪。可以给 chips 区一个
   骨架占位。
4. **展开题组的题组卡片行内密度**：题组卡（命中高亮那套）信息密度可以，
   但「加入草稿卷」按钮要 hover 才浮现，容易不被发现（对新同事上手是
   门槛）。M2 邀同事前值得复查。
5. **草稿卷工作台 980px 断点**：竖排后工具栏组间没有分隔感（本刀只做了
   去掉竖线，没有补组间距强化）。窄屏用户少，低优先级。
6. **思考模式 checkbox 是原生样式**：与整体暖色语汇不搭，可换成与 chips
   同风格的开关。一行 CSS 的事，但属于「再打磨」档。
