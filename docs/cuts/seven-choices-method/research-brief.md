# 七选五研究：多余选项瞄准哪一空，每空凭什么锁定

## 背景

我们在给高考英语「七选五」写配套解析（给中国高中老师和学生看的 PDF）。七个选项填五个空，多两个。Owner 认为：这两个多余选项是命题人专门设的陷阱，常常是「一个干扰另一个」：某个多余选项和某一空的正确答案很像（同一个关键词、同一种句式、同一个话题），专门用来诱错那一空。讲好这两个选项是我们解析的特点。

你要回答的核心问题：**能不能稳定地把每个多余选项锁定到它专门干扰的那一空，并说清它像在哪、断在哪？** 同时给每空提炼「找法」线索，用来写做题心法。

## 材料

每组一个文件，在 `/tmp/claude-0/-home-user-english-question-bank/39a9a66b-ae6b-5b60-8a08-4128435244de/scratchpad/seven/dump/`。文件里有：原文（空用 `__36__` 标出，空后偶尔跟一个残留的小数字，忽略它）、七个选项、官方答案、多余选项字母、模型写的现有解析。

**现有解析只供参考，可能有错**。你的判断以原文、选项、官方答案为准。官方答案就是对的，不质疑。

## 每组要做的

### A. 两个多余选项（重点）

对每个多余选项写：

- `瞄准`：它最能诱错的那一空（题号）。如果同时能诱两空，写两个，主次分开。如果实在哪空都不像，写「无明确目标」，不要硬凑。
- `像在哪`：引选项里的英文原词和空前/空后的英文原词（一字不差），说明表面上为什么能接上。例如：选项里的 they 看似回指空前的 students；选项和空后都有 exercise。
- `断在哪`：引原文的英文原词，说明在哪一点接不上（指代对象不对、逻辑方向反了、时间/对象错位、话题对但说的不是这件事、和后文矛盾等）。必须能指出具体的词或事实，不说「不符合语境」这种空话。
- `影子`：它是否和瞄准那一空的**正确答案**成对：共用同一个关键词、句式、话题，像是照着正确答案改出来的。是就写「是」，并引两边的共同词；不是就写「否」。
- `把握`：明确 / 大致 / 牵强。

### B. 每个空（简要）

- `位置`：段首 / 段中 / 段尾 / 小标题 / 标题。
- `先看`：空前还是空后，还是整段。
- `锁定词`：一字不差地引原文中锁定答案的词（1–3 处）和选项中对应的词。
- `招式`：用一个短名字概括这空怎么解。可以从这些里选，不够就自己起新名字并说明：指代回指、连接词逻辑、问答呼应、原词或同义复现、并列平行（句式/结构一致）、小标题概括段意、段首总起、段尾总结、承上启下、举例说明、转折对比、因果。
- `现有讲解是否套话`：用搬家测试：现有讲解的主要句子原样搬到别的题还成立吗？写「是/否」，是的话引那句。
