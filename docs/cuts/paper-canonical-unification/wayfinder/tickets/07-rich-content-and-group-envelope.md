## Question

What must every Canonical Question Group share, and which facts must remain inside discriminated family variants? Design the common identity, source-map, digest, ordering, question/blank references, option-bank ownership, and validation envelope together with a minimal rich-content node model for text, semantic blanks, tables, figures, and source-linked media. Stress-test shared versus per-question option banks, nested or flattened tables, figure placement, punctuation ownership, inline annotations that are not paper semantics, and renderer projections so the canonical model cannot encode duplicated option ownership and renderer contracts can reject duplicated projection, without fossilizing placeholder strings or becoming a universal document AST.
