## Question

What must every Canonical Question Group share, and which facts must remain inside discriminated family variants? Design the common identity, source-map, digest, ordering, question/blank references, and validation envelope together with a minimal rich-content node model for text, semantic blanks, tables, figures, and source-linked media. Stress-test nested or flattened tables, figure placement, punctuation ownership, inline annotations that are not paper semantics, and renderer projections so the model does not fossilize placeholder strings or become a universal document AST.
