# 课标与高考应用文范文生成的对应关系

## 文件定位

本文件只摘取并转译《普通高中英语课程标准（2017年版2025年修订）》中
直接约束高考应用文写作与范文生成的内容。它不是整本课标的替代品，也不
包含课堂案例、课程安排或学生材料。

来源身份与 SHA-256 见 [`../source-manifest.json`](../source-manifest.json)。
以下小节名称与表号沿用来源 Markdown，便于回到原文核对。

## 1. 应用文是一种在真实语境中完成交际目的的语篇

来源：第五部分“课程内容”之“语篇”“语篇知识”。

课标把语篇界定为在具体语境中、为实现交际目的而使用的有意义语言单位。
应用文不仅是格式，也同时受以下因素控制：

- 交际目的；
- 参与者身份和关系；
- 时间、地点、场合与正式程度；
- 语篇类型、格式和结构；
- 句段之间的信息组织、衔接与连贯。

课标表3列出的相关语篇包括私人信件、电子邮件、宣传册、问卷、正式书信、
宣传稿、演讲、报告、新闻报道、观点类文章等。因此，Agent 不能把所有应用
文统一写成书信，也不能机械补称呼和落款。

### 对生成合同的约束

生成前必须确定：写作者、读者、关系、目的、场合、载体、格式和预期回应。
格式服从题面；语气服从关系；内容服从交际目的。

## 2. 语篇结构必须服务信息传递和观点表达

来源：“语篇知识”表7。

课标要求掌握常见应用文的基本格式、结构和语言特点，并根据交流需要：

- 选择恰当的语篇类型；
- 设计合理的语篇结构；
- 规划语篇组成部分；
- 保持句、段与主题之间的衔接和连贯；
- 运用次序、因果、概括与例证等语义逻辑关系；
- 根据新旧信息关系安排重要信息的位置。

### 对生成合同的约束

每句话都应承担明确功能：完成要点、补充读者所需信息、提供理由或证据、
推进逻辑、维持交际、完成收束。不能为了凑字数加入与任务主线无关的信息。

## 3. 得体性由对象、距离、场合和意图共同决定

来源：“语用知识”表8及教学提示。

课标要求根据交际目的、场合正式程度、参与者身份和情感距离，选择正式或
非正式、直接或委婉的语言。书面交际还要结合事由和跨文化背景，达到预期
交际效果。

### 对生成合同的约束

- 同辈交流可以自然、亲切，但不能轻浮或假装熟悉。
- 面向师长、组织者或陌生人时，应尊重、清楚，必要时先承认善意再委婉
  提出问题、请求或建议。
- 面向公众的报道、投稿、通知、倡议和演讲，应采用相应公共语体，不能套用
  私人书信口吻。
- “得体”不是添加几句礼貌套话，而是让全文的信息选择、请求力度、称呼、
  语气和收束方式共同匹配真实关系。

## 4. 表达性技能同时要求内容、结构、受众和问题解决

来源：“语言技能”表10。

必修阶段要求根据写作目的谋篇布局、起草、修改和校对；根据交际需要选择
正式或非正式语体；根据语篇类型和表达需要选择词汇、语法结构与衔接手段。

选择性必修进一步要求：

- 传递信息、论证观点、表达情感；
- 根据意图使用合理结构，有逻辑地构思内容；
- 根据受众特点选择恰当句式和词语；
- 从不同角度分析问题、提出解决办法；
- 比较、分析和评价内容与观点；
- 运用衔接手段保证连贯。

### 对生成合同的约束

Agent 必须先判断任务的主要认知动作：描述、告知、分享、比较、解释、评价、
论证、建议或解决问题。不同动作使用不同内容骨架，不能只替换几处主题词。

## 5. 高考的能力天花板是学业质量水平二

来源：“学业质量”表12及“学业质量标准的应用”。

课标明确：英语高考命题不超过学业质量水平二。水平二写作强调：

- 有效陈述事件、传递信息、表达观点和情感；
- 根据目的、正式程度、身份和角色选择语言；
- 有效描述、说明、解释、论证和评析；
- 表达清晰、得体、连贯；
- 从不同视角分析观点，有理有据地表达判断并提出解决办法。

水平三才强调熟练运用较复杂语言、丰富证据和更高强度的批判性论证。

### 对生成合同的约束

高分范文应是水平二的优秀执行，而不是用超出任务需要的复杂词汇和句式模拟
水平三。语言变化必须服务意义组织；清楚、准确、得体始终优先。

## 6. 高考任务强调真实性、开放性和综合运用

来源：“学业水平考试与高考建议”之“考试设计”“试题命制”。

课标要求考试情境接近真实语言交际，包含时间、地点、场合、目的、身份、
处境和心情等线索，并具有适度综合性与开放性，使作答者综合运用知识、技能
和策略解决问题。书面表达包括不同文体的写作任务。

评分标准应兼顾：

- 内容的达意度；
- 词汇、语法的准确性与得体性；
- 语篇的流畅性。

### 对生成合同的约束

Agent 不能只检查语法，也不能只追求“高级”。完成真实交际任务、覆盖要点、
使读者获得足够信息或被合理说服，是成文质量的首要证据。

## 7. 课标词汇和语法的工程落点

课标要求在语境中使用词汇、语块和语法表达意义，并强调“形式—意义—使用”
统一。该要求在题库工程中的落点是：

- 默认使用课标词及高频自然语块；
- 不为同义替换而冒险使用不确定表达；
- 语法结构只在压缩信息、突出重点或建立逻辑时使用；
- 最终词汇合规由仓库既有的高考词汇检查门负责，不把整份词表重复塞进
  Prompt；
- 不能因为词汇在课标内，就忽略搭配、语域和语境是否自然。

## 8. 给 Agent 的最短课标检查表

成文前后都要检查：

1. 这篇文字服务哪个真实交际目的？
2. 写作者与读者是什么关系，正式程度和表达力度是否匹配？
3. 体裁、格式与题面给定部分是否准确？
4. 每个要点是否变成读者真正能够理解和使用的信息？
5. 描述是否具体，论证是否有理由和证据，建议是否回应问题？
6. 句段是否围绕同一主线自然推进？
7. 表达是否达到水平二的清晰、得体、连贯，而非用复杂度冒充高分？
