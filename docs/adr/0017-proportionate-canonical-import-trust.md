# Proportionate trust at the canonical import seam

EQB accepts one deep canonical-import module as the semantic seam: a trusted adapter derives an Import Candidate from immutable source bytes, deterministic validation reports issues, and Teacher Confirmation is required before one complete Canonical Paper can be published atomically. We choose the least costly mechanism that closes the observed risk: verification strength scales with blast radius, irreversibility, and automation authority; shared adapter/schema/publication/renderer changes receive versioning, adversarial public-seam tests, one final full suite, and independent review, while a paper imported through unchanged accepted behavior receives digest binding, narrow deterministic checks, confirmation, atomic publication, and proportionate public-surface QA. This deliberately prefers one deep module over mirrored validation layers and rejects new frameworks or universal per-field proof obligations when the existing seam, deterministic validation, and human confirmation suffice.
