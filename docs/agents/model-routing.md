# Model and effort guidance

Manual owner dispatch remains the default; the owner-started
`$coordinate-eqb-wayfinder` exception may apply these same routes. This table
is the owner-approved project route to include in every `Next`, not independent
dispatch authority. Always report effort next to model.

| Work | Recommended model | Starting effort |
| --- | --- | --- |
| Coordinator, Wayfinder, grilling, domain modeling, to-spec, to-tickets, product investigation, implementation, fixes, QA preparation, and mechanical shipping | `gpt-5.6-sol` | `medium` |
| Every independent Standards review, Spec review, combined dual-axis review, and focused re-review | `gpt-5.6-sol` | `high` |

No current default EQB route uses `gpt-5.6-terra`. These defaults are explicit
owner direction. Any different model or effort requires fresh owner direction;
current tasks never inherit model choices from historical text.

If a route is unavailable, tell the owner and recommend the closest sensible
choice. Do not log availability probes, build substitution ledgers, or create a
blocked dispatch state. Model selection does not change product risk gates.
