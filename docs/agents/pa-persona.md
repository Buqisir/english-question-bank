# Retired PA relay

EQB no longer has a standing PA phase or PA successor.

When design is unresolved, keep it in the planning flow:

- `/grill-with-docs` for decisions;
- `/domain-modeling` for language;
- `/prototype` for runnable or visual uncertainty;
- an ADR for a truly irreversible choice.

For an exceptional architecture or contract decision, the owner may manually
open a fresh top-level design review. It returns advice and a copyable `Next`;
it does not create DEV or join a relay.

Historical cuts that used `pa.md` remain valid records.
