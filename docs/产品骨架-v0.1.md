# 英语题库工作台产品骨架 v0.1

日期：2026-05-09

## 一句话定位

一个本地优先的英语题库工作台，用来录入、检索、筛选、组题、排版并导出高考/模拟题风格的英语题集或试卷。

它不是单纯的“题目仓库”，而是教师备课时的“语篇材料库 + 题组管理器 + 组卷篮 + 成品导出器”。

## 核心教学判断

英语题库不应先按孤立小题堆积，而应先按“篇章/材料”组织。阅读理解、七选五、完形填空、语法填空、应用文材料和读后续写材料，本质上都依赖一个语篇或任务情境。

因此 V0 的主结构是：

```text
来源卷别 -> 篇章/材料 -> 题组 -> 小题 -> 选项/答案/解析
```

这样做的好处：

- 保留真题和模拟题的原始语境。
- 方便教师从材料主题、语篇类型、题型、难度、训练目标等角度找题。
- 未来可以做智能推荐：不是只推荐“某个题”，而是推荐“某篇材料适合训练什么能力”。

## V0 用户

第一阶段只服务黄老师个人使用。

不做账号系统，不做权限系统，不做公开发布，不做多人协作。

但数据结构要保留未来扩展空间：

- 可迁移到云端数据库。
- 可增加登录与班级/学生维度。
- 可接入智能推荐。
- 可接入外脑/教研判断，但 V0 不直接连接。

## V0 主要流程

### 1. 录题

教师手动录入或从 DOCX/PDF 导入后人工整理。

最小可用录入字段：

- 年份
- 地区
- 卷别
- 来源
- 篇章标题
- 篇章原文/材料
- 题组类型
- 小题题干
- 选项
- 答案
- 解析
- 标签
- 难度
- 小题题型

V0 可以先支持手动录入。DOCX/PDF 导入先做入口和原件归档，不追求自动解析完全准确。

### 2. 找题

教师可以通过关键词和筛选条件找到题目或题组。

V0 搜索条件：

- 关键词全文搜索
- 年份/地区/卷别
- 题型
- 标签
- 难度：低 / 中 / 高
- 来源：真题 / 模拟题 / 自建

搜索结果默认以“题组卡片”呈现，而不是单个小题列表。

每张卡片显示：

- 标题
- 来源信息
- 篇章摘要
- 题干/答案简览
- 标签、难度、来源
- 一键加入组题篮

### 3. 组题篮

组题篮是 V0 的核心操作区。

支持：

- 加入题组或小题
- 调整顺序
- 删除
- 修改题集/试卷标题
- 设置每题分值
- 保存为一套试卷/题集
- 切换学生版 / 教师版预览

V0 先以手动组题为主。自动组题只保留接口和后续设计。

### 4. 排版预览

V0 先做简洁试卷风格。

学生版：

- 保留题目、材料、题干、选项、答题区域。
- 不显示答案和解析。

教师版：

- 在学生版基础上显示答案和解析。
- 解析不追求花哨排版，优先清晰、可讲评。

### 5. 导出

V0 优先 DOCX。

PDF 可作为后续增强：

- 先从 DOCX 转 PDF。
- 或在网页内用打印样式导出 PDF。

## 页面骨架

### 题库列表页

用途：找题、筛选、加入组题篮。

布局建议：

- 左侧：筛选栏
- 中间：题组列表
- 右侧：组题篮

### 题目详情页

用途：查看完整篇章、小题、答案、解析、标签。

需要支持：

- 编辑字段
- 添加/删除小题
- 修改标签与难度
- 查看来源信息

### 录题页

用途：新建篇章、题组和小题。

V0 不追求复杂导入，先保证手动录入稳定。

### 试卷预览/导出页

用途：查看组题结果、切换学生/教师版本、导出 DOCX/PDF。

需要支持：

- 改名
- 调整分值
- 检查顺序
- 导出学生版 DOCX
- 导出教师版 DOCX

### 标签管理页

用途：管理标签系统和 AI 建议标签。

V0 简化为：

- 查看标签
- 新增/改名/停用标签
- 接受或拒绝 AI 建议标签

## V0 不做

- 不做用户登录。
- 不做多人协作。
- 不做云端同步。
- 不做学生作答系统。
- 不做自动批改。
- 不做复杂 AI 推荐。
- 不直接连接现有外脑和公众号录入流程。
- 不把 Open Design 当正式代码生成主链。

## V1 预留

- DOCX/PDF 自动解析。
- 题目自动结构化。
- AI 建议标签和难度。
- 按教学目标自动组题。
- 试卷模板管理。
- 与外脑概念/教研判断建立引用关系。
- 云端访问和账号系统。
- 学生作答与错题反馈。

## V0 成功标准

V0 做到以下程度就算成功：

1. 能稳定录入一篇材料和一组小题。
2. 能按关键词和筛选条件找到题组。
3. 能把题组加入组题篮并调整顺序。
4. 能保存一套题集/试卷。
5. 能导出学生版 DOCX。
6. 能导出教师版 DOCX。
7. 数据结构清楚，后续能继续扩展。
