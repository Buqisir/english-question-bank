# 英语题库工作台数据模型 v0.1

日期：2026-05-09

## 建模原则

V0 采用本地 SQLite。核心不是先追求复杂，而是把“语篇、题组、小题、组题篮、导出版本”这条链建稳。

主线关系：

```text
source -> passage -> question_group -> question -> option
                                       -> answer / explanation
tag <-> passage / question_group / question
paper_set -> paper_item -> question_group / question
import_file -> source / passage
```

## 枚举值

### source_type

- `real_exam`：真题
- `mock_exam`：模拟题
- `self_made`：自建
- `other`：其他

### difficulty

- `low`：低
- `medium`：中
- `high`：高

### question_group_type

先保留常见英语任务：

- `reading`：阅读理解
- `cloze`：完形填空
- `seven_choices`：七选五
- `grammar_cloze`：语法填空
- `writing`：应用文/写作
- `continuation`：读后续写
- `listening`：听力
- `other`：其他

### question_type

V0 可简单使用文本标签，后续再规范成枚举。

示例：

- 细节理解
- 推理判断
- 主旨大意
- 词义猜测
- 语篇结构
- 句子还原
- 语法填空
- 完形语义
- 写作任务

## 表设计

### sources

记录来源卷别或资料来源。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | 来源 ID |
| source_type | text | 真题/模拟题/自建/其他 |
| year | integer | 年份 |
| region | text | 地区，如 全国、新课标I、浙江 |
| paper_name | text | 卷别或资料名 |
| section | text | 题型板块，如 阅读理解B |
| publisher | text | 发布方/资料方，可空 |
| original_url | text | 原始链接，可空 |
| file_ref | text | 本地原件路径，可空 |
| note | text | 来源备注 |
| created_at | text | 创建时间 |
| updated_at | text | 更新时间 |

### passages

记录篇章或材料。一个来源下可以有多篇材料。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | 篇章 ID |
| source_id | text fk | 所属来源 |
| title | text | 篇章标题，可人工命名 |
| material_text | text | 原文/材料正文 |
| summary | text | 摘要，用于列表显示 |
| theme | text | 主题语境，可空 |
| discourse_type | text | 语篇类型，可空 |
| word_count | integer | 词数，可自动计算 |
| difficulty | text | 篇章整体难度 |
| note | text | 教师备注 |
| created_at | text | 创建时间 |
| updated_at | text | 更新时间 |

### question_groups

记录题组。一个篇章可以有多个题组。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | 题组 ID |
| passage_id | text fk | 所属篇章 |
| group_type | text | 阅读/完形/七选五等 |
| title | text | 题组标题 |
| instruction | text | 题组说明 |
| display_order | integer | 在篇章内排序 |
| default_score | real | 默认每题分值 |
| difficulty | text | 题组难度 |
| note | text | 教师备注 |
| created_at | text | 创建时间 |
| updated_at | text | 更新时间 |

### questions

记录小题。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | 小题 ID |
| group_id | text fk | 所属题组 |
| question_no | text | 题号，可存 1 / 36 / A 等 |
| question_type | text | 小题题型 |
| stem | text | 题干 |
| answer | text | 答案 |
| explanation | text | 解析 |
| difficulty | text | 小题难度 |
| score | real | 默认分值 |
| display_order | integer | 题组内排序 |
| note | text | 教师备注 |
| created_at | text | 创建时间 |
| updated_at | text | 更新时间 |

### options

记录选择题选项。非选择题可以没有选项。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | 选项 ID |
| question_id | text fk | 所属小题 |
| label | text | A/B/C/D |
| content | text | 选项内容 |
| display_order | integer | 排序 |

### tags

记录标签。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | 标签 ID |
| name | text unique | 标签名 |
| category | text | 标签类别，如 主题/能力/题型/语篇/教学 |
| description | text | 说明 |
| is_active | integer | 是否启用 |
| created_at | text | 创建时间 |
| updated_at | text | 更新时间 |

### tag_links

多态标签关联表。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | 关联 ID |
| tag_id | text fk | 标签 ID |
| target_type | text | `passage` / `question_group` / `question` |
| target_id | text | 目标 ID |

### paper_sets

记录保存下来的试卷、题集、讲义或训练。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | 试卷/题集 ID |
| title | text | 标题 |
| set_type | text | paper / handout / training / collection |
| student_version_title | text | 学生版标题，可空 |
| teacher_version_title | text | 教师版标题，可空 |
| description | text | 说明 |
| created_at | text | 创建时间 |
| updated_at | text | 更新时间 |

### paper_items

记录题集里的项目。V0 优先加入题组，也允许后续加入单题。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | 项目 ID |
| paper_set_id | text fk | 所属题集 |
| item_type | text | `question_group` / `question` |
| item_id | text | 题组或小题 ID |
| display_order | integer | 排序 |
| score_override | real | 分值覆盖，可空 |
| section_title | text | 分区标题，可空 |
| note | text | 教师备注 |

### import_files

记录导入原件，先做归档，不强求 V0 自动解析。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | 导入文件 ID |
| original_name | text | 原文件名 |
| stored_path | text | 本地保存路径 |
| file_type | text | docx/pdf/image/other |
| status | text | imported / parsed / reviewed / archived |
| source_id | text fk | 关联来源，可空 |
| note | text | 备注 |
| created_at | text | 创建时间 |

### ai_tag_suggestions

记录 AI 建议标签，必须人工确认。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | 建议 ID |
| target_type | text | passage / question_group / question |
| target_id | text | 目标 ID |
| suggested_tag | text | 建议标签名 |
| category | text | 标签类别 |
| confidence | real | 置信度，可空 |
| reason | text | 建议理由 |
| status | text | pending / accepted / rejected |
| created_at | text | 创建时间 |
| reviewed_at | text | 审核时间 |

### export_jobs

记录导出历史。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | 导出任务 ID |
| paper_set_id | text fk | 所属题集 |
| version_type | text | student / teacher |
| format | text | docx / pdf |
| output_path | text | 导出路径 |
| status | text | success / failed |
| error_message | text | 错误信息，可空 |
| created_at | text | 创建时间 |

## 搜索设计

V0 使用 SQLite FTS5 建立全文索引。

建议索引内容：

- passages.title
- passages.material_text
- passages.summary
- question_groups.title
- question_groups.instruction
- questions.stem
- questions.answer
- questions.explanation
- options.content
- tags.name
- sources.paper_name / region / section

搜索结果优先聚合到题组卡片：

```text
题组卡片 = 来源信息 + 篇章摘要 + 命中的题干/答案/标签 + 加入组题篮
```

## V0 数据边界

V0 不做：

- 学生表
- 班级表
- 作答记录
- 错题本
- 公开分享权限
- 云端同步字段

这些后续可以在不推翻主模型的情况下增加。
