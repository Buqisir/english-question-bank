# 相似题维度标准 v1（owner 2026-07-08 敲定）

相似题是产品三主打之一（时效 / 解析 / 相似题，owner 2026-07-08 定向）。
本文档是**唯一权威**：配相似的检索维度、导题管线考点标注工序的 schema、
相似抽屉的界面分组，均以此为准。修改须 owner 拍板。

## 宪法（相似题三句话）

1. **相似只有一个动词——配**：从一道题出发，配出一张练习纸。不做
   "换相似"（组卷换篇章是选材问题，走整卷浏览 + 草稿卷，不属相似题）。
2. **支点是维度，出口是练习纸**：卷 → 题 → 维度 → 相似候选 → 勾选 →
   练习纸（可起标题、可带解析变学案）。
3. **可信先于丰富**：说不出相似理由的维度不上界面；宁缺勿假
   （与难度维度同纪律）。

## 敲定维度表

| 题型 | 相似单位 | 维度（主 + 副） | 数据现状 |
| --- | --- | --- | --- |
| 语法填空 | **空**（上下文 = 所在句，拿不准退整段） | 语法考点（继承 Exam Brain 配方体系，标细粒度、界面粗粒度可下钻）+ 提示词形态（有提示·动/名/形副 vs 无提示·虚词） | 提示词形态规则可判（blanks 已存 hint）；语法考点待 AI 标注 |
| 阅读理解 | 题 | **题型**（细节/推断/主旨/词义猜测/态度/标题）+ 主题 | 主题现成（topic label 273/273）；题型半现成（parse questionType） |
| 完形填空 | **篇** | **主题**（难度带留白待用数据说话） | 现成 |
| 七选五 | **空** | 空位类型（段首主题句/段中承接/段尾总结）+ 主题 | 主题现成；空位类型待标注（配练呈现形态首刀实做时定） |
| 应用文写作 | 题 | **功能文体**（邀请/建议/申请/通知/投稿/演讲稿）+ 主题 | 主题现成；文体半规则可判 |
| 读后续写 | 题 | **情节母题** + 主题 | 主题现成；母题待标注 |

通用副维度：主题（全题型，数据已备）；年份/来源随档案行展示不参与检索。

## 明确不做 / 搁置

- **坑型维度（干扰项类型）搁置**：owner 担心"同坑型但表面不相干"的
  推荐显得不准，信任风险大。字段保留在解析数据（distractorAnalysis.type）
  不删，不进 schema v1、不做卖点。
- **难度带留白**：配相似跑起来后由真实使用决定是否加"简单一点的"。
- 换相似 / 题组级相似：不做（见宪法 1）。

## 分期点亮

- **Phase 1（现有数据即可上线）**：主题（全题型）+ 阅读题型 +
  语法提示词形态；相似检索底座用现有「找类似」embedding 后端。
- **Phase 2（导题管线考点标注工序）**：语法考点、空位类型、功能文体、
  情节母题；标注 schema 照本表写，存量卷回填。
- 单空上下文提取：segmentPaperText + blankPattern + hints 三件现成，
  输出体裁 = 单句语法填空练习（教学标准体裁）。

## 关联

- 讲评动线入口：「我考过的卷」（草稿卷/导出历史）→ 错题 → 配相似
  （用过标记与此同批数据）。
- 练习纸 = 练习模式 v1 的存在理由（流式、可起标题、可带解析变学案；
  与真题卷面保真分级区隔，见 nck1-paper-standard §8 及排版标准）。
- 界面动线刀序（2026-07-08 构思定）：flow-hover → 配相似动线 →
  练习纸 → 用过标记/「我考过的卷」→ 时效流；数据轨（标注工序）并行。
