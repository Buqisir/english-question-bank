# 相似题维度标准 v1（owner 2026-07-08 敲定）

> 2026-09-17：[当前产品方向](public-papers-personal-analysis.md)以检索、可用题量为主，
> 全卷教学解析不再是目标导题前提。本文题型维度仍是设计依据，但“完整讲评与检索
> 同次生产”、以完整续写解析作为唯一入池载体等耦合待重设计，不继续扩大。
> 下一步按实际消费者确认最小检索字段；个人解析不进入公共索引，也不改公共标签。
> 未接线维度仍未接线，现行索引/源确认规则不因本注记自动改变。

相似题是产品三主打之一（时效 / 解析 / 相似题，owner 2026-07-08 定向）。
本文档是**唯一权威**：配相似的检索维度、导题管线考点标注工序的 schema、
相似抽屉的界面分组，均以此为准。修改须 owner 拍板。

## 宪法（相似题三句话）

1. **相似只有一个动词——配**：从一道题出发，配出一张练习纸。不做
   "换相似"（组卷换篇章是选材问题，走整卷浏览 + 草稿卷，不属相似题）。
2. **支点是维度，出口是练习纸**：卷 → 题 → 维度 → 相似候选 → 勾选 →
   练习纸（可起标题、可带解析变学案）。
3. **可信先于丰富**：说不出相似理由的维度不上界面；宁缺勿假
   （与难度维度同纪律）。

## 导题解析与相似检索接线总则（owner 2026-09-01 确认整合）

导题不再分别生成一套“给人看的解析”和一套“给相似题用的分析”。同一次
题型解析保存两层信息：

1. `reason`、`teachingNote`、`fitSummary` 等学生可见字段负责把具体题目
   讲明白；
2. 受控分类字段负责相似召回、排序和质量审核，不直接翻译到 Screen、Print
   或 PDF。

相似字段仍是对完整源材料的可回填判断，不改变 ADR-0008 的源数据边界：题面、
选项和权威答案先按原合同保存；相似字段缺失或过期时，该题不得进入对应的
相似池，但不得伪造默认值。新 NCK1 解析生成应同时产出这些字段，避免几千套
题导入后再做一次无谓的全库理解。Owner Review 仍审核解析内容；模型标签不是
答案权威，也不是人工认可。

### 哪些由解析保存，哪些由程序派生

| 题型 | 解析保存的相似依据 | 程序派生或另存的依据 |
| --- | --- | --- |
| 阅读 | 每题 `similarityProfile`：题族、子型、细节范围、解题动作、写作手法 | A/B/C/D 篇位、话题、年份、来源身份 |
| 七选五 | 复用每空现有 `positionFacet`、`roleFacet`、`primaryMechanismFacet` | 话题、年份、来源；练习出口按命中空组装单空片段或整篇 |
| 完形 | 题组 `similaritySummary`：一句话写清发生了什么及怎样发展/转变 | Embedding 向量、话题、年份、来源 |
| 语法填空 | 每空现有 `facetKey`/`role` 加 `similarityProfile.route/features` | 从权威答案确定性派生的时态、语态、一致敏感性及答案形式 |
| 应用文 | 复用完整 Writing Task 与 ReviewCard 的文体、主题、对象和任务要求 | 对完整短题干做 Embedding；年份、来源 |
| 读后续写 | 复用新版 `continuationAnalysis` 的故事状态、矛盾、转折、关系变化和结局约束 | 程序从这些字段组装情节指纹并做 Embedding；不得嵌入范文自由发挥 |

不得让 AI 重写篇位、年份、来源、权威答案或可由答案表面确定的语法形式；
这些已有事实必须由程序读取或派生。Embedding 向量是可重建索引，不进入
教学解析 JSON，也不进入学生可见成品。

### 新增字段形状

阅读每题增加：

```json
"similarityProfile": {
  "family": "detail | main-idea | inference | word-meaning | reference | writing-method",
  "subtype": "受控子型",
  "detailScope": "single | multiple | null",
  "technique": "受控写作手法或 null"
}
```

语法填空每空增加：

```json
"similarityProfile": {
  "route": "当前 facetKey 下的受控判断路线",
  "features": ["同一路线下可多选的受控辅助特征"]
}
```

`facetKey` 先确定大考点，`route` 再记录本题真正采用的细路线，`features`
只保存必须并存的独立维度，不把自由文字塞入标签。具体值域以下文各题型已
确认分类及题型 Prompt 为准。旧解析可以没有新增字段；新生成若字段不完整，
相似索引跳过该题并等待回填，不能从 `reason` 临时猜标签。

## 阅读小题相似分类 v2（owner 2026-08-31 逐项确认）

阅读有两个入口，不能混成一种相似：

- **篇章相似**从整篇发起，优先同话题，再看同年份；不需要 AI 另写篇章
  标签，直接使用题库已有话题和年份事实；
- **小题相似**从具体题目发起，按下文题族、解题动作和 A/B/C/D 篇位匹配。

本节替代上表中阅读理解的旧分类。目标不是只按大题型找题，而是匹配老师
讲评时真正使用的**解题动作**。新导题合同已经保存下列细分动作；当前线上
相似排序仍只读取 `skill.primary`，尚未消费细分动作和 A/B/C/D 篇位。

### 相似排序

1. 同题型是门槛；
2. 同解题动作优先；
3. 小题相似也考虑 A/B/C/D 篇位；
4. 再看话题和年份。

篇位是文章信息量和阅读负担的代理，不替代解题动作，也不单独构成相似。
解析阶段应把解题动作写成受控字段，不能继续依赖自由文本猜测。

### 1. 细节理解题

细节理解同时标两个独立维度：**信息范围**和**解题动作**。

信息范围：

- **单细节**：题干指定一个明确的信息目标，可以从题干或选项定位原文；
- **多细节**：题干没有单一信息目标，A-D 各自提出一项信息，必须逐项回
  原文核验。四个选项即使集中在同一段、同一事件附近，也仍是多细节。

解题动作：

- **一般细节**：定位信息并识别同义替换；
- **行为原因**：`Why did sb/sth do ...?`，先定位行为，再找原因、动机或
  目的；
- **计算**：找到数字和规则，再计算或换算；常见于 A 篇，但仍独立标注；
- **对比整合**：分别找到两个对象的信息，再比较共同点或差异；
- **情境匹配**：提取人物需求或限制条件，再与活动、项目、产品等匹配。

一题可以组合为“单细节 + 计算”“多细节 + 一般细节”等。`Why does the
author mention X?` 不属于细节理解，归入下文的写作手法。

### 2. 主旨大意题

- **段落大意**；
- **文章大意**；
- **最佳标题**。

同子型优先；文章大意与最佳标题可以次级互配；段落大意因信息范围不同，
优先只配段落大意。

### 3. 推理判断题

- **细节推断**：由一个或多个文中事实推出未直接说出的结论；
- **观点态度**：判断作者或文中人物的态度、评价和立场；
- **写作目的**：判断作者写整篇文章的主要目的；
- **人物性格**：由人物的行为、语言和选择判断其特点；
- **文章出处**：由内容、语言、体裁和形式判断文章可能来自哪里。

续写推断、作者身份等低频形式暂不单列，出现时归一般推断。整篇写作目的
与局部 `Why mention X` 不混：前者属于推理判断，后者属于写作手法。

### 4. 词义猜测题

- **猜单词**；
- **猜短语**；
- **猜句子**。

### 5. 指代理解题

单独成类。判断 `it`、`this`、`that`、`they`、`the former` 等表达回指
前文的什么内容；核心动作是追踪回指关系，不归入词义猜测。

### 6. 篇章结构题

目前只暂立**写作手法**。典型题干包括：

- `Why does the author mention X?`
- 作者如何呈现某个问题；
- 作者如何解释研究结果；
- 作者为什么引用某人、某事或某项研究。

常见手法包括举例、比较、引用、列数据、下定义、引出话题和支持观点。
例证只是写作手法的一种具体变式，不把所有 `Why mention` 都标成例证题。

句段作用、行文组织和全文结构目前没有足够明确的真题依据，暂不立类。
Watkins predictions 题属于写作手法，不能作为句段作用题的例证。以后遇到
明确真题，先核实解题动作是否超出现有分类，再决定是否增类。

## 完形填空相似 v2（owner 2026-08-31 确认方向）

本节替代上表中完形填空的旧分类，也替代“只按同话题配篇章”的现行配方。

### 产品结论

- **不做小题相似，只做篇章相似**。一个空的难点同时依赖故事、前后逻辑、
  情感变化、搭配和选项辨析；按答案词性或单空表面特征配题没有稳定教学
  意义。若为保留语境附上全文，本质上已经是篇章相似。
- **不建立封闭的故事套路分类表**。真题确有“受挫—转变—成长”“意外—
  紧张—化险为夷”等反复出现的路数，但一篇可以同时命中多个路数，新题
  也无法被有限枚举穷尽。
- 每篇完形在导入解析时生成一句结构化概括，同时写清**发生了什么**和
  **事情怎样发展或转变**。现有 `overview` 与 `affectiveArc` 是生成这句
  概括的原始材料；不能只写“温暖的故事”一类空泛结论。

### 检索方式

1. 导入时由云端 Embedding 模型把一句话概括转成向量，只计算一次并保存；
2. 老师从库内完形发起相似检索时，直接使用已保存的种子向量，在几千篇中
   召回最接近的 30—50 篇，搜索时不重复调用 Embedding；
3. 视真题盲测结果决定是否再用重排模型精排候选并给出理由；若 Embedding
   排序已经够准，可以省掉这一步，做到搜索时零模型调用；
4. 同话题只作加分，不作硬门槛；真题优先和年份新旧用于后续收尾；
5. 系统负责召回和排序，老师负责最终选择。

这不是把几千条概括一次性塞进长上下文。Embedding 负责海选，重排模型只
读几十条候选，因此题库扩展到几千套后仍可稳定复用。

### Embedding 一致性与换型

- 同一个启用中的向量索引必须统一使用同一 `provider + model + version +
  dimensions + instruction/profile`；即使维度相同，不同模型的向量也不能
  混用。
- 一句话概括是长期保留的内容真值，向量是可重建索引。更换供应商或模型时，
  用新模型把全库概括重新向量化，保留新旧双索引做盲测，确认后一次切换；
  禁止只给新增文章换模型后混入旧索引。
- 摘要生成模型、Embedding 模型和重排模型不必来自同一家。只有同一索引中
  的种子与候选向量必须来自同一 Embedding 坐标系；读取原始文字的重排模型
  可以独立替换。

### 尚未拍板

- Embedding 供应商和具体模型不先写死。用现有 35 篇完形分别生成每篇的
  Top 5，打乱模型来源后由 owner 盲判，再选在本题库上最准的一家；
- 首轮候选优先覆盖中文能力强且有稳定云端接口的 Qwen 系列，并保留至少一
  个外部模型作对照；
- 当前 `semanticSearchService` 是本地关键词预筛后交给 DeepSeek 重排，
  并没有真实 Embedding 索引。后续可复用重排接线，但需新增向量生成、存储、
  版本记录和相似度召回层。

## 七选五相似 v2（owner 2026-08-31 确认方向）

七选五与完形不同：单空有稳定、可讲清楚的解题动作，因此重新启用**小题
相似**；但 A—G 选项池由五个空共享，查找单位和练习单位必须分开。

### 保留现有逐空框架

每个空继续记录三个独立维度：

1. **位置**：段首 / 段中 / 段尾；
2. **句子作用**：主旨句 / 概括句 / 承启句 / 衔接句；
3. **主要衔接机制**：逻辑词衔接 / 指代衔接 / 话题场对应。

位置说明空在哪里，句子作用说明放入后做什么，主要机制说明凭什么选出答案，
三者不能揉成一个标签。`topicClues`、`contextEvidence`、
`mechanismSignals`、`optionFit` 和关键干扰项继续作为解析证据，不另造一套
相似题分析。

现有 35 套共 175 个空已全部具备位置、作用、主要机制、话题线索和选项
匹配解释，数据基础可用。当前索引把五个空的标签聚合成题组级集合，导致
“每篇都有段中/衔接/话题场”近似恒真；这是消费单位错误，不是逐空框架
无效。后续相似检索必须保留 `questionId/blankId` 对应关系。

### 小题相似排序

1. 同“位置 + 句子作用 + 主要机制”的完整解题动作组合进入第一层；
2. 第一层候选通常很多，**同话题立即优先**，再看真题优先和年份。话题是
   强排序项而不是硬门槛：没有同话题时，仍可返回解题动作真正相似的题；
3. 完整组合确实不足时，才放宽为同“句子作用 + 主要机制”；放宽层仍先排
   同话题，再考虑位置、真题优先和年份，并明确告诉老师位置不同；
4. 卡片必须指出具体命中的空和理由，如“候选第 38 空：段中 + 衔接句 +
   指代衔接”，不能只说整篇七选五相似。

一篇候选若命中多个种子空，显示命中数并优先；同一篇只出现和加入一次。
整篇相似入口仍是组级同话题路线，小题相似入口从具体空发起，两者不混。

### 两个练习出口

同一次逐空检索提供两个出口，不做两套相似算法：

#### 1. 单空专项

- 输出目标空的**最小可解片段**、一个空和原题 A—G 七个选项；
- 段首主旨和段尾概括通常给完整目标段及标题；段中衔接通常给目标段；
  承启句必要时补前一段或后一段，不能机械截一个自然段；
- 第一版只复用原题七个选项，不让 AI 重编干扰项；
- 明示“衔接专项练习，不等同于原卷完整作答环境”。

#### 2. 整篇实战

- 输出完整文章、五个空和原题 A—G 七个选项，保留排除法与全文结构；
- 告诉老师其中哪个空与种子相似；学生版不暴露目标提示，教师版显示匹配
  空、分类和解析；
- 多个相似空来自同一篇时合并，整篇只加入一次。

因此最终边界是：**小题相似负责“以空找题和解释为什么推荐”，单空专项
负责集中练一个动作，整篇实战负责保留真实考试能力。**

### 上线前数据门禁

存量中仅深圳 2026 M1 模拟卷有 4 个框架外 `roleFacet`（`elaboration`、
`turn`、`closure`）。新分析器已给位置、作用、机制三个字段增加硬枚举校验，
禁止新增数据继续漂移；启用小题相似前仍须把这 4 个存量空重归到四类正式
句子作用，否则应跳过这些空，不能临时猜测。

## 语法填空相似 v2（owner 2026-08-31 已确认）

语法填空继续以具体空为小题相似单位，复用现有 22 个叶级考点，但逐类复核
真正决定相似的解题动作；不能把“已经有细标签”等同于配方已经足够细。

### 谓语动词（已确认）

谓语动词保留三个主维度：

1. **时态**；
2. **语态**：主动 / 被动；
3. **主谓一致敏感性**：作答时是否必须根据主语的人称和单复数选择不同的
   表面形式。

其中“时态”再增加一层**时态判断路径**，记录学生凭什么判出该时态；它不
是第四种语法现象，而是时态维度内部的解题动作。主谓一致不是单独题型，
而是谓语题的一个维度，主要覆盖：

- 一般现在时主动的三单与非三单；
- `is/are done`、`was/were done`；
- `has/have done`、`has/have been done`。

动词原形按当前命题常态视为基本不考，不为它建立相似题路线。历史真题中
若偶有祈使句原形等例外，归入低频“其他”，不能反过来扩张主流配方。

#### 时态判断路径（已确认主干）

**一般现在时：**

- **客观事实 / 相对稳定描述**：通常没有显性时间标志，靠句意判断文章在
  说明事实、性质、现状或常态；这是现有真题的主流。
- **显性频率标志**：`always`、`often`、`every ...` 等直接提示习惯或
  反复发生；即使存量低频也单列，不能误标成“无标志客观描述”。

**一般过去时：**

1. **明确过去时间**：具体年份、`... ago`、`last ...` 等直接锁定过去；
2. **过去语境暗示**：`then`、`previously`、`originally`、`in the old
   days` 等不一定给出具体时间点，但明确把状态或动作推回过去；
3. **过去叙事链**：没有直接提示词，目标动作只是过去事件链中的一环，靠
   前后谓语、并列动作或整段叙事时间线呼应来判断。

**现在完成时：**

1. **显性完成时标志**：`since`、`in/over the last ...`、`so far` 等；
   现有真题基本走这条路线；
2. **过去影响现在**：没有显性标志，必须从语义上感知过去动作对现在的
   结果、影响或延续；这类更常见于模拟题，但仍保留为独立解题动作。

**过去进行时：**只保留一条，判断过去某个时刻或另一过去动作发生时正在
进行的背景动作，常由 `when / while` 与过去事件建立关系，不再细分。

**过去完成时：**只保留一条，判断在另一个过去时间点或过去动作之前已经
完成的动作，即“过去的过去”，不再细分。

**情态动词后的谓语形式：**作为特殊谓语形式单列，不硬归入某个时态。核心
动作是情态动词后接动词原形；按当前命题常态，实际主要考主语与动词为被动
关系时填 `be done`，不为低频主动原形另建相似路线。

相似排序中，同一时态且判断路径相同应优于只同一时态；它与语态、主谓一致
的具体优先顺序在谓语分类全部盘完后统一确定。

### 非谓语动词（已确认）

非谓语先判断句法成分，再按该成分下的**答案语法类型**配相似；不需要另把
学生用了哪一步推理做成“解题动作”维度。现有 `fast / slow` 路径不参与
相似匹配。

#### 作状语（已确认主干）

状语的关键不是是否紧邻主句谓语或是否有逗号，而是目标非谓语在语义上
修饰哪个动作，并为该动作补充目的、主动伴随、被动等关系。被修饰的动作
本身也可以是非谓语。例如：

`Buying extra to benefit from price reductions doesn't make sense.`

其中主句谓语是 `doesn't make sense`，但 `to benefit from ...` 修饰的是
作为主语中心动作的 `Buying extra`，回答“额外购买是为了什么”，因此仍是
目的状语。该嵌套位置不另建类别，仍与其他目的状语相似。

当前确认的答案分类：

- 目的状语 `to do`；
- 目的状语的被动形式 `to be done`；
- 形容词后 `to do` 作状语；
- `only to do` 表意外结果；
- `doing`：逻辑主语主动；
- `done`：逻辑主语被动；
- `having done`：逻辑主语主动，且该动作先于所修饰的动作发生。

AI 应在导入解析时自动判断是否作状语，不要求老师逐题提供。判定顺序是：

1. 找出句中所有谓语和动作中心；
2. 找出目标非谓语实际修饰的动作，不能默认只看主句谓语；
3. 若它给某个动作补充目的、结果、主动伴随、被动等关系，才标作状语；
4. 若它受某个动词固定支配、填充主宾表补，或直接修饰名词，则分别归对应
   成分，不能因逗号或“句中已有谓语”就误标成状语。

逗号只是句首、句末分词状语的常见强提示，不是必要条件，也不是充分条件。
解析须同时输出被修饰动作的原文证据，便于发现 `aim to do` 被错标成状语
一类存量问题。

现有 2023 年全国乙卷 `Having visited ...` 是 `having done` 的真题依据；
当前数据错误地把其 `form` 存成 `done`，后续须修正，不能把完成式主动并入
“`done` = 被动”。

#### `to have done`（已确认单列）

完成式不定式 `to have done` 单列为答案形式，表示该动作早于谓语所表达的
判断或状态，如 `seem to have done`。它与 `having done` 都含“先发生”，
但句法成分和依附结构不同，不能互配：

- `Having done ..., S + 谓语 ...` 中，`having done` 是状语；
- `S seems to have done ...` 中，`to have done` 是受 `seem` 支配的完成式
  不定式补足成分，不是状语。

相似检索仍须先匹配句法成分，再匹配 `to-have-done` 这一答案形式。当前
35 套存量语法填空尚无该空，但 owner 确认已有真题考过；面向几千套题时
保留该低频小类，不能用当前小样本零计数否定它。暂不为尚无真题证据的
`to have been done` 自动扩类。

#### 作定语（已确认）

先锁定目标非谓语所修饰的中心名词，再区分不定式和分词。相似匹配使用受控
答案类别，不另比较学生的推理步骤。

**不定式作后置定语：**

1. **将来 / 尚未发生**：主动用 `to do`，被动用 `to be done`；
2. **解释抽象名词的内容**：如 `chance / ability / power / decision /
   plan / attempt + to do`，现有真题有 `the chance to discover`、
   `the power to change`；
3. **特殊限定结构**：序数词、最高级及 `the first / last / only` 等限定的
   名词后用不定式。`very` 本身不是独立触发词，通常进入 `the very first /
   last ...` 整体。

这三类先记录“不定式为什么作定语”，再记录答案形式 `to do / to be done`，
避免 `the first person to be chosen` 一类同时有特殊限定和被动时互相覆盖。

**分词作定语：**记录两个独立维度：

1. **位置**：前置 / 后置；
2. **答案关系与形式**：
   - `doing`：通常为主动；
   - `done`：及物动词通常为被动；不及物动词可表示动作完成后留下的状态，
     如 `fallen leaves`、`retired workers`，不是被动；
   - `being done`：正在被进行的动作，通常只作后置定语，如 `the bridge
     being built`。

除不及物动词 `done` 自带的完成 / 状态意义外，不再增加“与主句动作谁先谁后”
的时间维度。最终匹配按“不定式子类 + 形式”或“分词位置 + 形式 / 关系”的
完整组合进行；当前 18 个存量定语空均可归入该框架。

#### 作宾语（已确认）

先记录目标非谓语受动词、介词还是特殊结构支配，再记录答案形式；固定搭配
本身就是主要判断依据。

**动词后作宾语：**

1. 固定接 `to do`，被动答案为 `to be done`；
2. 固定接 `doing`，被动答案为 `being done`；
3. 同一动词两种形式都能接，但意义不同，单列为“形式改变意义”，例如：
   - `remember to do`（记得去做）/ `remember doing`（记得做过）；
   - `mean to do`（打算做）/ `mean doing`（意味着做）。

当前真题已有 `mean returning` 与 `remember being pushed`，因此第三类和
`being done` 都不是预造类别。解析必须输出支配动词及所取意义，不能只从
答案后缀反推。

**疑问词 + 不定式作宾语：**

- `what / how / when / whether + to do` 单列；
- 当前真题已有 `decide whether to bite`，不能混入直接的 `plan to do`。

**介词后作宾语：**

- 主动用 `doing`，被动用 `being done`；
- `look forward to`、`be devoted to` 等结构里的 `to` 是介词，仍接
  `doing / being done`，不得误判为不定式标记。

**`but` 固定结构：**不能简化成“`but` 后一律 `to do`”，须按完整结构：

- `have no choice but to do`；
- `do nothing but do`；
- `cannot but do`。

相似匹配使用“支配结构 + 选择类型 + 答案形式”的完整组合；不用要求支配
动词字面完全相同，但“只接一种形式”和“形式改变意义”不能互配成第一层。

#### 作主语（已确认）

`doing` 偏一般、常态或作为概念的行为，`to do` 偏具体、一次性或尚未发生，
可作为理解方法，但不是硬判据；考试中应先看句型。主动和被动形式都可以
作主语。

相似分类：

1. **直接主语 + `doing`**：主动的一般活动；
2. **直接主语 + `being done`**：被动的一般经历、过程或状态；
3. **不定式主语 / `it` 形式主语 + `to do`**：主动；
4. **不定式主语 / `it` 形式主语 + `to be done`**：被动；
5. **固定接动名词的形式主语句型**：如 `It is no use/good doing`，被动时
   用 `being done`。

当前存量已有直接主语 `Reading ...`、`It is possible to walk` 和 2026
全国卷 `It is + adj + for them + to be held`，说明直接主语、形式主语和
被动不定式都需保留。解析与匹配先看“直接主语 / 形式主语 / 固定句型”，
再看 `doing / being done / to do / to be done` 的答案形式。

#### 作表语（已确认）

表面同为 `doing` 的答案可能是动名词，也可能是分词，必须先区分是在说明
主语“内容是什么”，还是在描述主语的性质、感受或状态。

**名词性表语（说明内容）：**

- `doing`：一般、长期或经常性的活动；
- `being done`：一般性的被动经历、过程或状态；
- `to do`：具体目标、计划、任务或下一步；
- `to be done`：具体的被动目标或待办任务。

“动名词偏一般、不定式偏具体”只作辅助理解，优先看主语中心词和句型：
`hobby / job / favorite activity` 等通常引出活动内容，`goal / aim / plan /
purpose / task` 等通常引出具体不定式目标。

**分词性表语（描述性质、感受或状态）：**

- `doing`：主语主动产生某种影响，或具有相应性质；
- `done`：主语感受 / 承受影响，或处于被动、完成后的状态。

“人用 `done`、物用 `doing`”不是规则；应判断谁产生影响、谁感受或承受
影响。人也可以是 `an inspiring teacher`，人群也可以是 `a bored
audience`。

解析还须区分 `His fear is being ignored`（动名词被动式作表语）与 `He is
being ignored`（进行时被动谓语），不能仅凭 `be + being done` 的表面形式
归类。当前 `stays closed` 已正确归非谓语作表语，但 `excited`、`educated`
等真实分词表语仍错放在“动词变形容词”桶，后续须重归后才能正确参与相似
匹配。

#### 作宾语补足语 / 主语补足语（已确认）

宾补补充说明宾语，宾语是目标非谓语的逻辑主语或承受者；主动句变被动后，
原宾语升为主语，同一非谓语改作主补。不能把“主谓关系”只理解成主动：
还须判断中心词是发出动作、承受动作，还是处于某种状态。

**宾补四组：**

1. **一般支配动词**：如 `allow / tell / ask / expect / force / encourage`
   等，基本结构为“动词 + 宾语 + `to do`”，逻辑宾语承受该动作时用
   `to be done`；
2. **感官动词**：`see / hear / watch / notice / observe / feel` 等，可接
   `do / doing / done / being done`。主动句裸原形 `do` 因答案不变而很少
   直接设空，但解析必须识别，才能在被动句中正确还原 `to`；
3. **高频特殊支配动词**：核心为 `make / let / have / get / catch / find /
   keep / leave`，另保留 `help sb (to) do`。该组不是一张通用接法表，须
   记录具体支配动词及它实际允许的 `do / to do / doing / done / being
   done`；标签使用原形 `get`，不使用 `got`；
4. **`with` 复合结构**：`with + 宾语 + doing / done / being done / to
   do`，按宾语与动作的主动、被动、进行或待发生关系选择形式。

核心八个是老师高频记忆框架，不是封闭白名单。`set/send + 宾语 + doing`
及 `want/need/prefer + 宾语 + done` 等低频真实结构可按证据进入同一受控
支配词表，不另膨胀顶级类别。

**主补三组：**

1. **一般动词被动结构**：如 `be allowed/told/expected to do`，内层动作
   被动时可用 `to be done`；报告、认知类 `be said/reported/believed/
   thought/known to do/to have done` 也归本组，但保留来源子型，不能把
   `be said to do` 错还原成 `say sb to do`；
2. **感官动词被动结构**：主动句 `see/hear sb do` 变被动时恢复为 `sb be
   seen/heard to do`；原来是 `doing / done / being done` 时不增加 `to`；
3. **特殊支配动词的可被动结构**：如 `be made to do`、`be caught doing`、
   `be kept/left doing/done`。不能把八个动词机械地全部变被动；`have/get`
   等须按真实结构处理。

相似匹配先区分宾补 / 主补，再比较支配动词组、具体结构和答案形式；对应的
主动宾补与被动主补可以作为明确标注角色变化的放宽层。

**状态型分词宾补（已确认）：**

- 结构：支配动词 + 宾语 + `doing / done`；
- 先找分词实际补充的宾语中心词；中心词主动做事或产生影响用 `doing`，
  中心词感受 / 承受影响或保持结果状态用 `done`；
- 常见支配动词包括 `keep / leave / find / make`。

例如 `keep somebody astonished` 中，可还原为 `somebody is astonished`；
`somebody` 是感受者，故用 `done`。`keep somebody astonishing` 表示让此人
持续“令人震惊”，不是“让他保持震惊”。

该类与分词表语共享“产生影响 / 感受承受 / 结果状态”的答案关系，但句法
角色不同：`They remain astonished` 是分词表语，`The news keeps them
astonished` 是状态型分词宾补。第一层相似须保留角色区别；候选不足时可用
共享的“感受者 / 承受者 + done”等标签作放宽层，并明确角色不同。

当前真题 `leave us astonished` 错放在“动词变形容词”桶，后续须重归为
“宾补 + 状态型 + done”。

### 提示词为动词的派生（已确认）

提示词为动词时，先判断目标答案是否为谓语或非谓语；只有句法位置确实要求
另一词性时，才进入派生：

1. **动词 → 名词**：统一一个相似类别，如 `require → requirement`、
   `believe → belief`、`develop → development`、`arrive → arrival`、
   `guide → guidance`、`solve → solution`。冠词、物主代词、形容词、
   介词后或主宾表位置只作为“这里缺名词”的证据，不再拆相似子类；
2. **动词 → 真正的形容词**：统一一个相似类别，只收 `taste → tasty`、
   `remark → remarkable`、`sleep → asleep` 等非分词派生。

答案为 `-ed/-ing` 时句法功能优先：作定语、表语、状语、宾补或主补均归
非谓语七格，不得以“看起来像形容词”为由归动词变形容词。当前原始数据有
16 个动词变名词空；原标 9 个动词变形容词空中，`astonished`、`excited`、
`educated`、`shared`、`recommended`、`existing` 六个应重归非谓语，真正
派生形容词只余 3 个。当前无动词变副词空，且通常涉及连续派生，暂不建立
类别；以后有真实设空再增加。

### 提示词为名词（已确认）

分类从提示词词性出发，不先笼统地说“词形转换”。提示词为名词时先分三条
主路线：名词的数、名词所有格、名词派生为另一词。

#### 名词复数（已确认）

按答案变复数的判断来源分五类：

1. **数量限定词**：`many / few / a few / several / numerous / a number
   of` 等提示可数名词复数；`much / little / a little / a great deal of`
   提示不可数名词，不能误当复数信号；
2. **句子数的一致关系**：由复数谓语、`there are`、复数主语与表语呼应等
   句法关系反推，如 `Activities range`、`Studies show`、`They are
   treasures`；
3. **并列结构**：与相邻并列项保持复数，如 `gates and watchtowers`、
   `notes, stories and illustrations`；
4. **语境中的多个 / 泛指一类**：无显性数量词，靠语义判断为多次、多种、
   多个或泛指群体，如 `humans / interviews / populations / seasons /
   afternoons / necessities / events`；
5. **词义变化后可数化**：提示词在目标词义下成为可数名词，如 `time`
   表“次数”、`favorite` 表“喜爱之物”、`number` 表一个个数字。

当前 35 套共 19 个名词复数空仍全部只带 `noun.number`，尚未记录上述判断
来源。后续解析须增加受控来源字段并附原文证据；相似匹配以同来源优先。

#### 名词所有格（已确认）

所有格统一为一个相似类别，不按所有者语义继续拆分。答案形态仍须正确处理：

- 单数名词和不以 `s` 结尾的不规则复数加 `'s`，如 `student's / people's`；
- 规则复数已以 `s` 结尾时只加撇号，如 `students'`。

当前 3 个存量空为 `son's / person's / people's`。形态差异由规则生成和
校验，不构成不同的相似题类别。

#### 名词派生（已确认）

只列三个方向：

1. **名词 → 形容词**：当前 16 空，是绝对主体；
2. **名词 → 另一名词**：当前 1 空，如 `photograph → photographer`；
3. **名词 → 动词**：当前 0 空，低频但保留。

名词变动词必须使用两层标签，不能在“派生方向”处终止：第一层记录
`noun-to-verb`，第二层继续按结果动词判断谓语 / 非谓语。若为谓语，复用
时态、语态、主谓一致及时态判断路径；若为非谓语，复用句法成分与
`to do / doing / done ...` 等答案分类。单值 `facetKey` 只表达派生方向；
新增 `similarityProfile` 用 `route` 记录 `finite-result / non-finite-result`，
并在 `features` 复用对应的谓语判断路线或非谓语成分路线。时态、语态、
一致敏感性和答案形式仍由程序从权威答案派生，不交给 AI 重写。

### 提示词为形容词（已确认）

#### 形容词变副词（已确认）

派生方向只有“形容词 → 副词”一个，但按副词实际修饰范围分五类相似题：

1. **修饰形容词**：如 `completely different / particularly true`；
2. **修饰谓语动词**：如 `moved gently / slipped accidentally`；
3. **修饰非谓语**：如 `digitally generated / originally meaning /
   merely waiting`；
4. **修饰整个句子**：如 `Basically, ... / Fortunately, ...`；
5. **修饰副词、数词或数量**：如 `rarely enough / roughly 200`。

当前 15 个存量空已覆盖这五种范围，但分析数据只记录派生方向，没有受控的
修饰对象。后续须输出被修饰中心词或整句范围的原文证据。

#### 形容词比较级（已确认）

判断信号可多选，不强迫一题只能归一个来源：

1. `than` 显性比较；
2. `much / far / a lot / even / still / slightly / a little` 等程度修饰；
3. 与相邻 `higher / fewer / smaller ...` 等比较级并列呼应；
4. 无形式标志，靠上下文中的比较对象或前后状态作语义比较；
5. 固定句式：`the + 比较级, the + 比较级`、`比较级 and 比较级`、
   `more and more + 形容词` 等。规范示例是 `the less, the better`，不是
   `the little, the better`。

#### 形容词最高级（已确认）

1. **明确范围或唯一结构**：`in/of/among ...`、`one of the + 最高级 +
   复数名词`、`Africa's highest ...`、`the best ... ever` 等；单独一个
   `the` 不能证明最高级，还需范围、唯一性或语义支持；
2. **纯语义最高级**：从多个对象中选最好，或表达唯一最大、最好、最细等，
   但没有明显范围词。

比较级和最高级必须先分开，不能继续只共用一个 `adjective.comparison`。
按实际命题习惯，通常不要求提示形容词连续完成“变副词 + 再变比较级”两次
变化，因此不为 `more carefully` 一类预造组合标签；以后有真实题再处理。

#### 形容词变名词（已确认）

统一为一个相似类别：先根据句法位置判断该空需要名词，再把提示形容词派生
为名词。介词后、冠词或限定词后、主宾语位置、与名词并列等，只作为“此处
缺名词”的解析证据，不拆成不同的相似题子类。

当前 9 个存量空包括 `curious → curiosity`、`accurate → accuracy`、
`responsible → responsibility`、`rich → richness`、`visible →
visibility` 等。形容词提示词分支至此完成。

### 有提示词代词（已确认）

以给出的人称代词主格为主要入口，按目标答案形式分五类：

1. **宾格**：如 `he → him`；
2. **形容词性物主代词**：如 `they → their`；
3. **名词性物主代词**：如 `I → mine`；
4. **反身代词**：如 `I → myself`、`they → themselves`；
5. **`one → ones` 名词替代**：用 `one/ones` 替代前文已出现的名词，避免

主格答案通常不设空，因为提示词无需变化。当前 10 个存量空为形容词性物主

### 有提示词数词（已确认）

### 无提示词介词（已确认）

介词统一为一个大类，内部只按主要解题动作分两类：

1. **纯固定搭配**：答案主要由前后的动词、形容词、名词或完整短语锁定，
   如 `compete for`、`be similar to`、`focus on`、`from ... to ...`、
   `without doubt`；
2. **介词本义 / 上下文关系**：主要靠判断时间、地点、方式、对象、身份、
   施动者、逻辑主语、增量等关系选出介词，如 `in the Tang dynasty`、
   被动结构中的 `by`、`increase by 2.1`、`as the capital`、`for sb to
   do`。

当前 35 套共 31 个介词空，全部可以落入这两类，不需要第三个顶级类别。
有些结构既常作为搭配记忆，又保留明显本义，不重复贴两个相似类别：若去掉
固定支配词或短语后便难以锁定答案，归“纯固定搭配”；若答案主要来自两部分
之间的语义关系，归“介词本义 / 上下文关系”。边界题只记录主要决定因素，
解析证据仍可同时说明搭配和介词关系。

### 无提示词冠词（已确认）

冠词相似不能只比较答案是 `a/an` 还是 `the`，须按决定冠词的主要解题
路线匹配。

**使用 `the` 的四条路线：**

1. **返指**：前文已经提及，后文以原词、上位词或唯一相关事物再次指向
   同一对象；
2. **共同语境**：前文未提及，但根据当前场景、双方共享的当地情形或常识，
   能够确定是哪一个；
3. **后置修饰后的特指判断**：名词后的 `of` 短语、其他介词短语、定语
   从句、不定式或分词使读者能够确定是哪一个。修饰语本身不自动决定用
   `the`，必须判断修饰后是否真正形成特指；
4. **结构锁定 `the`**：内部保留最高级 / 序数词，`one ... the other` /
   `the same`，固定带 `the` 的专有名词类别，数量 / 比例结构，`the +`
   形容词指一类人，以及固定短语六个子类。精确相似优先匹配同一子类，候选
   不足时才放宽为同属“结构锁定 `the`”。

**使用 `a/an` 的三条路线：**

5. **第一次引入 / 任意一个**：单数可数名词首次进入话题，或只表示该类
   中未指定的任意一个；
6. **补充身份或类别**：中心对象已经出现，随后在表语、`as` 后或同位语
   中说明它是什么。若身份已被限定为唯一，仍可能用 `the`；
7. **结构锁定 `a/an`**：内部区分 `a range of / a touch of / as a
   result` 等固定短语，与 `a success / a pleasure / a must / a
   must-read` 等抽象词具体化。前者主要靠搭配，后者主要判断抽象概念是否
   落成一件具体的事或一个具体的人。

`a` 与 `an` 的语音选择是上述路线确定后的第二层标签，不作为第一层相似
类别。除一般的辅音 / 元音音素外，保留 `a unique / a university / a
one-of-a-kind` 与 `an hour / an 81-year-old` 等拼写和读音不一致的特殊
发音证据。

当前 35 套共 24 个冠词空，全部能落入上述路线：`the` 16 空，包括返指 1、
共同语境 1、后置修饰形成特指 5、结构锁定 9；`a` 8 空，包括第一次引入
3、结构锁定 5。当前尚无 `an` 或补充身份空，但 owner 提供的冠词专项材料
已有对应真实教学样本，故保留这两条路线。现有分析仍只标
`no-hint.article`，后续须补主要路线、结构子类及 `a/an` 语音证据。

### 无提示词代词（已确认）

真题和高质量模拟题以无提示词 `it` 及名词替代为主，先保留六条受控路线：

1. **回指 `it`**：回指前文的单数事物、动作或整件事情，须输出明确先行
   内容；
2. **形式主语 `it`**：`it` 先占主语位置，真正主语是后面的不定式、动名词
   或从句；
3. **形式宾语 `it`**：常见于 `find / think / make ... it + 补语 + to
   do / that ...`，真正宾语在后；
4. **强调句 `it`**：识别 `It is/was + 被强调部分 + that/who ...` 框架；
5. **替代词 `that/those`**：为避免重复，替代前面已出现的同类名词；
   `that` 替代单数可数名词或不可数名词，`those` 替代复数名词，常见于
   比较结构并后接 `of ...` 或定语从句；
6. **无人称 / 固定用法 `it`**：表示天气、时间、距离、环境等，低频保留。

回指 `it` 表示仍是前面同一个对象；替代 `that/those` 通常表示同类中的
另一个或另一些对象，二者不能合并。当前 35 套只有 1 个无提示词代词空，
为回指 `photography` 的 `it`；`that/those` 由 owner 根据模拟题命题事实
确认保留。暂不把 `one/ones`、`another` 及所有不定代词预先展开为“代词
大全”，以后有真实设空再增加。

### 无提示词并列连词（已确认）

并列连词先按主要逻辑关系分五条普通路线：

1. **并列、补充或顺承**：主要使用 `and`；
2. **转折或对比**：主要使用 `but / yet`；
3. **选择**：使用 `or` 表示两种可能或二选一；
4. **解释或换一种说法**：使用 `or` 表示“或者说 / 也就是”，不能与选择
   路线合并；
5. **因果**：使用 `so / for`，当前存量尚无，作为常规命题路线保留。

关联连词不按单个答案归入普通 `and / but / or`，而按完整配对结构匹配：

- `not ... but ...`：不是 A，而是 B，表示纠正或替换；
- `not just ... but (also) ...`：不只是 A，而且 B，表示递进补充；
- `not only ... but (also) ...`：表示递进补充；
- `both ... and ...`：A 和 B 两者都；
- `either ... or ...`：两者择一；
- `neither ... nor ...`：两者都不；
- `whether ... or ...`：列出两种情况或表示无论哪一种。

精确相似优先匹配同一套关联结构；例如 `not ... but ...` 不能仅因答案含
`but` 就与普通转折句匹配。被连接的是词、名词短语、谓语、非谓语、独立
主格还是完整分句，作为第二层结构信息，不膨胀为第一层类别。

当前 35 套共 25 空：`and` 17、`or` 4、`but` 2、`neither` 1、`than` 1。
其中 `than` 实为比较结构连接词，现错放在并列连词叶级；后续应重归比较
结构路线，不能参与普通并列连词匹配。

### 无提示词定语从句关系词（已确认）

第一层按关系词在定语从句中承担的成分匹配：

1. **缺主语**：先行词指人用 `who/that`，指物用 `which/that`；
2. **缺宾语或表语**：指人用 `who/whom/that`，指物用 `which/that`；
   限制性从句中作宾语的关系词有时可以省略，真实设空须说明为何需要填写；
3. **缺定语 / 所属关系**：人或物均可用 `whose + 名词`，须输出后面名词
   与先行词的所属证据；
4. **缺状语**：从句主宾结构完整时，根据时间、地点、原因关系使用
   `when / where / why`；先行词表示时间、地点或原因并不自动决定关系
   副词，如 `a place which welcomes ...` 中从句缺主语，仍用关系代词；
5. **介词 + 关系代词**：指人使用“介词 + `whom`”，指物使用“介词 +
   `which`”；介词由搭配或上下文关系决定，介词提前后不能用 `that`；
6. **`as` 特殊结构**：如 `such ... as`、`the same ... as`、`as is known
   to all`、`as often happens`，按固定结构和“正如”含义判断。

第二层记录先行词指人 / 物 / 整件事，以及限制性 / 非限制性。非限制性定语
从句有逗号，不能用 `that`；关系词指代前面整件事情时主要比较 `which /
as`。精确相似先匹配所缺成分，再比较先行词和从句类型，不能只按最终答案
词匹配。

当前 35 套共 21 空：`which` 8、`that` 6、`who` 3、`where` 3、`whose`
1；尚无 `when / why / whom / as`，但均属常规真实考法，按 owner 确认
保留。

### 无提示词名词性从句连接词（已确认）

先记录从句整体在主句中作主语、宾语（含介词宾语）、表语还是同位语，再按
从句内部结构和句意匹配以下真题主干路线：

1. **`that`**：从句结构完整，陈述一件确定的事情，`that` 只负责连接；
2. **`whether / if`**：从句结构完整，表达“是否”；解析须保留所在位置，
   以处理只能用 `whether` 的主语从句、表语从句、同位语从句、介词后、
   `whether to do` 及 `whether or not` 等限制；
3. **`what`**：从句缺主语、宾语或表语，且前面没有先行词；这是连接代词
   中的绝对主力，须与不在从句内充当成分的 `that` 区分；
4. **`who`**：从句缺表示人的主语或宾语，低频保留，不为 `whom` 另建
   相似类别；
5. **`when / where / why / how`**：从句主干完整，分别补时间、地点、
   原因或方式信息；
6. **疑问词 + 不定式**：如 `what/how/where/whether + to do`，不是普通
   完整名词性从句，须作为相邻但独立的结构优先互相匹配。

根据 owner 的长期教学经验，`whatever / whoever / whichever` 等 `-ever`
系列及名词性从句中的 `which / whose` 基本不考，当前不建立相似类别；以后
几千套题中有足够真实设空证据再增加。当前 35 套共 9 空：`what` 5、
`whether` 2、`why` 1、`how + to do` 1，正好支持该收缩方向。

### 无提示词状语从句连接词（已确认）

状语从句按主从句的实际逻辑关系匹配，不按连接词字面匹配；`as / since /
while` 等多义词必须标明本题中的实际关系。保留九类：

1. **时间**：内部细分同时发生 `when/while/as`、先后 `before/after`、
   起点 `since`、截止 `until/till`、一……就…… `once/as soon as/the
   moment ...`；
2. **原因**：`because / since / as / now that`；
3. **条件**：`if / unless / as long as / provided/providing that`，其中
   `unless` 保留“相当于 `if ... not`”的否定条件证据；
4. **让步**：`although/though / even if/even though / while / no matter
   ...`；
5. **目的**：`so that / in order that`，回答“为了什么”；
6. **结果**：`so ... that / such ... that` 及表结果的 `so that`，不能
   与目的 `so that` 合并；
7. **方式**：表“按照 / 正如”的 `as` 及 `as if / as though`；
8. **比较**：`than / as ... as`；现错放在并列连词的 `than` 应迁入本类；
9. **地点**：`where / wherever`。

高考很少直接考完整九类，但模拟题会覆盖，故保留为扩展分类。排序不能让
理论上的低频类别挤占真实高考路线：有同关系候选时精确匹配；候选不足时按
高考 / 模拟来源和真实频率放宽。当前 35 套仅 3 空，包括时间同时发生
`when/as`、时间先后 `before`、方式“正如”`as`，也说明不得只因答案同为
`as` 就判为相似。

## 应用文写作相似 v2（owner 2026-08-31 已确认）

应用文以整道作文题为相似单位，只保留三个维度：

1. **文体 / 交际功能**：邀请、建议、申请、通知、投稿、演讲稿等，是第一
   优先级，决定写作动作和基本结构；
2. **主题**：校园活动、传统文化、环境保护、志愿服务等，提供可解释的
   主题优先；
3. **整题 Embedding**：直接嵌入完整短题干，包括写作者身份、写作对象、
   情境和内容要求，不先调用大模型概括，避免短题被二次摘要后丢信息。

排序为同文体优先，再看同主题及 Embedding 对具体情境和任务要求的接近
程度；同主题但文体不同的题不应压过同文体候选。Embedding 在导题时离线
计算一次并存储，点击“配相似”只做向量检索，不额外调用生成式大模型。

## 读后续写相似 v2（owner 2026-08-31 已确认）

读后续写以整道原文、两个段首句和写作要求组成的完整任务为相似单位。相似
目标不是表面场景相同，而是续写所需的情节推进动作相似。当前讨论中的主要
维度为情节母题、主题及结构化情节摘要 Embedding。

**新版解析是入池硬门槛（已确认）：**

- 只认基于原文、两个段首句和写作要求生成的当前结构化续写解析；
- 旧版 `continuationDesign.theme` 只有一句主题思想，缺少故事当前状态、
  核心矛盾、人物关系变化、段首句约束、必需转折和结局方向，不能参与相似
  检索；
- 不把旧主题字符串直接做 Embedding，也不写兼容转换冒充新版数据；
- 旧题须从源材料重新解析，完成前宁可显示“暂无可用相似分析”，也不返回

当前 18 道续写中只有最新 2 道具备完整 `continuation-analysis-v1`，其余
16 道必须重跑新版解析。现实现也明确禁止写作题配相似，尚无可用续写检索。

**情节母题使用开放式情节指纹（已确认）：**

续写套路无法穷尽，不建立封闭的母题枚举表。新版解析按固定结构生成一条
人可读、可嵌入的情节指纹：

> 人物起点 → 核心矛盾 / 抉择 → 关键转折 → 人物关系变化 → 结局方向

例如铲雪故事可概括为“兄弟为买车替人铲雪 → 已收钱却想半途而废 → 主人公
选择守诺并带动兄弟 → 共同完成工作 → 获得认可并理解诚信比金钱重要”。
情节指纹不是自由发挥的摘要，其内容从当前结构化解析的 `centralSituation`、
`unresolvedProblem`、`relationships`、`coreTension`、
`requiredTurningPoints`、`relationshipMovement`、段首句功能及
`closureRequirements` 等有原文证据的字段组装；不使用旧主题，不嵌入
范文措辞，也不让某一篇范文的自由选择冒充题目硬约束。

相似检索以情节指纹 Embedding 比较“需要怎样续写”为主，主题作为价值方向
的结构化加权和可解释理由。雪地、自行车、图书馆、动物等表面场景不应压过
核心矛盾、转折和人物关系推进。Embedding 在新版解析完成后离线计算一次；
运行时只做向量召回与结构化主题加权，不把几千篇全文重新塞给生成式模型。

## 语法填空单空上下文铁律（owner 2026-07-08 拍板，本功能特色所在）

- **整段为单位**：目标空所在的整个自然段全文给出——语法填空考纲本质是
  语篇中的语法（时态链/指代/衔接常跨句），单句练习是普通练习册做法，
  恰恰要区别开。**不做单句体裁**。
- **非目标空用答案回填**：同段其他空还原成通顺原文（answerKey 现成，
  纯规则），只留目标空。学生读完整语篇，做精确任务。
- **同段/同篇多目标自动合并**：勾选同篇 3 个空 → 该段只印一遍、3 空
  同时留白。
- **上下文尺度不做运行时智能判断**：规则（整段）打底；标注工序顺手
  加 `context_scope` 字段（段内可解 / 需跨段），跨段依赖的空练习时
  自动附带前一段。运行时零 AI 开销。
- 篇幅账：10 目标空 ≈ 800 词 ≈ 练习纸 1.5-2 页 A4，为语篇完整性可接受；
  练习纸流式排版行距从紧。
- 工程件：segmentPaperText + blankPattern + hints + answerKey 四件现成。
