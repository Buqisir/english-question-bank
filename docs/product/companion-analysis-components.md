# 教师解析 PDF 构件规范

状态：草案，等 Owner 看样张拍板（2026-11-21，Claude 记）。

本文规定教师解析 PDF（`server/exports/companionAnalysisRenderer.mjs`）里每一种功能用哪个构件，以及这个构件长什么样。代码里的对应关系在
`server/exports/companion-analysis/components.mjs`，样式在同目录的 `styles.mjs`。
`scripts/verify-companion-analysis-export.mjs` 双向检查：页面上的每个类名都必须属于某个构件，`styles.mjs` 里的每个类选择器也必须属于某个构件。所以要加一种新样子，先在 `components.mjs` 里加构件或扩展构件；在题型模块里临时起一个类名，检查就会失败。

版式的其余约定（纸张、页边距、字体、字号、对齐、页眉页脚）见
[配套解析适配记录](companion-analysis-adaptation.md)「打印版式」。

## 八条规则

1. **层级靠题号块、字重和留白，不靠横线。** 全卷只有两条线：卷头卷名下的一段 18mm 短绿线，以及双栏中间的发丝竖线。部分标题、题组标题、答案速查、题组答案行、写作的事实行，上下都不画线。`verify-companion-analysis-export.mjs` 会检查：除卷头短线外，没有任何实线边框。
2. **线索用淡绿底，不用下划线。** 原文和译文里支撑答案的词句铺 `--tint`（#e2e7df）底色，在最后一个字上挂题号上标。中文里上标放在句末标点前（「一座岛²²。」），和 GB/T 7714 的引注位置一致。
3. **长难句的成分用方括号括出。** 方括号是松烟绿细体，不铺底色，不加编号。这是 EBS 수능특강「Structure in Focus」的做法。原文里不再标长难句。
4. **一个空一个号，一条线索一个号。** 填进去的答案用粗体，题号写在答案前面，和试卷上的空一样（「63 **absence**」）。线索只在末尾挂一个上标；几题共用一条线索时，上标写成「36,37」。
5. **答案先给，给得紧。** 首页是全卷答案速查，每个题组开头再给一行本组答案（和首页速查重复，但翻到题组时不用回首页，Owner 2026-11-21 定：保留）。单题的题头是绿底反白题号块加答案，讲解接在同一行。
6. **不用「·」分隔。** 答案靠对齐分开，听力话题三级之间用全角空格，人物和身份之间用冒号。外国人名里的间隔号照 GB/T 15834 保留。
7. **全卷左对齐。** 中英混排的行用两端对齐时，一行末尾放不下一个英文长词，前面的中文字就会被拉开（「提 示 词」）。2025 新课标Ⅱ 两端对齐有 31 行被拉开，左对齐 0 行，换行和页数不变。中文字等宽，左对齐的右边最多差一两个字。对齐只在 `.analysis-body` 上写一次，构件里不再各自设对齐（Owner 2026-11-21 定）。
8. **同一种东西只有一种写法。** 干扰项不论题型都写「**A 项**（选项）错在：说明」，完形的选项词也放进括号，完形写「意为」（「**A 项**（normally）意为：」），因为完形的说明多是选项词的词义，写「错在」不通。证据不论题型都是一个接排标签加引文，引原文的标签都叫「原文依据」，不用圆点列表，标签后不加冒号；读后续写引题干和段首句时，标签写「题干依据」「段首句 1」「段首句 2」，让老师看出引文出处。读后续写「原文理解」里的行名（中心情境、人物、因果链等）接排在内容第一行行首，不再单占一行，原文理解下面只剩一层。这一条学的是 EBS 全书固定的标签词和 SAT 每题同一个句式（「Choice A is the best answer because…」「Choice B is incorrect because…」）（Owner 2026-11-21 定）。干扰项不设「干扰项辨析」标签：标签接在第一项前面挤，单占一行又空，学 SAT 每项自己写「错在」；不标陷阱类型名，怕类型标错反成错误（Owner 2026-11-22 定）。同日复议后仍定不写类名，句尾的「属无中生有」「对象错配」一类标签在导出时去掉，类型只留在数据里（规则见 `server/paper-import/trapNameTail.mjs`）。

## 构件表

| 构件 | 功能 | 长什么样 |
|---|---|---|
| Masthead 卷头 | 出版标记、卷名 | 「獭石试题解析」小号字距标记（Owner 2026-11-22 定，BRAND.md 第 131 条），卷名大号粗体，下面一段 18mm 松烟绿短线 |
| AnswerKey 答案速查 | 首页全卷答案 | 答题卡式的表：左侧题型名，右侧五题一格，题号印在淡绿底带上，答案粗体在下；字母答案一行四格（20 题），单词答案一行一格；格与格之间靠白缝分开，不画格线（Owner 2026-11-21 要表格，待拍板） |
| BodyGrid 正文双栏 | 正文排版 | 两栏，栏距两字，中间 0.35pt 发丝竖线 |
| PartHead 部分标题 | 「第三部分 语言运用」等 | 11pt 松烟绿粗体（正文 10pt），两个部分之间空一行，不画线 |
| GroupHead 题组标题 | 「完形填空」等，进页眉 | 粗体标题，下接本组答案行，答案行的「答案」二字用淡墨小字 |
| Label 接排标签 | 篇章大意、原文依据、句子解析、参考译文、基本审题等 | 正文字号的松烟绿粗体，写在块的第一行行首，不单占一行；块本身另起一行时（如「原文」「长难句解析」「基本审题」）也是同一种绿色粗体 |
| PassageBlock 篇章块 | 篇章大意、篇章结构、完形主线、全文译文 | 正文段落，段间小空。完形有 `mainLine` 时（2026-11-22 起新生成的，待拍板），篇章大意下面接「主线」：主题意义一行（引的原文粗体）、每段一行（段号粗体，卷面说明不印）、情感线一行（说明文没有就不印）。串空不印（Owner 2026-11-23 定）。写法见 `docs/product/cloze-methods.md` |
| Mark 原文标注 | 原文和译文里的线索、填入的答案 | 线索铺淡绿底、末字挂上标题号；答案粗体、前置题号 |
| QuestionHead 题头 | 每题第一行 | 绿底反白题号块（10.5pt 粗体衬线等宽数字，约等于旁边答案字母的大写高度，和正文同一基线；一位数和两位数同宽 2 字，数字左右居中、上下留白相同，块只比基线低约 2pt，不往下坠；正文的 text-align-last: start 会被题号块继承，题号块自己写回 center）、粗体答案、语法填空的提示词，讲解接排。阅读题（2026-11-21 起，待拍板）题号块后接英文题干，照卷面原文、正文字重，定位词粗体（只在 `locateBy: stem` 时）；下一行淡墨中文译文。这样题干、定位行、原文三处粗体是同一条线 |
| Prose 讲解 | 讲解正文 | 10pt / 15pt。讲解、错项、桥接和找法里的段落和句子，分析写成记号 `[[paragraphId]]`、`[[paragraphId|该段某句里的原词]]`，程序数成「第 3 段」「第 3 段首句」，模型自己不数（2026-11-24 起，阅读第 2 轮）|
| EvidenceQuote 原文依据 | 定位、引原句、正确选项 | 「原文依据」接排标签加引号引出原句；读后续写的依据行同样写法，不用圆点。阅读题在它前面加一行「定位」。分析里有 `locateBy`（BUB-255，2026-11-21 起，待拍板）时用数据：`stem` 题写「定位 **定位词** 原词 第几段第几句」，原文换了说法时写「定位 **题干词**（中文）→ **原文词**（中文）第几段第几句」（两边的中文意思是分析的 `sourceZh`、`targetCueZh`，淡墨；原文词只是题干词去掉或多出几个词时算原词，不加中文；Owner 2026-11-24 定）（句位由程序数定位句：首句、末句、第 M 句，一句成段的不写；分小标题的篇写「小标题 末句」；2026-11-23 学《答案详解》的句位指法）；答案不在定位句时，下一行对齐写「答案不在定位句，在前一句 / 后两句 / 同段后文 / 下一段 / 第几段」（程序按位置算）。下面引定位句，定位词在原文里加粗、答案所在加淡绿底；答案不在定位句时引文末尾一行淡墨「→ 桥接一句」，只说为什么，不说在哪；`options` 题写「定位 按选项回原文」；`passage` 题只有段落大意题写段号，其余不写定位行。阅读部分小标题下一行图例「粗体是定位词，淡绿底是答案所在」。没有 `locateBy` 的旧解析照旧用程序比对：题干里在线索段也出现的词（粗体，不是作者另写的）→ 第几段；后面加一行「正确选项」：「C 项（选项译文）」接卷面上的整句选项原文，正确项和错项一样印一次中文（2026-11-23；2026-11-24 起标签从「同义替换」改为「正确选项」，因为正确项和原文的关系不只是换说法，还有原词、概括、两处合并、推一步；关系由讲解第一句用白话说，不贴类型标签，Owner 定）。新旧解析都印这一行。顺序：定位 → 原文依据 → 正确选项 → 讲解 → 干扰项，和听力「先依据后讲解」一致 |
| Distractors 干扰项 | 错项为什么错 | 不设标签，「A 项」粗体，选项内容放括号，一项一行，写「A 项（选项）错在：」，完形写「意为：」；阅读一个理由同时排掉几项时（分析里几项写同一句），合成一行「A、B 项（…；…）错在：」，排在第一项的位置；不写陷阱类型名，阅读题旧数据句尾的类型名导出时去掉（`server/paper-import/trapNameTail.mjs`）；各题型同一写法 |
| ContextChain 上下文链 | 七选五的空前、答案、空后 | 三行，每行行首一个淡墨小标签；答案那一行是松烟绿粗体 |
| LongSentence 长难句 | 长难句解析 | 「关联题目」淡墨小字；原句成分用方括号；「句子解析」「参考译文」接排 |
| ListeningMaterial 听力材料 | 每段材料 | 段落标题粗体，话题淡墨小字，听力原文和参考译文接排，短选项排成一行 |
| FactList 事实行 | 写作的审题卡、原文理解、续写约束 | 应用文审题：左侧标签淡墨、右侧内容；读后续写原文理解：行名用松烟绿接排标签；行间留白，不画线 |
| ModelEssay 范文 | 参考范文 | 段间小空，署名单独成行 |

## 每个题型会出现什么

按四套样卷的实际输出统计（2025 新课标Ⅱ、2024 浙江 1 月、两套模拟卷）。某一块只有数据里有才会印，数据没有就不印，所以单题不一定样样都有。

| 题型 | 题组层 | 单题 |
|---|---|---|
| 听力 | 题组答案行；每段材料：段落标题、话题、听力原文、参考译文 | 题头、选项、原文依据、讲解、干扰项辨析 |
| 阅读 | 题组答案行、篇章大意、篇章结构、全文译文（线索标注）、长难句解析 | 题头、原文依据、讲解、干扰项辨析 |
| 七选五 | 题组答案行、篇章大意、全文译文、长难句解析 | 题头、上下文链、讲解、干扰项辨析 |
| 完形填空 | 题组答案行、篇章大意、主线、全文译文、长难句解析 | 题头（答案词后接正确项「词典义；此处指语境义」，正文墨色）、脉络、找法（「词性看考点」粗体，引的原文粗体）、干扰项辨析；没有新字段的旧解析照旧印一段讲解 |
| 语法填空 | 题组答案行、篇章大意、全文译文、长难句解析 | 题头（含提示词、考点）、原句行、讲解 |
| 应用文写作 | 基本审题、内容要点、读者意识、参考范文 | 无 |
| 读后续写 | 原文理解（人物、关系、因果）、续写约束、两段发展方案、参考范文 | 无 |

五个题型都不重印英文原文，老师手上有试卷（Owner 2026-11-23 定）。七选五、完形、语法填空以前整篇再印一遍「原文」（空用答案填好），量过四套卷，占这三个题型篇幅的 10%–23%；作答位置靠全文译文里的 [41] 和每题的讲解已经找得到。语法填空的讲解常常只说「空前的 dates」，离开原句看不懂，所以每题题头后面接一行「原句行」：答案所在的那一句，各空都填好，本题的答案粗体、本题的线索铺底，不标题号也不挂上标（题号块就在上面，Owner 2026-11-23 定）；线索落在前后句时把那一句也带上（本地 27 套有语法填空解析的卷、270 题里 8 题这样，最长一行 319 个字符），别的空照常填好不标。题头同一行接「考点」：由分析里已有的字段拼出（模型选的考点 facetKey、非谓语的句子成分 role、服务器从答案推出的时态语态和形式），不由模型另写；名称按 grammar-fill-methods.md §六，数据定不下的细项不印（不写「待定」），认不出的考点不印这一行。本地 27 套卷 270 题都拼得出，Owner 2026-11-23 会审 40 空全部判对。阅读不印原文：英文原句只在每题的「原文依据」里出现一次，全文译文里同一处铺底挂号，老师手上有试卷（SAT 解析的做法）。以前阅读另印「原文证据段落」，同一条线索会出现三次（原文、译文、原文依据），去掉后 2025 新课标Ⅱ 和 2024 浙江 1 月各少一页（Owner 2026-11-21 定，比过「段号 + 见第 N 段」的方案：段号按数据数，标题和小标题也算一段，和老师在卷面上数的对不上）。

段号现在按卷面数（2026-11-21 改，待拍板）：标题和小标题不算段，翻页处被切成两半的段（后半段以小写字母开头）算一段；分小标题的文章（如 2025 新课标Ⅱ 阅读 A）直接写小标题名。篇章结构和「定位」用同一个数法。以前按数据数，2025 新课标Ⅱ 阅读 D 第二段在翻页处被导入切成两段，篇章结构从第 3 段起都多数一段，和题干「paragraph 5」对不上。

## 调研依据

Owner 不喜欢「很多横线的 AI 感」，并要求看看顶尖的解析书怎么做。2026-11-21 实际看过的样页如下（样页存在会话草稿区，没有进仓库）：

| 来源 | 看到的做法 | 本规范借了什么 |
|---|---|---|
| 마더텅 수능기출 영어 독해 / 듣기（알라딘 미리보기） | 大号彩色题号；关键句整句铺底色；正文区基本没有横线 | 题号块；线索铺底色 |
| EBS 수능특강 영어 정답과 해설（알라딘 미리보기） | 单元首行先给紧凑答案；语法句用 [ ] 括出成分；只有大标题下一条细线 | 答案先给；长难句方括号；不画线 |
| 자이스토리 영어 독해 실전（알라딘 미리보기） | 彩色题号块；主题句铺绿底；颜色最多，接近满版标注 | 反例：颜色和标签不能多 |
| College Board SAT Practice Test 10 Answer Explanations（官方 PDF） | 全页一条细线；题与题之间只靠粗体题头和段距；不重印原文，证据用引号引在解释里；每题同一句式 | 层级靠字重和留白；原文依据用引号；阅读不重印原文；干扰项一种写法 |
| Cambridge B2 First Handbook 和听力答案（官方 PDF） | 答案表按 Part 分组，只有题号和答案 | 答案速查按题型一行 |
| ETS TOEFL iBT Teacher's Resources Practice Test 3（官方 PDF） | 答案表只有两列 | 同上 |
| 金考卷（Owner 提供的第 45、47 页截图） | 国内解析书的通行结构：答案、解析、译文 | 和我们现有的块对得上，不另加 |

没有看到实页的：五三、天利38套、王后雄、必刷题（网站拦截或预览图防盗链），赤本、青本、黒本、Z会（官网只有封面），剑桥雅思真题书（只找到盗版，没有看）。这些书的做法本规范不作依据。

样页里「AI 感」和「出版社感」的区别，归纳成三条：

- AI 感：每个标题上下都有线，标题一层层叠起来，每处证据都是下划线加括号编号。
- 出版社感：只用一种强调色，固定用在题号和证据底色上；一套标签词贯穿全书；层级靠留白和字重。
- 我们对应的改动：去掉部分标题、题组、答案速查和事实行的线；写作去掉「审题卡」这一层，从四层（第四部分 / 应用文写作 / 审题卡 / 基本审题）变成三层；线索从下划线改成底色；空和线索各只标一个号。

## 改动和检查

- 改样式前先看构件表，找到功能对应的构件，在它自己的类上改。
- 改完跑：
  - `node scripts/verify-companion-analysis-export.mjs`（构件登记、横线、标注）
  - `node scripts/verify-analysis-text-ranges.mjs`（标注位置）
  - `node scripts/verify-companion-analysis-snapshots.mjs`（35 套卷 HTML 摘要；版式有意改动时加 `--update` 重钉，并在提交说明里写清改了什么）
- 版式只影响新封存的解析。已封存的旧版不变；要换新版式就得重新封存，重新封存就要重新审核。
