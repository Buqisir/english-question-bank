# 教师解析 PDF 构件规范

状态：草案，等 Owner 看样张拍板（2026-11-21，Claude 记）。

本文规定教师解析 PDF（`server/exports/companionAnalysisRenderer.mjs`）里每一种功能用哪个构件，以及这个构件长什么样。代码里的对应关系在
`server/exports/companion-analysis/components.mjs`，样式在同目录的 `styles.mjs`。
`scripts/verify-companion-analysis-export.mjs` 双向检查：页面上的每个类名都必须属于某个构件，`styles.mjs` 里的每个类选择器也必须属于某个构件。所以要加一种新样子，先在 `components.mjs` 里加构件或扩展构件；在题型模块里临时起一个类名，检查就会失败。

版式的其余约定（纸张、页边距、字体、字号、对齐、页眉页脚）见
[配套解析适配记录](companion-analysis-adaptation.md)「打印版式」。

## 七条规则

1. **层级靠题号块、字重和留白，不靠横线。** 全卷只有两条线：卷头卷名下的一段 18mm 短绿线，以及双栏中间的发丝竖线。部分标题、题组标题、答案速查、题组答案行、写作的事实行，上下都不画线。`verify-companion-analysis-export.mjs` 会检查：除卷头短线外，没有任何实线边框。
2. **线索用淡绿底，不用下划线。** 原文和译文里支撑答案的词句铺 `--tint`（#e2e7df）底色，在最后一个字上挂题号上标。中文里上标放在句末标点前（「一座岛²²。」），和 GB/T 7714 的引注位置一致。
3. **长难句的成分用方括号括出。** 方括号是松烟绿细体，不铺底色，不加编号。这是 EBS 수능특강「Structure in Focus」的做法。原文里不再标长难句。
4. **一个空一个号，一条线索一个号。** 填进去的答案用粗体，题号写在答案前面，和试卷上的空一样（「63 **absence**」）。线索只在末尾挂一个上标；几题共用一条线索时，上标写成「36,37」。
5. **答案先给，给得紧。** 首页是全卷答案速查，每个题组开头再给一行本组答案（和首页速查重复，但翻到题组时不用回首页，Owner 2026-11-21 定：保留）。单题的题头是绿底反白题号块加答案，讲解接在同一行。
6. **不用「·」分隔。** 答案靠对齐分开，听力话题三级之间用全角空格，人物和身份之间用冒号。外国人名里的间隔号照 GB/T 15834 保留。
7. **全卷左对齐。** 中英混排的行用两端对齐时，一行末尾放不下一个英文长词，前面的中文字就会被拉开（「提 示 词」）。2025 新课标Ⅱ 两端对齐有 31 行被拉开，左对齐 0 行，换行和页数不变。中文字等宽，左对齐的右边最多差一两个字。对齐只在 `.analysis-body` 上写一次，构件里不再各自设对齐（Owner 2026-11-21 定）。

## 构件表

| 构件 | 功能 | 长什么样 |
|---|---|---|
| Masthead 卷头 | 出版标记、卷名 | 「EQBANK 教师解析」小号字距标记，卷名大号粗体，下面一段 18mm 松烟绿短线 |
| AnswerKey 答案速查 | 首页全卷答案 | 左侧题型名，右侧答案；字母答案每五题一排，单词答案按列对齐；不画格线 |
| BodyGrid 正文双栏 | 正文排版 | 两栏，栏距两字，中间 0.35pt 发丝竖线 |
| PartHead 部分标题 | 「第三部分 语言运用」等 | 11pt 松烟绿粗体（正文 10pt），两个部分之间空一行，不画线 |
| GroupHead 题组标题 | 「完形填空」等，进页眉 | 粗体标题，下接本组答案行，答案行的「答案」二字用淡墨小字 |
| Label 接排标签 | 篇章大意、原文依据、干扰项辨析、句子解析、参考译文、基本审题等 | 正文字号的松烟绿粗体，写在块的第一行行首，不单占一行；块本身另起一行时（如「原文」「长难句解析」「基本审题」）也是同一种绿色粗体 |
| PassageBlock 篇章块 | 篇章大意、篇章结构、全文译文、原文 | 正文段落，段间小空 |
| Mark 原文标注 | 原文和译文里的线索、填入的答案 | 线索铺淡绿底、末字挂上标题号；答案粗体、前置题号 |
| QuestionHead 题头 | 每题第一行 | 绿底反白题号块（9pt 粗体，最小宽 1.75 字）、粗体答案、语法填空的提示词，讲解接排 |
| Prose 讲解 | 讲解正文 | 10pt / 15pt |
| EvidenceQuote 原文依据 | 引原句 | 引号引出原句 |
| Distractors 干扰项辨析 | 错项为什么错 | 选项字母粗体，一项一行；第一项接在「干扰项辨析」后面 |
| ContextChain 上下文链 | 七选五的空前、答案、空后 | 三行，每行行首一个淡墨小标签；答案那一行是松烟绿粗体 |
| LongSentence 长难句 | 长难句解析 | 「关联题目」淡墨小字；原句成分用方括号；「句子解析」「参考译文」接排 |
| ListeningMaterial 听力材料 | 每段材料 | 段落标题粗体，话题淡墨小字，听力原文和参考译文接排，短选项排成一行 |
| FactList 事实行 | 写作的审题卡、原文理解、续写约束 | 左侧标签淡墨、右侧内容，行间留白，不画线 |
| ModelEssay 范文 | 参考范文 | 段间小空，署名单独成行 |

## 每个题型会出现什么

按四套样卷的实际输出统计（2025 新课标Ⅱ、2024 浙江 1 月、两套模拟卷）。某一块只有数据里有才会印，数据没有就不印，所以单题不一定样样都有。

| 题型 | 题组层 | 单题 |
|---|---|---|
| 听力 | 题组答案行；每段材料：段落标题、话题、听力原文、参考译文 | 题头、选项、原文依据、讲解、干扰项辨析 |
| 阅读 | 题组答案行、篇章大意、篇章结构、全文译文（线索标注）、原文证据段落（只印有线索的段落）、长难句解析 | 题头、原文依据、讲解、干扰项辨析 |
| 七选五 | 题组答案行、篇章大意、全文译文、原文（答案补全进去）、长难句解析 | 题头、上下文链、讲解、干扰项辨析 |
| 完形填空 | 题组答案行、篇章大意、全文译文、原文（答案补全进去）、长难句解析 | 题头、讲解、干扰项辨析 |
| 语法填空 | 题组答案行、篇章大意、全文译文、原文（答案补全进去）、长难句解析 | 题头（含提示词）、讲解 |
| 应用文写作 | 基本审题、内容要点、读者意识、参考范文 | 无 |
| 读后续写 | 原文理解（人物、关系、因果）、续写约束、两段发展方案、参考范文 | 无 |

「原文」和「原文证据段落」的区别：七选五、完形和语法填空的原文是整篇印一遍，空已经用答案填好；阅读只印带线索的那几段，所以叫「原文证据段落」。

## 调研依据

Owner 不喜欢「很多横线的 AI 感」，并要求看看顶尖的解析书怎么做。2026-11-21 实际看过的样页如下（样页存在会话草稿区，没有进仓库）：

| 来源 | 看到的做法 | 本规范借了什么 |
|---|---|---|
| 마더텅 수능기출 영어 독해 / 듣기（알라딘 미리보기） | 大号彩色题号；关键句整句铺底色；正文区基本没有横线 | 题号块；线索铺底色 |
| EBS 수능특강 영어 정답과 해설（알라딘 미리보기） | 单元首行先给紧凑答案；语法句用 [ ] 括出成分；只有大标题下一条细线 | 答案先给；长难句方括号；不画线 |
| 자이스토리 영어 독해 실전（알라딘 미리보기） | 彩色题号块；主题句铺绿底；颜色最多，接近满版标注 | 反例：颜色和标签不能多 |
| College Board SAT Practice Test 10 Answer Explanations（官方 PDF） | 全页一条细线；题与题之间只靠粗体题头和段距；证据用引号引在解释里 | 层级靠字重和留白；原文依据用引号 |
| Cambridge B2 First Handbook 和听力答案（官方 PDF） | 答案表按 Part 分组，只有题号和答案 | 答案速查按题型一行 |
| ETS TOEFL iBT Teacher's Resources Practice Test 3（官方 PDF） | 答案表只有两列 | 同上 |
| 金考卷（Owner 提供的第 45、47 页截图） | 国内解析书的通行结构：答案、解析、译文 | 和我们现有的块对得上，不另加 |

没有看到实页的：五三、天利38套、王后雄、必刷题（网站拦截或预览图防盗链），赤本、青本、黒本、Z会（官网只有封面），剑桥雅思真题书（只找到盗版，没有看）。这些书的做法本规范不作依据。

样页里「AI 感」和「出版社感」的区别，归纳成三条：

- AI 感：每个标题上下都有线，标题一层层叠起来，每处证据都是下划线加括号编号。
- 出版社感：只用一种强调色，固定用在题号和证据底色上；一套标签词贯穿全书；层级靠留白和字重。
- 我们对应的改动：去掉部分标题、题组、答案速查和事实行的线；写作去掉「审题卡」这一层，从四层（第四部分 / 应用文写作 / 审题卡 / 基本审题）变成三层；线索从下划线改成底色；空和线索各只标一个号。

## 改动和检查

- 改样式前先看构件表，找到功能对应的构件，在它自己的类上改。
- 改完跑：
  - `node scripts/verify-companion-analysis-export.mjs`（构件登记、横线、标注）
  - `node scripts/verify-analysis-text-ranges.mjs`（标注位置）
  - `node scripts/verify-companion-analysis-snapshots.mjs`（35 套卷 HTML 摘要；版式有意改动时加 `--update` 重钉，并在提交说明里写清改了什么）
- 版式只影响新封存的解析。已封存的旧版不变；要换新版式就得重新封存，重新封存就要重新审核。
