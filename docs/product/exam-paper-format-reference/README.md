# Exam Paper Format Reference

This folder stores A4 visual references for the hard exam-paper formatting
standards in `docs/product/exam-paper-format-standards.md`.

These images are not random examples. They are the visual target for paper
authoring, import normalization, PaperSurface display, print/export, and future
paper-building workflows.

Listening and opening-page measurements are recorded in
[`listening-measurements.md`](listening-measurements.md), with digest-bound
raw coordinates in [`listening-measurements.json`](listening-measurements.json).
These distinguish cropped-image ratios from physical PDF measurements; they
do not by themselves change runtime typography or certify 8/10-page output.

## Use

- Preserve source semantics: passage text, question meaning, option content,
  answer keys, and writing prompts.
- Do not treat imported source formatting as authority. If a real or mock paper
  is visually sloppy, normalize it toward this reference set.
- If formatting normalization may change meaning, stop and surface the ambiguity
  for human review.
- Do not copy chat history as the standard. Use this folder and
  `exam-paper-format-standards.md` as the durable source of truth.
