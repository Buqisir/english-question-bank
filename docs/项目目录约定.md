不放入 `Local Vaults`，避免把知识库、node_modules、数据库、导入原件和导出成品混在一起。

## 目录分工

```text
english-question-bank/
  app/      # 前后端正式代码
  data/     # 本地数据库与应用运行数据
  imports/  # DOCX/PDF 导入原件
  exports/  # DOCX/PDF 导出试卷与题集
  docs/     # 产品设计、数据结构、开发记录
  design/   # open-design 视觉原型与界面实验
```

## 工具边界

- `open-design`：用于界面原型、审美探索、工作台视觉方案。
- `english-question-bank`：正式产品代码仓库。
- `Local Vaults`：继续作为外脑、知识库、教研沉淀，不承载题库应用代码。
- 本项目暂不使用 Codex 内置浏览器做 UI 验收；本地页面检查、截图和烟测使用 Chrome/headless Playwright。
