# Teaching Analysis Style — V1

本规范约束 NCK1 导题产生的教学解析。它蒸馏的是优秀教师的讲解动作，
不是任何市售答案册的固定句式或原文。

## 目标

以结构化证据为骨架，把已经核实的判断讲成学生听得懂、下一题用得上的话：

- 后台保留完整分类、标签、证据与边界，供匹配、校验和审核；
- 学生可见字段先还原具体语境，再补出关键一步，最后才在确有帮助时点出术语；
- 讲解以“恰好讲透”为准，不以标签数量、篇幅或语言华丽程度为准。

所有题型原有 JSON 输出合同、枚举、答案权威和精确引文规则优先。本规范只
约束教学文字的内容与表达，不授权新增字段、改变答案或绕过验证。

## 一条总口令

> 先讲人话，再给名字；先讲这道题为什么，再讲这类题怎么看。

`facetKey`、`signatureFacet`、`primaryMechanismFacet`、`primaryType` 等字段
可以完整保存，但 `reason`、`note`、`fitSummary`、`explanation` 等学生可见
文字不得拿这些标签代替解释。

以下写法不能独立充当讲解：

- “属于语义场”“符合施受关系”“考查词钩”“逻辑一致”；
- “由此可知”“显然”“符合文意”，却没有说出中间一步；
- 只把选项或原句换一种中文再说一遍；
- 先堆一串术语，再让学生自己倒推题目里发生了什么。

若一个术语确有迁移价值，先把具体现象讲明白，再短写“这也就是……”。

## 六个讲解动作

每道题只选真正需要的动作，不机械凑齐六项。

1. **还原现场**：用一句话说明此处正在发生什么、作者刚说了什么。
2. **指出接口**：指出空格、选项、句子或段落之间真正相接的词义、动作、
   结构、因果、转折或指代。
3. **补出暗步**：把学生必须自己跨过的那一步写出来；简单直取题不硬造推理。
4. **预判误选**：说明错项为什么看起来像答案，例如照搬原词、只对上一半、
   对象相近或符合常识。
5. **放回语境**：说明错项在这一句、这一段或这一事件中具体哪里接不上。
6. **收住结论**：只说证据能够支持到的范围，不把可能、一次或局部写成必然、
   每次或全部。

## 证据强度

讲解用语必须与证据强度一致：

- 原文明说：`原文明确指出……`
- 一步可得：`由……可知……`
- 需要合并或跨一步：`把……与……合起来，更支持……`
- 只有可能：`这种情况可能存在，但原文不足以确认……`
- 原文没有证据：说明“原文只说了什么、没有说什么”，不得把“没提”写成
  “现实中不存在”。

不要把以下关系画等号：

- 没提到 = 不存在；
- 一次如此 = 后来每次都如此；
- 不是本文重点 = 现实中不重要；
- 符合常识 = 原文已经证明；
- 一条参考续写路线 = 唯一正确情节。

## 恰当密度

默认使用“一条主证据链 + 一条必要验证链”：

1. 先用 1—2 句讲清答案为什么成立；
2. 阅读四选一和完形按各自要求逐项辨析；其他题型只有在能防止真实误选时，
   才补一句验证或错项辨析；
3. 简单题允许一句讲完；复杂推理、计算、跨句整合可以多写一步；
4. 不把内部完整标注逐项朗读给学生；
5. 同一信息只讲一次，必要的解题动作融入具体推理，不另写重复提示。

`teachingNote` 和写作 `highlightExpressions` 已退役，不生成、不要求补齐。
讲解所需的表达分析融入实际推理或范文，不另列精选表达栏目。

### 全文译文

- 阅读 A—D、七选五、完形和语法填空都要生成学生可见的 `fullTranslationZh`，
  与解析和相似题字段在同一次题组生成中完成，不另开一次翻译调用。
- 译文完整、自然、按原文顺序和段落展开；不夹讲解、词汇表、模型过程或原文
  没有的信息。
- 七选五、完形和语法填空先按权威答案补全，再在对应译文位置保留 `[36]`
  这类空号；每个空号恰好出现一次，并按题面空号顺序排列，便于学生对照后面的逐题解析。

### 精选长难句与下划线

- 阅读 A—D、七选五、完形和语法填空每个题组选择 1—2 句，写入同一份解析
  JSON 的 `selectedLongSentences`；不得另起一次模型调用，也不得为 PDF 另造
  一份解析数据。
- 先选“既关键又难”的句子：既承担解题或篇章理解，又有值得拆解的结构。
  如果直接答案句很简单，则退而选择紧扣篇章核心的真正难句；不能见长就选。
- 解析顺序是“找主干 → 接修饰 → 讲关系 → 译全句”。先说谁做什么或什么
  怎么样，再说明从句、非谓语、并列、插入或比较关系；不把术语清单当解析。
- `sourceText` 必须精确来自指定原文段落；七选五、完形和语法填空保留原空标，
  `displayText` 只按权威答案机械补全，绝不改写原句。
- `underlineTexts` 只选 1—3 个能够帮助学生看清主干或关键关系的短片段，必须
  在 `displayText` 中唯一精确定位、互不重叠。下划线用于阅读，不用于装饰，
  不整句全划，也不改变 Paper 页已有的证据高亮。

## 分题型讲法

### 阅读理解

- 正答按“题目问什么 → 原文哪里说 → 选项怎样改写或怎样推出”组织。
- 计算题必须写出参与计算的数、运算和结果，不能只报最终百分比。
- 对比整合题必须说清比较的两边及共同标准。
- 推理题必须写出原文事实与结论之间的中间一步，并控制结论强度。
- 写作手法题既要识别作者做了什么，也要说明这样写让哪个观点、程度或问题
  变得怎样；不能只说“举例”。
- 词义题优先找转折、同位解释、上下义、正反人物或结果；先解释该词在本句的
  意思，再按需命名线索。
- 三个错项都要辨析，写清“为什么容易选 + 放回原文哪里不成立”。
  `原文未提及` 只在确无可定位信息时使用，且不得为了凑齐三项虚构反证。

### 七选五

- 先把空前、答案、空后的实际推进讲出来，例如“做完饮品 → 喊名字 → 顾客
  取走”，再按需概括为动作链、问答、指代或主题句。
- 不能只列复现词；要说明这些词让两边形成了什么关系。
- 段首看它如何统领后文，段中看它如何承前启后，段尾看它如何收束或转向。
- `fitSummary` 负责讲完整衔接；机制字段负责内部标注，不得让字段名接管讲解。
- 干扰项只选最值得教的 0—2 个，说明它能接上哪一小部分、又断在何处。

### 完形填空

- 先还原当前事件或句意，再说正确词放进去后具体表达什么。
- `correctFit.reason` 要指出决定答案的上下文关系，不得停在“搭配合理”。
- 每个错项都要在 `distractorGlosses[].meaning` 中完成简短辨析：
  **此处词义 → 放回当前语境为什么不成立**。
- 不强制说明错项的诱惑性；仅在有源文依据且有助于辨析时补充，不虚构诱因。
- 辨析必须针对本空，不写可复制到任何题的词典释义；也不能为了“全排”虚构
  不存在的差别。
- 转折、动作先后、人物处境、情绪变化、前后复现和篇末回收都可以成为证据；
  先讲具体内容，必要时再概括方法。
- 一句话概括全文供整篇相似匹配，不能把十五个空拆成十五道独立相似题。

### 语法填空

- 不造干扰项，不为了显得深入而展开一套无关语法课。
- `reason` 按“还原句子骨架 → 说明空格职责 → 得到答案形式 → 用邻近结构验证”
  组织；简单空可以合并为一句。
- 谓语动词说清主语、时态、语态中真正决定本空的维度；没有明显时间词时，
  说明为何是一般事实或过去事件链的一环。
- 非谓语先说它修饰、补充或支配谁，再说主动/被动、先后或固定结构。
- 代词、从句、并列等要把所指对象或完整结构还原出来。例如不能只说
  `find oneself doing`，还要说明宾语与句子主语同指，所以用反身代词。

### 应用文写作

- ReviewCard 是学生可见的审题结果，写具体读者、交际动作和要点，不写模型的
  思维过程。
- 写作路线短写为“先完成什么 → 主体写什么 → 怎样得体收束”。
- 范文首先要在考场可复现：题面完整、约80词任务以110词左右为编辑目标，
  推荐100—120个学生新增词，不硬凑字数；明确硬性上限仍服从题面。
- 此区间不是官方评分线；语气匹配关系，每句有功能。
- 亮点来自准确内容、真实语气和自然衔接，不为制造“高级句”反向扭曲任务。

### 读后续写

- 先说原故事尚未解决什么，再从第二段开头反推第一段结尾必须达到的状态。
- 明确区分：原文/段首强制、原文支持但非唯一、完全开放、明确矛盾。
- 两段路线写“原因 → 行动 → 结果/状态变化”，不能只列热闹事件。
- 情绪必须有触发、有内在反应并落实到动作；不堆突然的眼泪、拥抱和升华。
- 范文是一条可行路线，不是隐藏标准答案；保留其他合理路线的空间。
- 结尾回收真实原文线索，不新造象征物，不把局部善意拔高成宏大口号。
- 参考范文控制在题面要求附近，表达服务叙事功能，保持学生可学可用。

## 生成后的静默质量门

逐项检查，任何一项不满足都应在提交 Owner Review 前修正：

1. 答案、事实、引文和对象是否准确；
2. 学生最容易漏掉的那一步是否已经说出；
3. 不知道内部术语的学生能否独立看懂；
4. 该讲的干扰项是否落到了当前语境；
5. 是否把可能、局部或一次写成了必然、全部或每次；
6. 是否存在“显然、符合逻辑、语义场、施受关系”等空壳话；
7. 是否一条主链已经讲透，却又被另一字段重复一遍；
8. 篇幅是否与真实难度匹配；
9. 写作范文是否考场可复现，续写路线是否仍保持开放；
10. 是否只输出题型合同允许的字段和格式。

## 来源与版权护栏

- 不把市售答案册 PDF、长摘录或其固定措辞提交到仓库；
- 不要求模型模仿某个机构、作者或教师的表面文风；
- 只保存我们自己概括出的讲解动作、边界和自有基准表述；
- 基准题引用项目已有合法 PaperAsset 与分析 sidecar，商业材料只用于人工发现
  讲解缺口，不成为运行时输入或发布内容。
